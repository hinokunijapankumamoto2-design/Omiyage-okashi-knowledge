# お土産お菓子ナレッジ構築

> お土産お菓子業界に特化した、Obsidian × Claude Code の企業向けナレッジ基盤
> **KENGOODメソッド** により、散在する市場情報・商品データ・業界知識を AI が自動整理し、組織の「第2の脳」を構築します

**提供元: お土産お菓子研究所（秋坂洋三郎）**

---

## 🎯 このシステムが解決する課題

お土産お菓子業界の企業・事業者が抱える、こんな悩みに対応します：

- 📚 市場調査レポート・トレンド情報がフォルダに埋もれて活用されない
- 🏢 ベテランバイヤー・商品企画担当の暗黙知が属人化している
- 🔍 競合商品の分析データを毎回ゼロから調べ直している
- 📦 駅ナカ・空港・道の駅・EC のチャネル別知見がバラバラに管理されている
- 📝 新商品企画のたびに過去の類似事例を探すのに時間がかかる
- 🔐 AIに社外サーバーへ情報を出したくない（全てローカル処理）

---

## 💡 ソリューション概要

お土産お菓子業界の知識資産を、**「使うほど賢くなる組織の脳」** に変える仕組み。

### KENGOODメソッド：2つのナレッジシステムが同居

| システム | 機能 | 効果 |
|---|---|---|
| **❶ 第2の脳** | 散在する業界情報を AI が自動整理し、質問可能な Wiki に | 検索時間 96% 削減 |
| **❷ 反省ノート** | AI が犯したミスを自動学習し、二度と繰り返さない | 品質の継続改善 |

### すべてローカル完結

- データは全て `.md` ファイルでローカル管理
- 外部サーバーへの送信なし（Claude API以外）
- オンプレミス環境・閉域網でも動作可

## 🏗 アーキテクチャ

```
企業のObsidian Vault
├── raw/                   ← 市場レポート、商品DB、バイヤー情報を投入
├── wiki/                  ← AIが業界カテゴリ別に整理
│   ├── 市場動向/
│   ├── 商品分析/
│   ├── 素材・製法/
│   ├── ターゲット分析/
│   ├── 販売チャネル/
│   └── ブランディング/
├── outputs/               ← 市場調査レポート、商品企画書を自動生成
├── mistakes.md            ← AIの失敗を自動蓄積 → 学習
└── CLAUDE.md              ← 業界特化のAI行動ルール
```

2つのスキル `/second-brain` と `/reflection-notes` を Claude Code に登録することで、**どのプロジェクトディレクトリからでも呼び出し可能**。

## 🚀 クイックスタート（個人試用）

### 前提条件
- [Obsidian](https://obsidian.md/)
- [Claude Code](https://www.anthropic.com/claude-code)
- Git

### Windows 向け自動インストール

```powershell
git clone https://github.com/hinokunijapankumamoto2-design/Omiyage-okashi-knowledge.git
cd Omiyage-okashi-knowledge
.\install\install.ps1 -VaultPath "C:\Users\<your-name>\Documents\OmiyageVault"
```

### Mac/Linux または手動セットアップ

[install/install.md](install/install.md) を参照。所要時間 約10分。

### 使ってみる

1. Obsidian で Vault を開く
2. `raw/` に市場レポートや商品データを投入（テキスト貼り付けでOK）
3. Claude Code で `/second-brain` を実行
4. 15分後、`wiki/` に業界カテゴリ別の整理済みナレッジが完成

## 🧩 Claude Code プラグイン: Kumiki（組木）

本リポジトリは **Claude Code のプラグインマーケットプレイス** も兼ねています。

**Kumiki** は「調べる → 束ねる → 出す」を1本の工程として扱う調査・ナレッジ構築
プラグインです。Web 収集・ナレッジ監査・トークン最適化を、外部の有料 API に
依存せず Python 標準ライブラリのみで実装しています。

```
/plugin marketplace add hinokunijapankumamoto2-design/Omiyage-okashi-knowledge
/plugin install kumiki@omiyage-okashi-lab
```

| 工程 | スキル | 内容 |
|---|---|---|
| 集材 | `/kumiki:gather` | robots.txt 尊重・レート制限・キャッシュ付き収集、CSSセレクタ抽出 |
| 木取り | `/kumiki:plan` | 問いを反証可能な主張に割り、検証ゲートを先に決める |
| 組む | `/kumiki:weave` | 1主張1ノート化と7種類の機械監査 |
| 鉋 | `/kumiki:thrift` | 読む前のコスト計測、アウトライン→スライス、索引化 |
| 仕上げ | `/kumiki:compose` | ノートから出典付き成果物を組み上げる |

詳細は [plugins/kumiki/README.md](plugins/kumiki/README.md)。

## 📖 設計・思想

本システムは **KENGOODメソッド** に基づき、お土産お菓子業界向けに独自実装されています。

### KENGOODメソッドの中核思想
- AIは効率化ツールではなく **認知負荷の再配分装置** である
- 知識は **保存するためでなく、判断に使われるため** に蓄積する
- **属人知を資産化** し、組織が再利用可能な知能へ変える
- 使うほど **複利的に賢くなる** 設計
