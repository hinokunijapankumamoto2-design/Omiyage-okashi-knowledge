# 第6章：AI駆動の𝕏ポスト生成ワークフロー

𝕏運用の最大の敵は「ネタ切れ」と「クオリティのムラ」である。
AIを清書ツールではなく、**リサーチ → 構造分解（型抜き） → マージ（融合）** を自律的に行う
戦略パートナーとして運用することで、後発からでも物量と質で市場を制圧できる。

## 6.1 構造分解（型抜き）— 伸びているポストのDNAを抽出する

いきなり「良いポストを書いて」では凡庸な文章しか出ない。
まず、市場で反応が取れている **競合ポストの構造だけ** を分解する。

### 分解の5観点

| # | 観点 | 抽出する内容 |
|---|---|---|
| 1 | **フックの属性** | 第2章のどのトリガーか（常識破壊／強欲／損失回避／身体描写／比喩） |
| 2 | **ベネフィットの提示法** | Before/After をどう対比させているか |
| 3 | **リズムと改行** | どこで息を吐かせているか（空行の位置、1行の長さ） |
| 4 | **権威性の挿入位置** | 実績・数字を何行目に差し込んでいるか |
| 5 | **CTAの接続** | キーワードと、その正当化（Why）の作り方 |

### 型抜きプロンプト（そのまま使える）

```
以下の𝕏ポストを、内容ではなく「構造」だけ分解してください。
出力形式：
【1行目のトリガー】（常識破壊／強欲／損失回避／身体描写／比喩のどれか＋なぜ効くか）
【骨格】（1行ずつの役割を「フック」「問題提起」「実績」等でラベリング）
【改行リズム】（何行ごとに空行が入っているか）
【権威性の位置】（何行目に、どんな数字が入っているか）
【CTAの型】（出口の種類と、正当化ロジック）
【再利用可能なスケルトン】（中身を空にした穴埋めテンプレート）

--- 対象ポスト ---
（ここに貼る）
```

## 6.2 コンテンツマージ — 「型」と「原液」を融合させる

型を抜いたら、そこに **あなたの原液（独自の知識・経験・実績）** を流し込む。
これが「パクリ」と「資産」を分ける核心である。

### マージの3ステップ

1. **スケルトンの配置** — 競合ポストの構造だけを残し、中身を空にする
2. **ナレッジの注入** — ユーザーの専門知識・独自定義・具体的な失敗談を配置する
3. **人格のシンクロ** — 「自信と丁寧さ、毒と愛」をバランスよく配合し、言葉を研磨する

### マージプロンプト（そのまま使える）

```
以下の【スケルトン】に、【原液】の内容だけを流し込んで新しい𝕏ポストを3案作ってください。
条件：
・競合の言葉づかいは1つも使わない（構造だけ借りる）
・数字は【原液】にあるものだけ使う。無い場合は【要実績】と書く
・1行目は40字以内。3案それぞれ別の心理トリガーを使う
・出口は「（キーワード）へのリプライ」に統一する
・禁忌語（魔法の杖／架け橋／羅針盤／第一歩／いかがでしたか／〜だと思います）は使わない

【スケルトン】
（型抜きの結果を貼る）

【原液】
・実績：
・独自メソッド：
・具体的な失敗談：
・特典の中身：
・なぜ無料で出すのか：
```

## 6.3 マージ実例（1つの型から市場を横断する）

### 型①：常識を否定して救済するスレッド
`否定 → 再定義 → 3つの型 → 特典配布`

| 原液 | 展開 |
|---|---|
| 英会話 | 文法を学ぶな → 文法はパズル → この3つの型だけでOK → 特典配布 |
| ダイエット | 食事制限はゴミ → 脳を騙す食事術 → 空腹感ゼロの理由 → メニュー配布 |
| 不動産投資 | 新築を買うな → 築古の利回り → 融資の考え方 → 個別相談 |
| 子育て | 褒めるな → 存在を認める言葉 → 子供が勝手に動く習慣 → チェックリスト |
| デザイン | 綺麗に作るな → 視線を誘導する配置 → 売れるバナーの共通点 → テンプレ |

### 型②：衝撃の数字から始まる権威性ポスト
`数字 → 種明かし → 意外な着眼点 → リスト誘導`

| 原液 | 展開 |
|---|---|
| 物販 | 粗利率 → 仕入れのセンターピン → 誰も見ない卸売市場 → リスト公開 |
| プログラミング | 年収の変化 → スキルの掛け算 → AIを部下にする技術 → ロードマップ |
| 店舗経営 | 広告費0円で満席 → 公式LINEの教育法 → リピート率の裏側 → 無料勉強会 |
| YouTube | 登録者100人で収益化 → 高単価バックエンド設計 → 再生数に頼らない → 個別診断 |
| 婚活 | マッチング数10倍 → プロフ写真の心理学 → 1通目の技術 → プロフ作成 |

### 型③：失敗談から入る共感ポスト
`身体感覚の描写 → どん底 → 転機の1行 → 現在 → Why → CTA`

どの市場でも通用する。**原液に「具体的な数字と時刻と場所」があるほど強い**。

## 6.4 無限フィードバックループ — AIを教育して精度を上げる

出力に対して、以下の指示で研磨する。

- 「もっと毒を強くして。競合の甘い言葉を具体的に叩いて。」
- 「身体感覚が足りない。脇汗が出る／喉が渇く、みたいな描写を入れて。」
- 「1行目が長い。15文字以内で、脳に刺さる言葉に削ぎ落として。」
- 「なぜこれを今配るのか、僕の過去の絶望を絡めて透明性を高めて。」
- 「実績の数字を、権威性が最大化する位置に移動して。」
- 「CTAが2つある。1つに絞って、残りは削って。」

## 6.5 ワークフローの最終検閲（OSチェック）

1. **【パクリ回避】** 競合の言葉をそのまま使っていないか？ 自分の実体験・独自解釈に置換されているか？
2. **【リスト獲得特化】** 単なる「いい話」で終わっていないか？ 今すぐ動く引力があるか？
3. **【透明性の担保】** なぜ無料で出すのか、理念が1行でも含まれているか？
4. **【視認性の極致】** スマホでスワイプ中に、一瞬で「自分に関係がある」と分かるか？
5. **【事実性】** 数字・限定・効果の記述は、すべて実行可能・実在のものか？

## まとめ

AI駆動ワークフローとは、**市場の成功事例（型）に自分の魂（原液）を流し込み、圧倒的な速度で資産を構築する技術** である。
これにより、運用者は「ネタ探し」から解放され、戦略立案と顧客対応にリソースを集中できる。
