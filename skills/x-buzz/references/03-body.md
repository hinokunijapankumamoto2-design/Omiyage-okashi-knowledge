# 第3章：【情報のパズル化】ファン化と教育を加速させるボディ構成

1行目で止まった視線を、離脱させずCTAまで運ぶ。答えは情報の **パズル配置** にある。
ボディは、読者の脳内にある「疑念」を1つずつ解消し、「信じてもいい」という確信に変えるフェーズである。

## 3.1 ボディを構成する5つのパズルピース

| ピース | 役割 | 書き方 |
|---|---|---|
| **[権威性・実績]** | なぜあなたの話を聞くのか | 数字で示す（累計◯円／受講生◯人／◯年） |
| **[ベネフィット]** | 読者が得る具体的変化 | 箇条書きでスキャン可能に |
| **[ボリューム訴求]** | GIVEの重量感 | 特典数／スライド枚数／動画分数 |
| **[透明性（Why）]** | 怪しさを共感に変える | なぜ無料で出すのか、理念・情熱 |
| **[一択の指示（CTA）]** | 迷わせない | 行動を1つだけ指示する |

**黄金比**：論理（数字）7：感情（理念）3。数字だけでは冷たく、理念だけでは中身がスカスカになる。

### 配置の基本形（単発ポスト）

```
[フック（1行目・40字以内）]
（空行）
[問題提起 or 常識否定 1〜2行]
（空行）
・[ベネフィット1]
・[ベネフィット2]
・[ベネフィット3]
（空行）
[権威性（数字）]＋[Why（なぜ無料か）]
（空行）
[CTA（一択）]
```

## 3.2 スレッド（連投）の黄金法則 — 10投で脳を書き換える

| # | 役割 | 内容 |
|---|---|---|
| 1 | フック | 衝撃の事実。ここに全てを懸ける |
| 2 | 問題提起 | ターゲットが抱える「隠れた痛み」の言語化 |
| 3 | 常識否定 | 今までのやり方がダメな理由を論理で暴露 |
| 4 | 解決策の提示 | メソッドの全体像をチラ見せ |
| 5〜7 | 具体的事例 | 自分・受講生の Before/After（身体感覚描写） |
| 8 | Why | 「同じ絶望を味わってほしくない」等、高い視座の理念 |
| 9 | オファー | 圧倒的な無料特典の紹介（ボリューム可視化） |
| 10 | CTA | リプライ or 公式LINEへの一択誘導 |

**離脱防止の原則**：各投の末尾を「言い切り」で閉じず、次への引き（「その理由は次で話します」「ここからが本題です」）を残す。
論理（3・4・9）と物語（2・5〜8）を **交互に配置** し、読者の脳を飽きさせない。

## 3.3 ボディ構成 実例 50選

### カテゴリF：ローンチ当日・爆発型（熱量とボリュームで圧倒）

1. 【重大発表】ついに完成しました。僕が〇〇で結果を出した全工程を、3時間超えの動画に凝縮。スライド200枚、全5大特典。本気で人生変えたい人だけ受け取って。詳細はリプ欄。
2. 業界をぶち壊します。高額塾が教えていない「裏の最短ルート」。今日から期間限定で完全無料公開。なぜやるか？ 詐欺師に騙される人を一人でも減らしたいから。
3. 1,000人以上を指導して確信しました。売れるか否かは「型」を知っているかだけ。僕の脳内にある最強の台本、そのまま差し上げます。受け取りはリプに「台本」。
4. 【本日終了】残り5時間でこの動画は消します。後悔したくないなら今すぐ見て。既に3,000人が受け取り済み。次はあなたの番です。
5. 実績ゼロから事業を作るまで。その「奇跡」ではなく「論理」を公開しました。泥臭い裏側まで全部話しています。受け取りはリプ欄へ。
6. 4年間の集大成を、1本にまとめました。動画3時間／ワークシート12枚／テンプレ50個。正直、有料級では足りません。今日だけ無料で開けます。
7. 準備に半年かかりました。だから中途半端な人には渡しません。「本気」とリプした人にだけ、全部渡します。
8. 【解禁】僕が最も再現性が高いと確信した1つの型。これだけで初月から動けます。受け取り方法は最初のリプ欄。
9. 反響が想定の5倍でした。サーバーが重くなる前に、今のうちに受け取っておいてください。
10. これが最後です。この企画以降、同じ内容を無料で出すことはありません。理由は本文の最後に書きました。

### カテゴリG：常識破壊・教育型（論理で納得させる）

11. 毎日投稿は時間の無駄。週2回の神投稿。これが今の𝕏の正解です。理由はアルゴリズムが滞在時間を重視しているから。具体的な設計は……
12. フォロワーは増やすな。100人の濃いリストを作れ。1万人の冷やかしより、100人のファン。これがビジネスの原理です。
13. 文章術なんて学ぶな。相手の「脳内反論」を先回りするパズルを学べ。これができれば、砂漠でも水が売れます。
14. 安売りは顧客への裏切り。価値に見合う価格をつけるのが誠実さです。単価を3倍にしても感謝される理由を話します。
15. AIに仕事を奪われる？ 逆です。AIで時間を作り、人間しかできない「教育」に全振りするのが勝ち筋。
16. バズは狙うな。狙うのは「保存」だけ。保存された投稿は、半年後もリストを運び続けます。
17. プロフを1行変えるだけで、遷移からの登録率は変わります。見るべきは1行目ではなく、最後の1行です。
18. 「有益な情報」を出しても売れません。売れるのは「あなたの失敗談」です。理由は人が動くのが論理ではなく感情だからです。
19. 企画は当日じゃ売れません。売れるのは2週間前から仕込んだ人だけ。カレンダーを公開します。
20. ノウハウはもう飽和しています。差がつくのは「誰が言うか」。その作り方を全部書きました。

### カテゴリH：ストーリー・共感型（弱さを開示し絆を作る）

21. 深夜2時、通帳の残高を見て震えていたあの日。もう誰にも頼らないと決めました。そこから這い上がった全記録を公開します。
22. 手取り18万。上司の怒鳴り声に怯える毎日。そんな僕を救ったのは、たった一行の言葉でした。その正体とは……
23. キラキラした生活、実は大嫌いです。僕の裏側はドロドロの努力。でも、その方がカッコいいと思うから。
24. 詐欺まがいの塾に払った300万。あの絶望があったから、僕は「本物」だけを追えるようになりました。同じ過ちをしてほしくない。
25. 家族との時間。それが僕の原動力です。ビジネスは手段。目的は愛する人を守ること。その思想をこの動画に込めました。
26. 初投稿のいいねは1でした。それも自分の。そこから何が変わったのか、順番に話します。
27. 一番苦しかったのは、稼げないことじゃなく「誰にも相談できない」ことでした。だから僕は場を作りました。
28. 妻に「もうやめて」と言われた夜。あの一言が、今の型を作りました。
29. 3年前の自分に渡したい資料を作りました。だから、当時の僕と同じ場所にいる人にだけ届けたい。
30. 成功談は聞き飽きたと思います。だから今日は、僕が捨てた失敗を全部並べます。

### カテゴリI：比較・スクリーニング型（属性を絞り成約率を上げる）

31. 本気じゃない人はスルーして。ここから先は、事業を本気で作りに行く人だけの場所です。
32. 楽に稼ぎたい？ それなら宝くじを買ってください。手を動かす覚悟がある人だけ、受け取ってください。
33. 甘い勧誘に騙されたくない人へ。ビジネスの残酷な現実と、それを越える唯一の武器を渡します。
34. 私のサポートは厳しいです。でも1年後に笑いたいなら、今の負荷に耐える価値がある。ついてこれますか？
35. 「明日からやる」を卒業しましょう。今この瞬間に動いた人だけが、切符を掴めます。
36. 副業を「趣味」でやりたい人には不要です。生活を変えたい人にだけ届けます。
37. ノウハウコレクターはお断り。1つでも実行する人にだけ渡します。
38. 1ヶ月で結果が出ないと嫌な人には向きません。1年で資産を積む覚悟がある人向けです。
39. 全員に向けて書いていません。𝕏歴3ヶ月・フォロワー500人・リストゼロ。この条件の人だけ読んでください。
40. 質問に答えられない人はスルーで大丈夫です。「何のために稼ぎたいか」即答できる人だけどうぞ。

### カテゴリJ：圧倒的GIVE・予告型（期待値を最大化）

41. 【予告】明日21時、過去最大の企画を発表します。通知オンにして待機を。全てを賭けた最高傑作です。
42. 制作費【要実績】。外注に溶かして得た究極のテンプレート。明日、無料で解禁します。理由は……
43. なぜ無料で配るのか。あなたの成果が僕の最高の広告になるからです。だから手は抜きません。詳細は明日。
44. 先行モニター30名が全員動き出した仕組み。一般公開は明日20時。準備はいいですか？
45. 最終章です。僕が最前線で動くのはこれが最後。全てを継承する企画、明日21時スタート。
46. 深夜3時。スライド200枚突破。無料で出すのは頭おかしいと止められています。でも、やる。
47. 今作っているものが、たぶん今年一番の自信作です。完成まであと3日。少しだけ中身を見せます。
48. 【調査】完全版をまとめています。欲しい人はどれくらいいますか？ 反応が多ければ一般公開します。
49. 明日から5日間、毎日21時に投稿します。1日でも見逃すと繋がらない構成にしています。
50. 特典が15個になりました。多すぎると言われましたが、削りません。全部必要だからです。

## 3.4 透明性の注入 — なぜ理念を語るとモノが売れるのか

情報提示（有益性）だけで終わってはいけない。必ず以下のいずれかを1文混ぜる。

- 「かつての自分のように悩む人を救いたい」
- 「業界の質を底上げしたい」
- 「家族との時間を大切にできる働き方を広めたい」

効果：**「売り込み」という印象が「救済」へ反転する**。

## 3.5 ボディの品質検閲

1. **【スキャナリティ】** スマホでパッと見て、箇条書きと空白が適切で読むストレスがないか？
2. **【論理と感情の比率】** 数字だけで冷たくないか／理念だけで中身がスカスカでないか？（7:3）
3. **【反論の先回り】** 「無料でそんなの出すわけない」と思う瞬間に、Why を提示できているか？
4. **【出口への期待】** 読み終わった瞬間、リプ欄や公式LINEの中身に飢餓感を感じさせているか？

## まとめ

ボディは、1行目の衝撃を揺るぎない確信へ昇華させる **論理のパズル** である。
MPT（圧縮）と透明性（情熱）を融合させることで、ポストは「つぶやき」から「演説」へ変わる。
