# Xバズskill（`/x-buzz`）

𝕏（旧Twitter）のポストを「つぶやき」から **24時間働く自動営業マシン** へ変えるスキル。

## 設計思想

インプレッションは **分母** に過ぎない。センターピンは **リスト獲得** と **プロフ回遊**。
出口（リンククリック／キーワードリプライ）を先に確定し、そこから1行目の1文字目を決める
**バックワード・デザイン** で全ポストを設計する。

## 使い方

```
/x-buzz
```

または自然文で依頼する（description のキーワードで自動発火する）。

```
「新商品の告知ポストを作って。出口はリプに『試作』で」
「この投稿を添削して」
「12/1に募集開始したい。14日分の告知カレンダーを組んで」
「この伸びてる投稿の型だけ使って、私の実績で書き直して」
```

SKILL.md は毎回読まれるが、references は **必要な章だけ** 読み込まれる（プログレッシブ・ディスクロージャ）。

## 生成時にヒアリングされる4項目

1. **出口（CTA）** — リンク／キーワードリプライ／引用RP／フォロー
2. **ターゲット** — 誰の、どんな痛みか（「全人類」はNG）
3. **実績・原液** — 使える実数、独自の体験・失敗談、特典の中身
4. **フェーズ** — 通常運用／プリプリローンチ／予告／当日／追い込み

## 機械チェック（check_post.py）

生成・添削の最後に必ず通る自動チェック。目視では必ずズレる項目だけを機械に任せている。

```bash
python3 scripts/check_post.py draft.txt          # 単発ポスト
python3 scripts/check_post.py draft.txt --thread # 連投（"---" 区切り）
python3 scripts/check_post.py draft.txt --long   # Premium の長文ポスト
python3 scripts/check_post.py draft.txt --json   # 機械可読な出力
```

検出するもの：

| 項目 | 内容 |
|---|---|
| 文字数 | 𝕏の重み付き280ユニット（日本語1文字＝2、URL＝一律23）で正確に計算 |
| 1行目 | 40字超過（タイムラインで折り返され衝撃が消える） |
| 禁忌語 | 魔法の杖／架け橋／羅針盤／第一歩／いかがでしたか 等 |
| 贅肉・抽象語 | 非常に／とても／〜と思います／驚きました／大変でした |
| 視認性 | 空行なしの4行以上連続、28字超の長い行 |
| 出口の一択性 | CTAが3種類以上に分散していないか（連投は最終投のみ必須） |
| 事実性 | 実績数字の要確認リスト、断定的利益保証の検出 |

出力例：

```
── 【要修正】
   文字数: 364/280ユニット（日本語換算 約182字）  1行目: 43字  出口: リプライ, フォロー, いいね
   ✗ [1-1] 1行目が43字。40字以内に削る（脳を止める前に折り返される）
   ✗ [4-1] 出口が3種類。1つに絞る（フォロー＋リプの併記までは可）
   · [6-1] 要確認: 実績数字 ['3000人'] は実数か？ 未確定なら 【要実績】 に置換
```

## 事実性ガードレール

訴求を強めるナレッジであるため、事実と演出の境界を運用側で管理できるよう、以下を標準で組み込んでいる。

- **数字は捏造しない** — 未提示の実績は `【要実績】` プレースホルダとして残す
- **実行しない限定は書かない** — 「5日で消す」と書くなら本当に消す運用が前提（有利誤認の回避）
- **断定的利益保証を書かない** — 効果は「〇〇さんの場合」と事例として限定する
- **業法チェック** — 健康・医療・投資テーマでは薬機法・金商法に触れる断定を避け、生成前に注意喚起する
