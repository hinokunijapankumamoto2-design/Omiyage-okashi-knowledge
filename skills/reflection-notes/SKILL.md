# AI反省ノート自動蓄積システム

以下の原文プロンプトを**一字一句変更せず**に実行する。ユーザーが❷のプロンプトを「必ず崩さずそのまま使用する」と指定したため、書き換え禁止。

---

## プロンプト本文

```

以下の「AI反省ノート自動蓄積システム」を、私の環境にセットアップしてください。

対話しながら進めてください。


---


## 構築するもの


AIが犯したミスを自動で蓄積し、次のセッションから同じミスを二度としなくなる仕組み。

Boris Cherny（Claude Code作者）のアプローチに基づく。


## セットアップ手順


### Phase 1: 環境確認（まず聞いてください）


以下を私に質問してください：


1. **Obsidian Vaultのパス**を教えてください（例: ~/Documents/my-vault/）。Obsidianを使っていない場合は「使っていない」と答えてください。

2. **CLAUDE.mdの場所**を教えてください（プロジェクトルート or ~/.claude/）。まだ作っていない場合は「なし」と答えてください。

3. **反省ノートの言語**は日本語と英語どちらがいいですか？


### Phase 2: ファイル作成


回答を元に、以下のファイルを作成してください。


#### 2-1: mistakes.md（反省ノート本体）


保存先: ユーザーが指定したVaultのルート、またはプロジェクトの .claude/rules/ 配下


```markdown

---

date: {{今日の日付}}

tags: [mistakes, rules, claude-code]

---


# AI反省ノート


AIが犯したミスをルール化して蓄積するファイル。

次のセッションで自動読み込みされ、同じミスの再発を防ぐ。


## 記録フォーマット


各ミスは以下の3行で記録する：

- **やったこと（NG）**: AIが実際にした間違い

- **正しい動作**: 次回からすべき正しい対応

- **トリガー**: どんな状況でこのルールが適用される


## ルール化の3条件（すべて満たす場合のみ記録）


1. ユーザーが明示的に訂正した

2. 同じミスが今後も起きそうなパターンである

3. 具体的な「する/しない」としてルール化できる


---

```


#### 2-2: CLAUDE.mdへの参照追加


既存のCLAUDE.mdに以下のセクションを追加（なければ新規作成）：


```markdown

## ミスルール

- mistakes.md を毎セッション参照し、記載されたルールに従うこと

- 新しいミスを発見した場合、ルール化の3条件を満たすなら mistakes.md に追記すること

```


#### 2-3: .claude/rules/ への配置（CLAUDE.mdに書かない方式を選んだ場合）


.claude/rules/ ディレクトリが存在しなければ作成し、mistakes.md をそこに配置。

Claude Codeが自動読み込みする。


### Phase 3: Stop Hook設定（自動蓄積）


.claude/settings.json（または .claude/settings.local.json）に以下のStop Hookを追加してください。

既存の設定がある場合はマージしてください。


```json

{

  "hooks": {

    "Stop": [

      {

        "type": "prompt",

        "prompt": "セッション中の会話を振り返り、以下の3条件をすべて満たすミスがあったか確認してください：\n1. ユーザーが明示的に訂正した\n2. 同じミスが今後も起きそうなパターン\n3. 具体的な「する/しない」として書ける\n\n条件を満たすミスがあった場合のみ、mistakes.mdに以下のフォーマットで追記してください：\n\n## YYYY-MM-DD: [ミスの一言説明]\n**やったこと（NG）**: [AIがした間違い]\n**正しい動作**: [次回からの正しい対応]\n**トリガー**: [このルールが適用される状況]\n\n条件を満たすミスがなかった場合は何もしないでください。"

      }

    ]

  }

}

```


### Phase 4: 動作確認


セットアップが完了したら、以下を実行して動作確認してください：


1. mistakes.md が正しい場所に作成されたか確認

2. CLAUDE.md（または rules/）から参照できているか確認

3. settings.json にStop Hookが正しく追加されたか確認


最後に、セットアップ結果のサマリーを以下の形式で報告してください：


- ✅ mistakes.md: [保存先パス]

- ✅ 参照設定: [CLAUDE.md or rules/ のどちらか]

- ✅ Stop Hook: [settings.json or settings.local.json]

- 📝 次にやること: 普通にClaude Codeを使うだけ。ミスがあれば自動で蓄積されます。


---


## 重要な注意事項


- 既存のCLAUDE.mdやsettings.jsonがある場合は、内容を壊さないようにマージしてください

- ファイルを作成・編集する前に、既存の内容を必ず確認してください

- 不明点があればユーザーに質問してください。推測で進めないでください
```
