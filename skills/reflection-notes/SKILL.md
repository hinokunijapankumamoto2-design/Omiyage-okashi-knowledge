# 反省ノート自動蓄積システム（KENGOODメソッド）

秋坂洋三郎（お土産お菓子研究所）が設計した **KENGOODメソッド** の「反省ノート」コンポーネント。
AIが犯したミスを自動蓄積し、次のセッションから同じミスを二度としなくなる仕組み。

## 中核思想（KENGOODメソッド）

- AIの失敗は **再発させなければ資産** に変わる
- 人間が同じ訂正を繰り返す **認知負荷を消す** 装置
- 組織が使うほど、AIが **組織の判断基準を学習していく**
- 使うほど **複利的に賢くなる** 設計

---

## セットアップ手順

以下の手順でユーザーの環境にセットアップを行う。対話しながら進めること。

### Phase 1: 環境確認

以下をユーザーに質問する：

1. **Obsidian Vaultのパス**を教えてください（例: ~/Documents/my-vault/）。Obsidianを使っていない場合は「使っていない」と答えてください。
2. **CLAUDE.mdの場所**を教えてください（プロジェクトルート or ~/.claude/）。まだ作っていない場合は「なし」と答えてください。
3. **反省ノートの言語**は日本語と英語どちらがいいですか？

### Phase 2: ファイル作成

回答を元に、以下のファイルを作成する。

#### 2-1: mistakes.md（反省ノート本体）

保存先: ユーザーが指定したVaultのルート、またはプロジェクトの `.claude/rules/` 配下

```markdown
---
date: {{今日の日付}}
tags: [mistakes, rules, claude-code, kengood]
---

# AI反省ノート（KENGOODメソッド）

AIが犯したミスをルール化して蓄積するファイル。
次のセッションで自動読み込みされ、同じミスの再発を防ぐ。

## 記録フォーマット

各ミスは以下の3行で記録する：
- **やったこと（NG）**: AIが実際にした間違い
- **正しい動作**: 次回からすべき正しい対応
- **トリガー**: どんな状況でこのルールが適用される

## ルール化の3条件（すべて満たす場合のみ記録）

1. ユーザーが明示的に訂正した
2. 同じミスが今後も起きそうなパターンである
3. 具体的な「する/しない」としてルール化できる

---
```

#### 2-2: CLAUDE.mdへの参照追加

既存のCLAUDE.mdに以下のセクションを追加（なければ新規作成）：

```markdown
## ミスルール（KENGOODメソッド）

- mistakes.md を毎セッション参照し、記載されたルールに従うこと
- 新しいミスを発見した場合、ルール化の3条件を満たすなら mistakes.md に追記すること
```

#### 2-3: .claude/rules/ への配置（CLAUDE.mdに書かない方式を選んだ場合）

`.claude/rules/` ディレクトリが存在しなければ作成し、mistakes.md をそこに配置。
Claude Codeが自動読み込みする。

### Phase 3: Stop Hook設定（自動蓄積）

`.claude/settings.json`（または `.claude/settings.local.json`）に以下のStop Hookを追加する。既存の設定がある場合はマージする。

```json
{
  "hooks": {
    "Stop": [
      {
        "type": "prompt",
        "prompt": "セッション中の会話を振り返り、以下の3条件をすべて満たすミスがあったか確認してください：\n1. ユーザーが明示的に訂正した\n2. 同じミスが今後も起きそうなパターン\n3. 具体的な「する/しない」として書ける\n\n条件を満たすミスがあった場合のみ、mistakes.md（KENGOODメソッド反省ノート）に以下のフォーマットで追記してください：\n\n## YYYY-MM-DD: [ミスの一言説明]\n**やったこと（NG）**: [AIがした間違い]\n**正しい動作**: [次回からの正しい対応]\n**トリガー**: [このルールが適用される状況]\n\n条件を満たすミスがなかった場合は何もしないでください。"
      }
    ]
  }
}
```

### Phase 4: 動作確認

セットアップが完了したら、以下を確認する：

1. mistakes.md が正しい場所に作成されたか
2. CLAUDE.md（または rules/）から参照できているか
3. settings.json にStop Hookが正しく追加されたか

最後に、セットアップ結果のサマリーを以下の形式で報告する：

- ✅ mistakes.md: [保存先パス]
- ✅ 参照設定: [CLAUDE.md or rules/ のどちらか]
- ✅ Stop Hook: [settings.json or settings.local.json]
- 📝 次にやること: 普通にClaude Codeを使うだけ。ミスがあれば自動で蓄積されます。

---

## 重要な注意事項

- 既存のCLAUDE.mdやsettings.jsonがある場合は、内容を壊さないようにマージすること
- ファイルを作成・編集する前に、既存の内容を必ず確認すること
- 不明点があればユーザーに質問すること。推測で進めないこと
