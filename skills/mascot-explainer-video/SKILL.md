# マスコット解説動画スキル（Minimax H3スタイル）

参照元動画（ユーザー提供 v1.mp4）の分析から抽出した再現仕様。
**15.1秒 / 1280×720 (16:9横型) / 約24fps / 音声トラックあり / 全編フラットベクター調2Dアニメ**

## 1. 固定レイアウト（全シーン共通・これがスタイルの正体）

```
┌─────────────────────────────────┐
│  【テロップ】大きな白極太ゴシック2行          │
│   キーワードにオレンジ(タン色)の下線          │
│                    ┌──────┐ │
│      【中央アイコン】      │マスコット │ │
│   (時計/吹き出し/禁止/!/🎁)  │ ロボット  │ │
│ ┌────────┐          │(右1/3占有)│ │
│ │PC作業する人物│          └──────┘ │
│ └────────┘(左下固定)              │
└─────────────────────────────────┘
```

- **マスコット**: 白いずんぐりしたロボット。黒いスクリーンの顔＋光る青い目。シーンごとに表情が変わる（笑顔→得意げ→困り顔→大喜び）。指差し・腕組み・プレゼント抱えなどのポーズで感情を演出
- **人物**: グレーパーカーでノートPCに向かう簡略線画の人。左下に常駐（視聴者の分身）
- **テロップ**: 白の極太ゴシック、必ず2行、1行10文字前後。強調語の下にオレンジ色のアンダーライン
- **背景**: 話の局面で色が変わる（後述）。青→ベージュ→ゴールドの転換がトーンの合図

## 2. シーン構成テンプレート（5幕×約3秒）

| 幕 | 時間 | 役割 | 参照元の実例 | 背景色 | マスコット表情 |
|----|------|------|-------------|--------|--------------|
| 1 | 0–1秒 | 登場（テキストなし） | キャラがお辞儀/手を振る | 青グラデ | 笑顔 |
| 2 | 1–4秒 | フック（数字で驚かす） | 「この動画、1時間で作れます」＋時計 | 青グラデ | 笑顔で指差し |
| 3 | 4–7秒 | 方法（シンプルさ訴求） | 「AIに、指示するだけ」＋吹き出し | 青グラデ | 得意げ(目閉じ) |
| 4 | 7–11秒 | ベネフィット/対比 | 「After Effects、もう不要」＋禁止マーク | 青グラデ | 困り顔(旧手法に同情) |
| 5a | 11–13秒 | 正直な注意書き | 「※まだベータ版、文字化けあり」＋！ | **ベージュに転換** | 困り顔 |
| 5b | 13–15秒 | CTA | 「無料配布ページはオープンチャットから」＋🎁 | **ゴールドに転換** | 大喜び |

構成の要点：**フック(数字)→方法→対比→正直な欠点開示→CTA**。欠点開示（5a）を挟むことで宣伝臭を消し、CTAの信頼度を上げている。

## 3. 生成手順

### STEP 1: 台本を作る（無料）
上の5幕テンプレートに沿って、テロップ10文字×2行×5本と各幕のアイコン・表情を決める。
テロップは「数字入りフック」「体言止め」「※付き注意書き」の型を守る。

### STEP 2: 生成エンジン＝**MiniMax H3（正式採用・確認済み）**

利用可能な2経路（どちらも接続確認済み）：

| 経路 | 呼び出し | 対応機能 | 使いどころ |
|------|---------|---------|-----------|
| **① Higgsfield（推奨）** | `generate_video` で model `minimax_h3` | duration 4–15秒 / 2K / 16:9・9:16ほか / batch 1–4 / **start_image・end_image・image_references・video_references・audio_references対応** | 参照動画・参照画像でスタイルを固定できる本命 |
| ② Comfy Cloud | `partner_generate` で model `minimax/hailuo-03-t2v` | duration 5–15秒 / 768P・2K / aspect_ratio / seed / watermark | テキストのみのシンプル生成。アセットライブラリに保存される |

- **参照動画の登録について**: このリモート環境からのファイルアップロード（upload.higgsfield.ai）はネットワークポリシーで遮断されるため、参照元v1.mp4を`video_references`に使う場合は、claude.aiアプリ側のセッションかHiggsfield UIからアップロードして media_id をこのファイルに追記する（記録欄→ `reference_media_id: 未登録`）。**参照なしでも下記STEP 3の詳細スタイルプロンプトで再現可能**
- **日本語テロップの扱い**: 参照元動画自身が「※まだベータ版、文字化けあり」と明記している通り、H3の日本語文字生成は化けやすい。テロップ込みで生成→化けたシーンのみseed変更で再生成。確実性を優先する日は文字なし生成＋後付けテロップ合成に切り替え
- いずれも**クレジット消費のためユーザー承認後に実行**。承認前は台本とプロンプトの提示まで。15秒1本を丸ごと生成（シーン分割せず1プロンプトに5幕を時系列で記述）するのがH3の尺仕様（4–15秒）に合う

### STEP 3: シーン別生成プロンプト（コピペ用テンプレート）

```
flat vector 2D motion graphics explainer animation, minimal clean style.
A chubby white robot mascot with a black screen face and glowing blue eyes
[表情: smiling / proud closed-eyes / worried frown / overjoyed], [ポーズ: pointing left /
crossing arms / hugging a gift box], standing on the right third of the frame.
A simplified line-art person in a gray hoodie typing on a laptop, fixed at bottom left.
Center icon: [clock / speech bubble with sparkles / prohibition sign over an app icon /
exclamation mark in circle / gift box].
Background: [smooth blue-purple gradient / warm beige / gold gradient].
16:9, 1280x720, smooth subtle character animation, no camera movement, 3 seconds.
(ルートAのみ追記) Bold white Japanese headline text on the left: "【1行目】【2行目】"
with an orange underline under the keyword.
```

### STEP 4: 検証チェックリスト（納品前に必ず）
1. テロップの文字化け・脱字がないか（ルートAは1文字ずつ目視）
2. マスコットのデザインが5シーンで同一か（顔・体型のブレ＝別キャラ化に注意）
3. 背景色の転換（青→ベージュ→ゴールド）が幕の切り替わりと一致しているか
4. 無音でも意味が通るか（音声なし再生で確認）
5. 尺が15秒±1秒に収まっているか

## 4. お土産お菓子研究所での使い分け

- **このスキル（15秒・横型・解説）**: サービス告知、Grok/AI活用法の解説、キャンペーンCTA
- **Daily Sweetsベスト10（10秒・縦型・ランキング）**: `workspace/daily-sweets-best10/README.md` 参照。別スキル
- マスコットは「研究所の白衣ロボット」等に差し替え可（STEP 3のキャラ記述を変更）。一度決めたら全動画で固定し、アカウントの識別子として育てる

## 5. 制約・未確認事項

- 参照元動画の音声トラック（BGM/ナレーションの有無・内容）は本環境では解析未実施。音声を再現する場合はユーザーに内容を確認すること（H3は`audio_references`にも対応しているため、音声ファイルがあれば参照可能）
- リモート実行環境からはHiggsfieldへの直接ファイルアップロードが遮断される。参照動画・参照画像の登録はclaude.aiアプリ側セッションかHiggsfield UIで行う
