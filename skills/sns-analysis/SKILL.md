# SNS分析スキル（sns-analysis）

企業・ブランドについて、**実測データに基づくSNS競合分析と提案書を自動生成**するスキル。

---

## 🎯 **このスキルの目的**

単なる「SNS の使い方」ではなく、以下を実現します：

- ✅ **実測データで信用を取る** — 推測ではなく、公開情報から数えた具体的な数字
- ✅ **空白ポジションを特定** — 競合が埋まっていて、自社が入れる隙間を見つける
- ✅ **提案書を自動生成** — 分析結果を HTML フォーマットの提案書に即変換
- ✅ **ビジネスロジック重視** — 数字だけでなく、それが何を意味するかまで言語化

---

## 📋 **使用方法**

### **基本的な使い方**

```
/sns-analysis
→ 企業名や商品名を入力
→ 分析パラメータを確認
→ 自動分析実行
→ HTML提案書 + JSON分析データを生成
```

### **指定可能なパラメータ**

ユーザーが以下を入力できます：

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| `company_name` | 企業名またはブランド名 | 菓匠三全 / 萩の月 |
| `target_sns` | 分析対象SNS | X / Instagram / note / YouTube / all |
| `output_format` | 出力形式 | html / json / markdown |
| `include_competitors` | 競合企業を含めるか | true / false |

---

## 🔍 **分析プロセス**

### **Phase 1: データ取得**

以下のデータを取得します：

- **X**: フォロワー数、投稿数、表示数、エンゲージメント
- **Instagram**: フォロワー数、投稿数、更新頻度
- **note**: 公開アカウントの有無、投稿数、社名/商品名の言及数
- **YouTube**: チャンネル登録者、動画数、再生数

### **Phase 2: 比較分析**

取得したデータを以下の視点で分析します：

1. **フロー vs ストック**
   - フロー（流れる媒体）: X, Instagram
   - ストック（蓄積する媒体）: note, YouTube
   - バランスの診断

2. **自社コンテンツ vs 第三者言及**
   - 社の投稿数 vs 社外からの言及数
   - コンテンツの質（伸びやすい投稿型）

3. **競合比較**
   - 同業他社との投稿数・フォロワー比較
   - 戦い方の違い

### **Phase 3: 空白ポジション特定**

以下を明示します：

- すでに埋まっているポジション
- 競合が走っているが後発に厳しいポジション
- **小さいが勝ちやすいポジション** ← ここを狙う
- 明らかに空いているポジション

### **Phase 4: 提案書生成**

自動的に以下を含む HTML 提案書を生成：

- エグゼクティブサマリー
- 現状分析（数字＆テーブル）
- 特定した課題（3〜5個）
- ご提案内容
- 進め方（Phase ごと）
- 成果の測り方
- 費用感（テンプレート）

## 📊 **出力フォーマット**

### **HTML 提案書**

美しく印刷可能な HTML ドキュメント：
- ダークモード対応
- 数値は表形式で整理
- グラフ・チャート含む
- 手元のファイルとして保管可能

```json
  "recommendation": { ... }
}
```

## ⚙️ **技術仕様**

### **データ取得方法**

- **公開 API**: note 検索 API、YouTube Data API（キー必要）
- **Web Scraping**: Bright Data、yt-dlp（落ちる場合は代替案提示）
- **公開情報**: 企業サイト、採用情報サイト、Wikipedia

### **推測と事実の分離**

- **事実**：取得したデータ、外部ソースの引用
- **推測**：「このアカウントは強く見えるが〜」など（推測と明記）
- **未確認**：記事に書く前に要確認の項目をリスト化

---

## 🛡️ **使用上の注意**

### **やること**

- ✅ 公開情報だけを使う
- ✅ 推測は推測と明記する
- ✅ 未確認情報を断定しない
- ✅ 事実と推測を明確に分ける
- ✅ 出典を必ず記載する

### **やらないこと**

- ❌ 非公開情報を使う
- ❌ ログインが必要な情報を取得する
- ❌ 個人 SNS を無断分析する
- ❌ 競合企業の内部情報を使う
- ❌ 仮説を事実として書く

## 🚀 **よくある質問**

### **Q: 競合他社の分析もできる？**

A: はい。ただし「名前を公開する」「営業資料に使う」など用途によって、倫理的配慮が必要です。このスキルは事実の整理であり、その使い方はユーザーの責任です。

### **Q: 更新頻度は？**

A: 実行するたびに最新の公開情報を取得します。月 1 回の定期実行もできます。

### **Q: API キーは必要？**

A: note・YouTube など一部で必要になる場合があります。初回実行時に案内します。

### **Q: 結果をそのまま提案書に使える？**

A: 使えます。ただし企業名・数字・出典は必ず確認してください。このスキルは「叩き台」であり、最終確認はユーザーの責任です。
