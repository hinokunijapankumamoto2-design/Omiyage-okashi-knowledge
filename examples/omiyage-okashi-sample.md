# 業界特化ユースケース集

お土産お菓子業界での `/second-brain` 活用事例。

## ユースケース 1: 競合商品分析の自動化

### 状況
新商品企画のため、同価格帯の競合商品を調査したい。

### 投入データ（`raw/`）
- 競合メーカーの商品ページをテキストコピペ（10社分）
- 商品レビューサイトのコメント抜粋
- 店頭でのPOPや陳列写真の撮影メモ

### 実行
```
> /second-brain
「raw/ 内の競合商品データを整理して、価格帯・主要素材・パッケージ傾向・ターゲット層別にwikiにまとめて」
```

### 生成される `wiki/` の例
- `wiki/競合分析_ガトーショコラ系.md`
- `wiki/競合分析_パッケージ傾向_2026.md`
- `wiki/競合分析_価格帯_1000円台.md`

## ユースケース 2: 観光客動向の継続トラッキング

### 状況
インバウンド復調に合わせて、観光客の購買動向を月次で把握したい。

### 運用
毎月、以下を `raw/` に投入：
- 観光庁の宿泊旅行統計（PDF抜粋）
- 空港免税店の売上レポート
- 自社EC（越境）の販売データ（匿名化）

```
> /second-brain
「先月投入した観光客動向データを既存wikiに統合して、前月比・前年同月比も出して」
```

### 継続運用効果
月を追うごとに時系列データが `wiki/観光客動向/` に蓄積され、**トレンドの可視化が自動化**される。

## ユースケース 3: 商品企画書の一括生成

### 実行

### 出力先

## ユースケース 4: バイヤー用の判断基準FAQ

### 状況
新人バイヤーが過去の商品選定基準を学びたい。

### 投入データ
- ベテランバイヤーへのインタビュー音声→テキスト化
- 過去5年の商品選定会議議事録
- 実際に売れた/売れなかった商品の分析レポート

### 質問例
```
> この商品を入荷すべきか判断したい。
> 原価率35%、ターゲットは30-40代女性、地域性は熊本、賞味期限45日。
> 過去の類似ケースをwikiから引いて、判断材料を教えて。
```

AIは `wiki/` を横断検索し、類似事例と判断基準を提示。

## ユースケース 5: 法規制・地域団体商標チェック

### 状況
新商品のネーミング・表示が食品表示法や地域団体商標に抵触しないか確認したい。

### 投入データ
- 食品表示法の該当条文（消費者庁サイトから）
- 地域団体商標の登録一覧（特許庁J-PlatPat検索結果）
- 過去の指摘事例・是正事例

### 質問例
```
> 商品名「博多あまおう苺ロマン」で熊本県産苺を使う場合、
> 地域団体商標と景品表示法の観点でリスクは？
```

AIは `wiki/法規制/` を参照し、リスクと代替案を提示。

## Tips: 業界特化の活用を加速する

### `raw/` 投入の推奨ソース
- 観光庁・農林水産省の統計PDF
- 帝国データバンク・東京商工リサーチの業界レポート抜粋
- 競合のプレスリリース（PR TIMES等）
- 業界誌（『製菓製パン』『お菓子読本』等）の記事
- 自社のPOS売上データ（CSVを抜粋）
- 店舗オペレーションの反省メモ

### ヘルスチェックの業界特化項目
月次チェック時に以下も確認するよう指示：
- 市場動向データの **季節性補正** がされているか
- 地域・県別情報が **混在していないか**
- 価格情報が **税込/税抜** 明記されているか
- 観光需要データの **国内/インバウンド区分** が明確か
