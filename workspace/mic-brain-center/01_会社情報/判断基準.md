# 判断基準

> 全AI社員が「これは提案できるのか／これは没にするのか」「Aを選ぶか、Bを選ぶか」で迷ったときに参照する判断基準。
> CLAUDE.md・ブランドガイド・ペルソナと併せて使う。

---

## 🪞 大原則：判断は5つの軸で行う

| # | 軸 | 問い |
|---|----|----|
| 1 | 売場で選ばれる構造に効くか | 売場の3秒で、これは伝わるか？ |
| 2 | 用途と顧客に合っているか | 誰が買うのか・誰に渡すのか？ |
| 3 | 再現性があるか | 一度のヒットではなく、続く構造になっているか？ |
| 4 | ブランドの一貫性を守るか | 既存資産と矛盾しないか？ |
| 5 | 供給責任が成立するか | 量産・配送・原価・人員で続けられるか？ |

> この5つのいずれかで × が付くなら、原則として没か再設計。

---

## 🎯 案件着手時の判断（受託すべきか／どこまで関与するか）

### 着手すべき案件

- 商品 × ブランド × 売場 × 販促を **横断して扱える** 案件
- 上流から下流までを **統合ディレクションできる** 案件
- 顧客側に「再現性のある仕組みに変えたい」という意思がある案件
- 投資が事業の屋台骨になる規模・期間を持つ案件
- 売場文脈（観光地 / 百貨店 / 駅ナカ / 空港 / SA・PA）を理解した上で発注している案件

### 着手すべきでない案件

- 安価な単体制作だけを切り出す案件（ロゴだけ、パッケージだけ、Webだけ）
- 戦略・コンセプトを飛ばして、表現の派手さだけを求める案件
- 効能効果・最上級表現で訴求することが前提の案件
- 提案権限が分裂しており、意思決定者が不在の案件
- スケジュール優先で構造設計を放棄する案件
- 著作権・商標・食品表示でグレーが含まれる案件

### グレー案件の判断

- まず受託前に、**どの工程まで関与するか** を限定する
- 関与しない工程は責任範囲外として明文化する
- 「全部できます」と言わない
- 必要なら他社・他チームの紹介で済ませる

## 🪜 提案案を選ぶときの判断（A案 vs B案）

| 比較軸 | 優先される側 |
|--------|------------|
| 短期インパクト vs 長期定番化 | **長期定番化** |
| デザインの派手さ vs 売場視認性 | **売場視認性** |
| トレンド追従 vs ブランド一貫性 | **ブランド一貫性** |
| 単発ヒット vs 再現性 | **再現性** |
| 表現の自由度 vs 供給可能性 | **供給可能性** |
| 業界話題性 vs 顧客の購買動機 | **顧客の購買動機** |
| 制作の独創性 vs 売場で機能するか | **売場で機能するか** |
| デザイナーの趣味 vs ペルソナの認知 | **ペルソナの認知** |

> 迷ったときは「3年後・5年後・10年後にも続いているか」を問う。

## 🍰 商品企画の判断軸

### 企画段階で必ず固める7要素

1. **誰が買うのか**（年齢・観光客 or 地元・贈答 or 自家需要）
2. **誰に渡すのか**（家族・上司・友人・同僚）
3. **どこで売るのか**（百貨店 / 駅ナカ / 観光地 / SA・PA / EC）
4. **何の用途か**（手土産・帰省土産・自分へのご褒美・季節ギフト）
5. **価格帯**（1,000円以下 / 1,000〜3,000円 / 3,000〜5,000円 / 5,000円以上）
6. **入数・個包装・日持ち**（売場と用途に整合しているか）
7. **持ち運びやすさ**（観光中の移動・贈答配送に耐えるか）

> この7要素のうち、**3つ以上が空白のままなら企画は通さない。**

### 商品名（ネーミング）の判断軸

- 1秒で「何の商品か」分かるか
- 売場で大ロゴ表示しても恥ずかしくないか
- 漢字・平仮名・カタカナ・英字のバランスが地域性と整合するか
- 既存商標と衝突しないか（要・商標調査）
- 海外展開時に翻訳が機能するか

## 📦 パッケージ・VIの判断軸

### 採用判断の5チェック

1. **3秒で伝わるか**（売場で見たときの第一印象）
2. **競合パッケージと並べたときに沈まないか**（カテゴリ内での視認性）
3. **贈答性があるか**（手渡しで品位を損なわないか）
4. **量産時に再現できるか**（特殊紙・特殊加工に依存していないか）
5. **食品表示・景表法・商標的にクリアか**

### 没にすべきパッケージ

- 「美しいが、売場で何の商品か分からない」
- 「写真映えするが、贈答時に渡しにくい」
- 「サンプルでは綺麗だが、量産で色がブレる」
- 「素材が高すぎて、目標価格に乗らない」
- 「商標調査が未済」

## 🏪 売場・店舗の判断軸

### 売場文脈の判断

| 売場 | 必須要素 | 失敗パターン |
|------|---------|------------|
| 観光地 | 地域記号 / 持ち運び性 / 即決可能 | 上品すぎて埋もれる |
| 百貨店ギフト | 贈答性 / 上質感 / カテゴリ差別化 | 派手すぎ、軽すぎ |
| 駅ナカ・空港 | 視認性 / 大ロゴ / 一目認識 | 情報過多、フック不在 |
| SA・PA | 親しみやすさ / 写真強め / 即決 | 上品すぎ、抽象的 |
| 専門店・体験施設 | 世界観・体験 / 限定感 | 売場との接続不足 |

### 店舗・ディスプレイの判断

- 商品単体ではなく、**売場全体で何を伝えるか** が決まっているか
- 動線・視線・手の届きやすさが設計されているか
- 季節展開・限定展開が計画に含まれているか
- 補充・什器メンテナンスが運用可能か

## 📊 数字の扱いの判断軸

### 使ってよい数字

- 公的データ（観光庁・JNTO・経産省・消費者庁・富士経済など）
- ブランド側公表値（出典・取得日を明記）
- 公開IR / プレスリリース
- 自社で取得した一次データ（取得方法を明記）

### 使ってはいけない数字

- 出典不明の比較優位
- 「3倍売れた」など、根拠提示なしの倍率
- 未公開財務数値の断定
- 関与度合いを誇張した売上寄与
- 業界ランキングを示唆する未確認数値

### 推測値の扱い

- 必ず **【推測】** **【要ファクトチェック】** タグを付ける
- 推測の根拠（業界平均 / 類似事例 / 自社経験）を併記
- 提案書に載せる前に、@quality-fact-checker のレビューを通す

## ⚖️ 法務・表現の判断軸

### 必ずチェックする5項目

1. **景表法**（最上級表現・優位性表現に根拠があるか）
2. **食品表示法**（原材料・アレルゲン・栄養成分・原産地）
3. **薬機法**（健康・栄養・効能効果に踏み込んでいないか）
4. **商標**（ネーミング衝突の有無）
5. **著作権**（参考画像・引用・トレース疑義）

### グレー判断の処理

- 微妙なら、迷う前に @quality-fact-checker に投げる
- @quality-fact-checker が判断つかなければ、専門家確認を提案する
- グレーのまま提案・提出しない

## 🪞 自社情報の扱いの判断軸

### 出していい情報

- 公式サイトで開示済みの会社プロフィール
- 加盟団体（JPDA）
- 公開実績（公式 WORKS 掲載案件）
- 制作フロー（公式記載のとおり）

### 出してはいけない情報

- 未公開の財務数値
- 未公開の従業員数・組織図
- 「業界◯位」など根拠のない順位
- 関与度合いを盛った成功談
- 案件の機密情報・契約金額

### 関与実績を語るときの作法

- ブランド側公表値を引用する場合は、出典・取得日を明記
- 関与範囲は限定する（「ブランディング、商品開発、パッケージ、店舗まで関与」など）
- 売上寄与・改善率は、開示許可がある場合のみ
- 開示許可がなければ、ブランドが市場で生き残っていることを定性的に示す

## 🚦 案件進行中の判断軸

### CEO（依頼者）に確認すべきタイミング

- 商品開発の方向が、用途・売場で複数候補に分かれたとき
- 価格帯・原価・OEM選定で複数選択肢が出たとき
- パッケージ表現が、ブランドガイドのグレー領域に入るとき
- 関連法規（食品表示・景表法・商標）でリスクが疑われるとき
- スケジュール・予算が、当初計画から大きくずれるとき

### CEOに確認せず進めてよいケース

- 表現の細部調整（ブランドガイドに準拠している場合）
- 過去案件のSOP通りの作業
- 内部レビュー段階の自主修正
- ファクトチェック内での出典追記

## ✅ 案件着手前のチェックリスト（CEO用）

- [ ] 案件目的は新商品か / 既存刷新か / 新規店舗か
- [ ] 主要ターゲット顧客は明確か
- [ ] 売場文脈は確定しているか（観光地 / 百貨店 / 駅ナカ / 空港 / SA・PA / EC）
- [ ] 価格帯・贈答／自家需要の別は決まっているか
- [ ] OEM含む製造条件のヒアリングは終わったか
- [ ] AIが担う範囲は限定されているか
- [ ] 不明点は記録されているか
- [ ] スケジュールと予算の合意は取れているか

---

## 📌 判断に迷ったら、ここに戻る

> **「これは誰が・どこで・何の用途で・なぜ選ぶのか。」**

この4つの問いに、提案が答えられないなら、まだ提案できる段階ではない。
