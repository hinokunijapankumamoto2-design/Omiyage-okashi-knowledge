# ペルソナ

> 全AI社員の提案・原稿・販促コピー・営業資料は、このペルソナに向けて書く。
> 主要顧客は「土産菓子メーカー経営者・商品企画責任者・ブランド責任者・営業責任者」。

## 🪪 第一ペルソナ：土産菓子メーカーの経営者・後継者

### 基本情報

| 項目 | 内容 |
|------|------|
| 仮名 | 田島 浩一 |
| 年齢 | 52歳 |
| 役職 | 代表取締役 / 二代目もしくは三代目 |
| 会社規模 | 従業員30〜200名 / 年商10〜80億円規模の地方菓子メーカー |
| 拠点 | 京都・北海道・福岡・愛媛など、地方の菓子業界 |
| 経歴 | 親元の家業に入社し、製造・営業を経て経営。MBAや戦略コンサル経験は無いが、現場勘は厚い |
| 家族構成 | 既婚・子ども2人。家族経営に伴う心理的責任が大きい |

### 抱えている悩み（3つ）

1. **既存定番の売上が静かに落ちている**
   - 観光地の定番商品が、コロナ後の客層変化で構造的に落ち始めた
   - 値上げで粗利は守れても、客単価ベースで「選ばれにくくなっている」
   - 数字には出るが、何が原因か言語化できない

2. **「次の柱」を作る方法が分からない**
   - 社内にはレシピ開発はある
   - だがブランディング・売場戦略・パッケージ・店舗設計を統合的に考える人材がいない
   - 外部に頼むと、デザイン会社は意匠だけ、コンサル会社は戦略だけで分断する
   - 「全体を一気通貫で設計してくれる相手」を探している

3. **属人化しすぎていて、引き継げない**
   - 創業者・先代の感性で売れてきた商品が多い
   - 後継者として、再現性のある仕組みに変えたいが、誰に相談していいか分からない
   - ブランド資産として残したいが、形にできていない

### 内面の声（言葉にしてないけど思っていること）

- 「いい商品なのに、売場で負けている気がする」
- 「うちのブランドは、結局なんなのか言語化できない」
- 「外部にいろんな会社に頼んできたが、毎回違う絵が出てきて統一感がない」
- 「デザインだけ綺麗にしても売上は変わらなかった」
- 「百貨店バイヤーに刺さる説明が、社内でできる人間がいない」
- 「もう一度、ゼロから商品を作るとしたら、何を作ればいいのか分からない」
- 「先代と同じやり方では、もう続かないと感じている」
- 「自分が引退するまでに、もう一つ定番を作りたい」
- 「価格競争に巻き込まれずに、長く売れる構造を作りたい」

### 達成したいこと（理想の未来）

1. **20年売れる定番商品を、もう一本作る**
   - 単発ヒットではなく、組織の屋台骨になるブランド
   - 京ばあむや東京ばな奈のような、長く売れる構造
2. **属人的判断を、再現可能な仕組みに変える**
   - 自分が引退しても続くブランド資産化
3. **百貨店・駅ナカ・空港・観光地で「選ばれる構造」を持つ**
   - 売場で3秒で伝わる商品とブランド
   - 贈答適性・配布性・地域性が一体化した設計

### 反応しない言葉・嫌う表現

- 「絶対売れる」
- 「ヒット確実」
- 「日本一」「世界一」
- 「最強パッケージ」
- 「神デザイン」
- 「インスタ映え一発」
- 「とにかくおしゃれにします」
- 「とりあえず若者向けに」
- 「これがトレンドです」（根拠なし）
- 「全部こちらに任せてください」（実態見えず）

### 嫌う理由

このペルソナは、すでにいくつもの外部発注を経験し、表層的な"おしゃれ提案"に失望している。
**派手な絶賛や万能感のある提案ではなく、現場と数字に降りた説明**を信頼する。

### 反応する言葉・刺さる訴求

- 「売場で3秒で伝わる構造」
- 「贈答適性のあるパッケージ」
- 「20年続くブランドの設計図」
- 「商品・ブランド・売場・販促を一気通貫で」
- 「定番化を狙う設計」
- 「再現性のある成功パターン」
- 「属人的判断を、組織資産にする」
- 「先代のブランドを、現代の文脈で翻訳する」
- 「京ばあむ型 / フェルム型 / REICACAO型」（具体事例で語る）
- 「OEM・自社製造・委託製造の選択を、用途と売場から逆算する」

## 📐 価格帯感覚

| 投資額 | 心理 |
|--------|------|
| 〜50万円 | 単発デザイン費としてはあり |
| 100〜300万円 | パッケージ刷新 + ロゴ刷新ならあり |
| 500〜1,000万円 | ブランド再構築・リニューアル予算として通せる |
| 1,000万〜数千万円 | 新ブランド立ち上げ・新規店舗込みなら通る |
| 数千万〜億 | 関連事業全体の改革プロジェクト規模で稟議化 |

決め手は「金額の大小」ではなく、**「投資が事業の屋台骨になるか」**。
表層的な数百万案件は迷うが、**長く売れる構造を作る投資**には腹を括る。

## 🔄 カスタマージャーニー（見込み客 → 受注）

```
他社案件 / 業界の口コミで認知
   ↓
公式サイトで実績確認（京ばあむ、東京ばな奈、N.Y.C.SAND、フェルム ラ・テール美瑛）
   ↓
「この会社なら統合できそう」と直感
   ↓
問い合わせ
   ↓
ヒアリング（自社の本当の課題が言語化されていく）
   ↓
概算見積
   ↓
複数案を見せられず、一つの統合案として提案される
   ↓
社内稟議（事業承継 / 中期経営計画と紐づけて通す）
   ↓
契約
   ↓
ブランド開発 → 商品開発 → デザイン → 売場 → 発売 → 運用フォロー
```

| 段階 | 進める要素 | 離脱要素 |
|------|----------|---------|
| 認知 | 「商品開発から入る」「ゼロベースで設計」「定番化実績」 | 単なるパッケージ会社・デザイン会社の見え方 |
| 実績確認 | 京ばあむ・東京ばな奈・N.Y.C.SAND の関与 | 食品系の実績が薄い、表層的な制作物だけ並ぶ |
| 問い合わせ | 「商品から店舗まで一気通貫」と即理解できる説明 | サービス範囲が断片的に見える |
| ヒアリング | 売場・贈答・OEMまで踏み込んで聞いてくる | 「コンセプト」「世界観」だけで終わる質問 |
| 提案 | 表現と構造の一体化、用途・売場文脈の具体性 | 抽象論、参考画像羅列、根拠不明な数値 |
| 稟議 | 投資が事業の屋台骨になることを示す、リスクと対策の明示 | 効果数値の誇張、保証なき断言 |

## 🪞 ペルソナの深層心理

このペルソナは、表向きには
**「いい商品を作りたい」**
と言っている。

しかし本音は違う。

本当は、

> **「自分の代で、もう一本、長く売れる定番を残したい」**

もっと深く言うと、

> **「先代から受け継いだブランドを、自分の代で確実に次に繋ぎたい」**

だから、単なるパッケージ刷新では満足しない。
"おしゃれにすること"ではなく、**長く残るブランド資産を作ること** を求めている。

## 🧩 第二ペルソナ：商品企画責任者 / 商品開発部長

### 基本情報

| 項目 | 内容 |
|------|------|
| 仮名 | 西村 早苗 |
| 年齢 | 43歳 |
| 役職 | 商品企画部長 / 商品開発マネージャー |
| 関心 | 売れる新商品の企画 / OEM管理 / 試作回転 / 売場との接続 |

### 抱える悩み

1. アイデアはあるが、市場で勝てる切り口に絞れない
2. パッケージ・売場・販促との連携が後手になり、統一感が出ない
3. OEMと自社製造の選択を、コスト以外の判断軸で決めきれない

### 内面の声

- 「上から『次のヒットを』と言われるが、ヒントが少ない」
- 「自社内のメンバーだけだと、視点が偏って商品が似てくる」
- 「OEM工場の都合に引っ張られて、本来の構想が薄まる」

### 反応する訴求

- 「商品 × 売場 × 用途を、最初から接続して設計する」
- 「OEM選定の前に、商品の核を決める」
- 「試作の前に、勝ち筋を絞る」
- 「売場視認性と贈答適性を商品仕様に組み込む」

## 📌 ペルソナを描くうえで、AI社員に守ってほしいこと

1. **デザイン用語で煙に巻かない**
   - 「ブランド世界観」「コンセプチュアル」「ストーリーテリング」だけで終わらせない
   - 必ず、用途・売場・配布性・価格帯・地域性に降ろす

2. **上から目線で教えない**
   - ペルソナはAI初心者ではない。マーケ初心者でもない。事業経験は厚い
   - 「教える」のではなく「整理する」「言語化する」「翻訳する」

3. **甘い夢を見せない**
   - 「絶対売れる」「ヒット確実」は使わない
   - 代わりに「定番化を狙える構造」「再現性のある勝ち筋」と言う

4. **デザイン提案の前に、構造を整理する**
   - 「こんなパッケージが映えます」より先に「誰がどこで何の用途で買うのか」

5. **数字は出典付きで使う**
   - ブランド側公表値は明記
   - 推測は推測と記載
   - 未公開数値は断定しない

6. **最後は必ず、相手が何をすればいいか分かる形で終える**
   - 「次のCEOアクション」を必ず示す

## 最重要メッセージ

このペルソナに刺さる核心はこれ。

> **「いい商品を作るだけでは、もう売れません。
>   売れる構造を、商品・ブランド・売場・販促まで一体で設計したときだけ、長く続くブランドになります。」**

この一文を、すべての提案・原稿・営業資料・LP・販促コピーの中心思想に置く。
