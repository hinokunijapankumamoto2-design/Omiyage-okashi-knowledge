# 江戸ひとくち 店舗・売場提案 v1

> 本提案は **パッケージA（江戸品格）/ B（江戸を裏切る）の意思決定が確定する前** の中立的な売場フレーム。
> どちらの選択でも機能する **共通の売場構造** を設計し、選択後に意匠を分岐させる方針。
> ただし最後に **A採用時 / B採用時 の演出差分** を明記する。

---

## 1. 提案サマリー（3行）

- **売場で達成したいこと**：N.Y.C.SAND（10年連続1位）と並ぶ、東京駅の **新たな長寿土産** ポジションを売場で立ち上げる
- **採用する型**：京ばあむ型（旗艦 + 大ロゴ手提げ袋による歩行広告）+ atelier京ばあむ型（中長期での体験施設化を視野）
- **核となる演出**：**6種が一目で並ぶ壁面陳列** × **試食ピース** × **季節限定の更新サイン**

## 3. 売場の核となる演出（5層構造）

### 層1：3秒視認のフック

- 売場前面に **大ロゴ「江戸ひとくち」**（A: 筆文字 / B: Helvetica Neue Black）
- ロゴ高さ：30cm以上、視認距離10m以上を担保
- 通行人が **3秒で売場の存在を認識** できる

### 層2：6種を一目で見せる壁面陳列

- 横長壁面に **6種すべてを並列展示**
- 各種類のパッケージ + 試食ピース1個 + 説明カード
- 「江戸の素材を6種のひとくちに」が一目で伝わる構成
- A・B どちらでも、**6マスのグリッド** が共通フォーマット

### 層3：試食ピースの体験

- ガラスケース内に **6種の試食ピース** を1個ずつ
- スタッフが **「どの素材から食べてみますか」** と声かけ
- 試食 = 説明 = ブランド理解の3点セット

### 層4：3SKU（S/M/L）の購入導線

- 壁面陳列の手前に S（8個入）/ M（12個入）/ L（16個入）を3列展示
- 価格札を **「S 1,728円・M 2,484円（人気）・L 3,240円（贈答）」** と用途別に表示
- 試食 → 「これいいな」→ サイズ選択の自然な動線

### 層5：季節限定の更新サイン

- 壁面横に **「次の節気まで○日」** のカウントダウン演出
- 季節限定（年4回更新）のタイミングで **店頭サインリニューアル**
- リピーターに「次に来た時の楽しみ」を作る

## 5. 動線・視線・手の届きやすさ

### 5-1. 通行人視点での動線

```
通行（10m先）→ 大ロゴ視認 → 「6種が並ぶ壁」が目に入る
   ↓
売場前で立ち止まる → 試食ガラスケースに目が行く
   ↓
スタッフ「どの素材から食べてみますか」声かけ
   ↓
試食 → S/M/L から選択 → 購入
```

### 5-2. 視線の高さ

| 高さ | 内容 |
|------|------|
| 180cm | 大ロゴ・ブランドサイン |
| 140-160cm | 壁面陳列（6種一覧） |
| 100-120cm | 試食ガラスケース |
| 80-100cm | S/M/L SKU 陳列 |
| 60-80cm | 季節限定サイン・カウントダウン |

### 5-3. 手の届きやすさ

- 商品取り出しは **スタッフ介在型**（カウンター越し）
- セルフ陳列は実装しない（盗難防止 + 接客機会の確保）

## 6. 体験要素（中長期：atelier 京ばあむ型展開）

> 立ち上げ12ヶ月後の **「店舗 + 体験」** 拡張案

### 6-1. 試食バー

- 売場奥に2-3席の試食バー
- 6種食べ比べセット + お茶（焙じ茶 / 煎茶 / 抹茶）
- 価格：1,200円程度
- **「江戸の食卓体験」** として外国人観光客も取り込む

### 6-2. 季節限定の節句菓子

- 端午（5月）/ 七夕（7月）/ 重陽（9月）/ 雛（3月）の節句限定菓子
- 通常6種 + 節句限定2種で **「日本の暦を体験する売場」** に拡張

### 6-3. ECとの連携

- 売場で QR コード経由で EC 登録
- 季節限定の事前案内 → 物流的なリピート喚起
- A 採用時：和の品格 EC（落ち着いたUX）
- B 採用時：高級電機系 EC（Apple型 UX）

## 7. 都心スペースへの凝縮（百貨店・大丸東京店）

百貨店の限定スペース（3-5坪）でグランスタの世界観を凝縮するには：

| 凝縮要素 | 仕様 |
|---------|------|
| 必須要素 | 6種壁面陳列 + 大ロゴ + L（16個入）/ 季節BOX 24個入 |
| 省略可能 | 試食バー（百貨店では不要・グランスタ旗艦のみ） |
| 強調要素 | 季節BOX 24個入を **中元・歳暮シーズンの顔** に |

## 8. 補充・運用観点

### 8-1. 補充負荷

| サイクル | 内容 |
|---------|------|
| 日次補充 | 試食ピースの入れ替え（朝・夕） |
| 週次補充 | S/M/L 在庫補充 |
| 月次補充 | 壁面陳列のクリーニング |
| 季節補充（年4回）| 限定SKU の入れ替え + 店頭サイン更新 |

### 8-2. スタッフ運用

- 平日：2名（接客 + バックヤード）
- 土日祝：3名（試食バー対応）
- 全員が **6種の素材ストーリー** を5分で説明できる教育

### 8-3. 在庫管理

- 1日販売想定：300〜500個（M箱換算）
- バックヤード在庫：3日分
- グランスタ周辺の倉庫から日次補充
