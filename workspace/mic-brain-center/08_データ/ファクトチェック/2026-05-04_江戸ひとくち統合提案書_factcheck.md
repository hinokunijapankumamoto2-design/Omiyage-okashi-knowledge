## 🟣 常識の壁・逆チェック（CEO の問いに直接答える）

### 逆チェック1：これは本当にグランスタの売場で通るか？

#### 通る根拠

- グランスタは「東京駅でしか買えない限定品」を強く好む（駅ナカ最大級の改札内）
- 6種パッケージは視覚記号として強い（オードリー グレイシアの拡張版）
- 二重シェル意匠は前例が少なく、出店審査時の「新規性」評価が高い

#### 通らない可能性のある懸念

| 懸念 | 評価 |
|------|------|
| **5-8坪の売場面積** | グランスタの新規出店は **2-3坪が多い**。8坪は大型枠で審査難度が高い。**3-5坪スタートを推奨** |
| **試食バー（中長期）** | グランスタは衛生管理上、**試食バーが原則不可** の場合が多い。試食ピース1個運用に限定する前提で計画 |
| **蛍光色の什器** | 駅ナカ全体の意匠調和（黒・白・木調が主流）の中で、B案の白アクリル × 蛍光色は **異質と判断され不採用** の可能性 |

#### 修正提案

- 売場提案を **「グランスタ先行は3坪 + A路線什器」**、 **「大丸東京店は5坪 + 二重シェル意匠」** に分離
- グランスタは案A（江戸品格）の什器、大丸は二重シェル戦略
- B（裏切り路線）は **EC + 期間限定POP** で先行展開し、市場反応を見て売場展開

### 逆チェック2：江戸を裏切る方が、むしろ江戸が際立つのではないか

#### 「裏切りで際立つ」という前提への厳格チェック

提案書では **「江戸の精神（粋・見立て・型破り）」 = 「現代の蛍光色・英字・QR的幾何」** と論理化している。
しかし、これが顧客の理解として成立するかは別問題。

#### 検証ポイント

| 検証項目 | 評価 |
|---------|------|
| **論理は成立するか** | ◯：江戸庶民が藍摺り・浮世絵で当時最先端の色彩を使ったのは事実。「裏切り = 江戸」の論理は史実に立脚 |
| **顧客に伝わるか** | ✗：50代以上のビジネス層に **「江戸の精神」「見立て」を5秒で説明できない**。一般顧客は「ふざけている」と判断する可能性が高い |
| **店頭スタッフが説明できるか** | ✗：複雑な思想を5分で説明する必要があり、**接客難度が高い** |
| **商品単独で意図が伝わるか** | △：表箱だけ見ると伝統、開けてようやく裏切りに気づく構造で、**衝動買い時には伝わらない** |

#### 結論：「裏切り」は **論理的には正しいが、顧客理解としては危険** な構造

#### 修正提案

1. **B案単独採用は推奨しない**（顧客理解が成立しない）
2. **二重シェル戦略**（A表+B裏）は推奨条件付きで成立する
   - 表箱（A）に「江戸の手土産」が読めるよう **キャッチコピーで補強**
   - 「江戸の見立て」の説明カード（A4両面）を1箱に同梱
   - 店頭スタッフ向け **5分の接客スクリプト** を `04_セールス` 系に整備
3. **EC・期間限定POP** で B 単体の市場反応を先に確認 → 売場展開判断

### 逆チェック3：そもそも「対立構造の二重シェル」は実現可能か

#### 製造面の現実性

| 項目 | 評価 |
|------|------|
| 表箱A + 個包装B の同時設計 | ◯：技術的には可能 |
| OEM工場での量産 | △：**蛍光インクの食品包装対応工場は限定的**。@product-planner と要協議 |
| 原価増加 | ✗：A単独より **15-25%増の可能性**。原価率が28-32%から33-40%に悪化する見込み |
| 賞味期限20日 | △：蛍光インク（一部）には **食品安全規格の制約** あり。要再確認 |

#### 修正提案

- **立ち上げ時は A単独**、4ヶ月後の限定展開で B 個包装を試す段階展開
- 原価増加を吸収するため、M（12個入）の価格を **2,484円 → 2,700〜2,800円** に修正検討
- 蛍光インクの食品安全規格（食品衛生法第18条・指定対象外色素）を **包装資材社に正式照会**

## 🪞 「画期的」評価への正直な評価

### 提案書の独自性は確かに高い

- 二重シェル戦略は単一意匠ブランド（京ばあむ・N.Y.C.SAND・オードリー）にない構造
- 「江戸の見立て」を商品設計に組み込む論理は新しい

### ただし「画期的」と称するには 2つの条件が必要

1. **顧客が理解できる構造**であること
   → 「江戸の見立て」が顧客に5秒で伝わる工夫が必要
   → 現状は **論理は成立、伝達は不十分**

2. **製造・売場で実装できる構造** であること
   → 蛍光インクの食品安全 / グランスタ什器調和 / 接客難度
   → 現状は **要追加検証**

### 推奨：「画期的」表現を提案書から削除し、「これまでにない構造」と限定する
