# 株式会社ミックブレインセンター README

> 売れるお菓子を、ゼロからつくる。
> 商品開発から、ブランド設計・デザイン・売り場づくりまでを一気通貫で支援する、商品開発一体型のブランディング／デザイン会社。

---

## 🎯 この会社は何者か

株式会社ミックブレインセンターは、**菓子・土産菓子領域に強い、商品開発一体型のブランディング／デザイン会社**です。

一般的な制作会社のように、依頼されたロゴやパッケージだけをつくる会社ではありません。
この会社の本質は、**「何を、誰に、どう売るか」まで含めて設計すること**にあります。

提供価値は大きく3つです。

- **ブランド開発**
  市場理解、ポジショニング、ブランドコンセプト、世界観整理
- **商品開発**
  アイデア設計、試作、OEM検討、生産方式の整理
- **デザイン開発**
  パッケージ、ロゴ、キービジュアル、Web、店舗、売場演出

つまり、ミックブレインセンターは
**「表現を整える会社」ではなく、「売れる理由を設計する会社」**です。

## 💼 事業領域

この会社の事業は、単なるパッケージ制作ではありません。
本質は、**菓子ブランドの上流設計から下流実装までを一体で支援すること**です。

### 1. ブランド開発
- 市場理解
- コンセプト設計
- ポジショニング整理
- ブランドストーリー設計
- 世界観の言語化と可視化

### 2. 商品開発
- おみやげ新商品の企画
- 試作支援
- 提携パティシエ連携
- OEM検討
- 自社製造 / 外部製造の整理
- 量産仕様調整

### 3. デザイン開発
- パッケージデザイン
- ロゴデザイン
- キービジュアル開発
- Web / EC表現
- 撮影、動画、販促物制作

### 4. 店舗・売場づくり
- 新規店舗立ち上げ
- 既存店舗リニューアル
- ディスプレイ設計
- 売場演出
- 冷蔵ケース、什器、店舗導線整理

### 5. 販促・運用フォロー
- POP、販促物
- 撮影、動画
- 販売後の運用支援
- ブランド運営素材整備

## 🔄 標準的な支援フロー

ミックブレインセンターの強みは、工程を分断しないことです。
典型的な進行は、次の流れで進みます。

```text
問い合わせ・課題設定
        ↓
ヒアリング
        ↓
概算見積
        ↓
ブランド開発
        ↓
商品開発・試作
        ↓
製造方式決定（自社製造 / OEM）
        ↓
パッケージ・ロゴ・Web設計
        ↓
店舗設計・ディスプレイ設計
        ↓
入稿・色校正・仕様調整
        ↓
施工・売場演出
        ↓
発売・出店
        ↓
販促・運用フォロー
```

この流れから分かる通り、同社は
**コンセプト会社ではなく、発売までの泥臭い実装会社**です。

## 🧭 この会社のポジション

ミックブレインセンターは、規模で勝つ会社ではありません。
大手総合デザイン会社のように、組織規模や拠点数で圧倒するタイプではない。

その代わりに、
**菓子・手土産・百貨店・観光地という狭い領域で、極めて深いノウハウを持つ会社**です。

### つまり何が違うのか

- 総合大手のように何でも広くやるのではない
- パッケージ専業のように見た目だけを整えるのでもない
- 商品企画部のように中身だけ考えるのでもない

ミックブレインセンターは、その中間にいて、
**商品・ブランド・売場・販促・体験を一つの商売として束ねるプレーヤー**です。

## 🏆 公開実績の代表例

この会社の価値は、会社案内よりも、**関与したブランドが市場で生き残っているか**で判断した方が早いです。

### 京ばあむ
- 京都土産の主力ブランド
- 生八つ橋市場の飽和を背景に、次の定番土産をゼロベースで構想
- 商品コンセプトとパッケージ意匠が一体化
- 「京都らしさ」を味・構造・包装記号に同時実装
- 累計販売数は1,500万個規模の実績文脈（2023年3月末時点・ブランド側公表）

### フェルム ラ・テール美瑛
- 地域資源 × 食 × 空間 を束ねた代表案件
- 商品、店舗、景観、体験を一体でブランド化
- 単なる菓子ブランドではなく、地域体験拠点として成立
- 初年度来店者 38,703人という文脈を持つ

### REICACAO
- サステナビリティ文脈を含んだ現在形の代表案件
- 商品、店舗、Web、ブランド思想まで一体で設計
- 単なる"おしゃれなチョコレート"ではなく、循環性や生産地支援を含んだブランド

### 東京ばな奈 / N.Y.C.SAND など
- 長期に流通し続ける強い売場ブランド文脈への関与
- 東京土産、百貨店ギフト、駅ナカ売場の勝ち筋理解を示す補助線

## ✅ この会社の強み

### 1. 商品・ブランド・売場・販促を分断しない

多くの会社は、

- 商品企画
- デザイン
- 店舗設計
- 販促
- Web

が別々です。

ミックブレインセンターは、それらを一つの商売設計として扱います。
ここが最大の強みです。

### 2. 菓子・土産市場の勝ち筋を知っている

この市場は「味が良い」だけでは勝てません。

必要なのは、

- ネーミング
- 贈答適性
- 持ち運びやすさ
- 売場映え
- 地域性
- 限定感
- 話題性

です。

同社は、この複合条件に対して設計できる数少ない会社です。

### 3. ゼロベースの商品構想に入れる

既存商品の見せ方改善だけではなく、
**そもそも何を作るべきかから入れる**。
ここが普通の制作会社との決定的な違いです。

### 4. ブランドを"立ち上がった状態"まで持っていく

ロゴ単体、箱単体、Web単体ではなく、
**ブランドが市場で成立している状態**まで統合して考える。
これが公開実績の強さにつながっています。

### 5. 実店舗・実販売の現場感に近い

関連ブランドや案件の文脈から見て、
机上の理論だけではなく、**実際に売れるかどうか**を強く意識した実務寄りの会社です。

## ⚠️ この会社を見る上での注意点

### 1. 企業情報の開示は厚くない

公開情報では、

- 資本金
- 従業員数
- 財務数値
- ESG方針
- 採用情報
- 組織詳細

などは薄いです。

したがって、
**実績の強さに対して、コーポレートの可視性は高くない**
というのが率直な評価です。

### 2. 実績の質は強いが、定量比較情報は限定的

ブランド事例は強い一方で、

- どの程度売上が伸びたか
- どこまで担当したか
- 成果比較がどうか

は公開だけでは十分に比較できません。

発注判断では、個別ヒアリング前提です。

### 3. 属人的リスクはある

創業起点が古く、代表体制にも継承色があり、
ブティック型企業らしく**主要人物依存のリスク**はあります。

逆に言えば、そこがブランド一貫性の源泉でもあります。
