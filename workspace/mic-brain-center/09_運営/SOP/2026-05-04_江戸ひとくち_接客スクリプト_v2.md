## 8. 法人贈答・取材・インフルエンサー対応（v2 新規・Fix12）

### 8-1. 法人まとめ買い（10箱以上）

#### 想定シーン

スーツ姿の顧客が「会議用に20箱欲しい」「取引先への手土産で50箱まとめて」と申し出。

#### スクリプト

```
[1]（落ち着いて応対）
「ありがとうございます。何箱ご検討でしょうか？」

[2]（10箱以上の場合）
「10箱以上の法人ご注文には、専用窓口がございます。
 配送先・請求書発行・領収書のご希望、いずれもご対応します。
 名刺をお預かりできれば、店長から30分以内にご連絡差し上げます。」

[3]（CEO/店長エスカレーション）
店長到着まで顧客にお茶をお出しする。
店長は到着後、30分以内に：
- 配送可能日（最短3日）
- 法人割引の判断（CEOのみ）
- 領収書・請求書の発行プロセス説明
- 必要なら専用包装（社名入り掛け紙）の相談
```

#### 法人案件の判断基準（CEOのみ）

| 数量 | 対応 |
|------|------|
| 10〜29箱 | 通常価格 + 法人配送対応 |
| 30〜99箱 | **5%割引検討**（CEO決裁）|
| 100箱以上 | **10%割引 + 専用打ち合わせ**（CEO決裁）|

### 8-2. 取材対応（記者・編集者・出版社・テレビ）

#### 想定シーン

「○○マガジン編集の○○です。お話を聞かせていただけますか」と来訪。

#### スクリプト

```
[1]（受付対応）
「ありがとうございます。本日はどちらの取材でしょうか？
 媒体名と取材趣旨を伺えますか？」

[2]（媒体・趣旨確認後）
「店長／広報担当に取り次ぎます。
 名刺をお預かりしてもよろしいでしょうか。
 当日対応か後日対応か、状況により異なります。
 約30分ほどお待ちいただけますか。」

[3]（CEO/広報エスカレーション）
- メモ書きで以下を CEO に伝達：
  - 媒体名
  - 取材者氏名・連絡先
  - 取材趣旨
  - 来訪時刻
- CEO/広報の判断で当日対応か後日設定
```

#### 取材対応の禁止行動

- **「ふざけている」「これって冒涜では」と言われた場合のスクリプト**：
  > 「ご質問ありがとうございます。当ブランドのコンセプトは『江戸の見立ての精神を現代に翻訳する』ことで、当時最先端の表現を恐れなかった江戸文化への敬意から生まれています。詳細は広報担当より資料を後送しますので、お名刺を頂戴できますでしょうか」

- **絶対NG**：その場で売上情報・原価・契約金額を口にしない
- **絶対NG**：CEO の許可なく商品の試作品・未公開ラインを見せない

### 8-3. SNSインフルエンサー対応

#### 想定シーン

スマートフォンで撮影しながら「フォロワー○万人の○○です。投稿させてください」と申し出。

#### スクリプト

```
[1]（笑顔で）
「ありがとうございます。
 SNS投稿、ぜひお願いします。
 撮影はパッケージと商品のみでお願いします。
 店内全体の撮影は他のお客様のご迷惑になることもあるので、
 こちらの商品コーナーでお願いします。」

[2]（インフルエンサー投稿希望の場合）
「投稿の際は、ハッシュタグ #江戸ひとくち を付けていただけると嬉しいです。
 後日、店長からご連絡差し上げる場合もありますが、よろしいでしょうか。」

[3]（フォロワー数が大きい場合：1万人以上目安）
「もしよろしければ、店長との打ち合わせの機会をご提案できます。
 名刺・SNSアカウントをお預かりしてもよろしいでしょうか」
→ CEO/広報にエスカレーション
```

#### インフルエンサー対応の判断基準

| フォロワー数 | 対応 |
|-----------|------|
| 1,000〜10,000人 | 通常対応 + 試食推奨 |
| 10,000〜100,000人 | 通常対応 + ハッシュタグ依頼 + CEO報告 |
| 100,000人以上 | **CEO/広報の事前同意プロセスへ**（PR タイアップ可能性）|

#### 撮影に関する禁止事項

- 他のお客様の顔・私物が写る撮影
- 商品の **裏面表示（原材料・アレルゲン）** をクローズアップさせる撮影（誤解を招く可能性）
- **未公開ライン・試作品**の撮影
- **店舗バックヤード**の撮影
