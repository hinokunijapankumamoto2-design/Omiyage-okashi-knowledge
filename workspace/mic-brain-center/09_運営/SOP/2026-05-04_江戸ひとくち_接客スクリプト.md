# 江戸ひとくち 接客スクリプト

> 売場スタッフ全員が **5分接客まで** 暗記する。
> 「江戸の見立て」を顧客に5秒で伝える方法。
> Phase 2 以降の二重シェル戦略の説明はこのスクリプトの中核。

---

## 0. 基本姿勢（全員共通）

### 守ること

1. **「江戸時代から続く」と言わない**（景表法・断定NG）
   → 「江戸の手土産文化を現代に翻訳した」と言う
2. **「絶対」「必ず」「最高」「日本一」を使わない**
3. **6種すべての産地を覚える**（産地証明の質問に即答）
4. **試食を必ず誘う**（試食ピース1個で説明する）
5. **押し売りしない**（「ご検討ください」で終える）

### 言わない言葉

- 「絶対売れます」「ヒット商品です」
- 「業界最高級」「日本一の和三盆」
- 「これだけ買えば大丈夫です」
- 「他のお店より美味しい」

### 言ってよい言葉

- 「江戸の手土産文化を現代に翻訳しました」
- 「6種それぞれの素材の産地はこちらです」
- 「ひとくちサイズなので、人数の多いお席にも合わせやすいです」
- 「個包装なので、お渡しもしやすいです」
- 「常温20日もちますので、配送・お持ち帰りどちらも安心です」

## 1. 30秒接客（通行人を立ち止まらせる）

### 想定シーン

通行人が売場前を歩いている。3秒視認で売場の存在に気づいた瞬間。

### スクリプト

```
[1]（明るく・押しつけずに）
「こんにちは。東京駅限定の和菓子です。
 6種類の江戸素材をひとくちずつにしました。
 試食はこちらからどうぞ。」

[2]（試食ピースを差し出しながら）
「最初に和三盆から。香川県産の上品な甘さです。」

[3]（顧客が一口食べた直後）
「お持ち帰りしやすい個包装で、常温20日もちます。
 12個入が一番人気ですが、ゆっくり見ていってください。」
```

### 30秒で伝える3つのこと

1. 東京駅限定（希少性）
2. 6種の江戸素材（独自性）
3. 個包装・常温20日（贈答適性）

### 想定シーン

試食を受け取った顧客が「他にどんな種類があるんですか？」と聞いた。

### スクリプト

```

「全部で6種類あります。
 1. 和三盆（香川県産）
 2. 焙じ茶（京都府産）
 3. あんこ（北海道十勝産小豆）

 江戸時代から手土産として流通していた

[3]（試食を勧めながら）
「もう1種類いかがですか？
```

2. 「江戸時代から手土産として流通していた素材」（断定NG・歴史的事実）
3. 試食2個目の誘い（離脱防止）

## 3. 3分接客（サイズ選択・購入決定）

### 想定シーン

試食を2個食べた顧客が「これ、お土産にしようかな」と考えている。

### スクリプト

```
[1]（サイズ選択肢を見せながら）
「サイズは3種類ご用意しています。

 ・8個入 1,728円（ご家族向け・3〜4名様）
 ・12個入 2,484円 ★一番人気（オフィス・お友達向け）
 ・16個入 3,240円（贈答・ご贈答先10名様前後）

 何名様ぐらいにお渡しになりますか？」

[2]（顧客の用途を聞いた後）
「それでしたら12個入が合うかと思います。
 ひとくちサイズなので、人数より少し多めでも
 余裕を持ってお配りいただけます。」

[3]（Phase 2 以降のみ：二重シェル説明）
「実は、開けていただくと面白い仕掛けがあります。
 表箱は江戸の品格に整えていますが、
 中の個包装は色鮮やかで、開けた瞬間に
 印象が変わるんです。
 渡された方が驚かれることが多いです。」

[4]
「お渡しの際、贈答用の手提げ袋もご用意できます。
 こちらでよろしければ、お会計いたしますね。」
```

### 3分で伝える3つのこと

1. 3SKU の用途別案内（人数で選ばせる）
2. M（12個入）が一番人気である事実
3. 二重シェル戦略（Phase 2 以降のみ）

## 4. 5分接客（江戸の見立ての精神・本ブランドの思想）

### 想定シーン

関心の高い顧客（ビジネス層・贈答用途・記者・インフルエンサー）が「このブランドのコンセプトを聞かせてください」と言った。

### スクリプト

```
[1]（落ち着いて・教える口調にしない）
「江戸ひとくちは、東京駅限定で販売している和菓子です。
 コンセプトは『東京の挨拶を、ひとくちに』。

 東京は、もともと江戸という街でした。
 江戸時代の手土産文化は、ただの贈り物ではなくて、
 挨拶の所作そのものだったと言われます。

 その文化を、現代の暮らしに合うひとくちサイズで
 翻訳したのが、このブランドです。」

[2]（Phase 2 以降のみ）
「もうひとつ大切にしているのが、『見立て』の精神です。
 江戸時代の文化は、表と裏、伝統と新規、
 両方を抱えて発展してきました。
 浮世絵も歌舞伎も、当時最先端の表現だったんですね。

 私たちのパッケージも、
 表は江戸の品格、開けると現代の色彩、
 という二重構造にしています。
 これが『江戸の見立て』の現代解釈です。」

[3]（質問を促す）
「このパッケージのご感想や、
 何かご質問があればお聞かせください。」
```

### 5分で伝える3つのこと

1. ブランドコンセプト「東京の挨拶を、ひとくちに」
2. 江戸の手土産文化の現代翻訳という位置づけ
3. 「見立て」の精神（Phase 2 以降の二重シェル戦略の根拠）

### 5分接客が必要な顧客の見極め

- 「コンセプト」「思想」「ブランド」という言葉を使った
- パッケージを長く眺めている
- メディア関係者・インフルエンサー風（取材ノート、カメラ、SNS世代の50代以下）
- 法人贈答（10箱以上のまとめ買い検討）

## 5. よくある質問への回答（FAQ）

### Q1：江戸時代の何ですか？

**A1**：「江戸時代から続いているわけではなく、江戸の手土産文化を現代に翻訳したブランドです。
ブランド自体は2026年（仮）に始まりました。素材は江戸時代から流通していた普遍的なものを使っています」

> **重要**：「江戸時代から続く」は景表法的に断定NG。歴史的継承を匂わせない。

### Q2：他で買えますか？

**A2**：「グランスタ東京限定です（Phase 1）/ グランスタ東京と大丸東京店限定です（Phase 2）/ 一部商品はECでもお取り扱いがあります」

### Q3：日持ちはどれくらいですか？

**A3**：「常温で20日です。ご贈答先への配送、ご旅行のお持ち帰り、どちらも安心してお使いいただけます」

### Q4：個包装の色が派手ですが…（Phase 2 以降）

**A4**：「驚かれましたね。これは『江戸の見立て』の精神を意匠で表現したものです。江戸文化は表と裏、伝統と新しさを同時に抱えていました。私たちはその精神を現代の色彩で翻訳しています。表箱の品格と中の意外性、両方を楽しんでいただけたらと思います」

> **重要**：「ふざけている」と思われた瞬間にこのスクリプトで方向修正。

### Q5：他のお菓子との違いは？

**A5**：「東京駅限定で、6種類の江戸素材をひとくちサイズで一度に楽しめる点が特徴です。それぞれの素材の産地にこだわっていますので、お渡しした方に『これ、和三盆だね』『あ、十勝の小豆？』というような会話が生まれやすいかと思います」

> **重要**：「他より美味しい」とは言わない。「特徴」として淡々と説明。

### Q6：お値段が他より高いように感じます…

**A6**：「ひとくちサイズで6種類入っているので、1個あたり約207円（M箱の場合）になります。ひとつひとつが産地指定の素材を使った和菓子としては、適正帯かと思います」

> **重要**：価格弁解はしない。事実のみ淡々と。

### Q7：アレルゲンは何が入っていますか？

**A7**：「6種それぞれで異なります。お渡しする際にアレルゲン一覧表をお渡ししますね。特に大豆（きな粉）、乳成分（あんこの一部）、小麦（つなぎ）が含まれる種類があります」

### Q8：海外のお土産にも合いますか？

**A8**：「個包装で常温20日もちますので、海外の方への手土産にもお選びいただけます。素材の説明カードを英語でもご用意しています（Phase 2 以降）」

## 6. NG行動・トラブル対応

### NG行動

| NG | 理由 | 代わりに |
|----|------|---------|
| 「絶対売れます」 | 景表法・断定 | 「人気の商品です」 |
| 「江戸時代から続く」 | 断定・誇張 | 「江戸の手土産文化を現代に翻訳」 |
| 「全員に喜ばれます」 | 範囲断定 | 「お渡しした方の反応が良いとお聞きしています」 |
| 「世界一の和三盆」 | 最上級表現 | 「香川県産の上質な和三盆」 |
| 押し売り | ブランド毀損 | 「ご検討ください」 |
| 試食の強要 | 顧客不快 | 「いかがですか」と1度だけ |

### トラブル対応

#### 顧客が「個包装の色が変だ」と苦情

→ 5分接客 Q4 のスクリプトで対応。それでも納得しない場合は「貴重なご意見ありがとうございます。今後の改善に活かします」で終える。

#### 試食で具合が悪くなった顧客

→ **直ちに CEO（店長）にエスカレーション**。アレルゲン表示を確認。必要なら救急対応。

#### メディア取材の依頼

→ **その場で対応せず、CEO へ取り次ぎ**。「広報を通してご対応いたします」と伝え名刺を受け取る。

#### 法人まとめ買い（10箱以上）

→ 5分接客で対応 + 法人窓口（CEO）に取り次ぎ。割引や請求書対応の判断は CEO のみ。

## 8. 接客の品質を測る指標

| 指標 | 目標 |
|------|------|
| 試食誘導成功率（通行人 → 試食） | 30%以上 |
| 試食 → 購入転換率 | 50%以上 |
| 1接客あたりの平均時間 | 1〜3分（5分接客は10%以下が適正） |
| 苦情発生率 | 0.1%以下（月1件未満）|
| メディア取材エスカレーション漏れ | 0件 |
| アレルゲン質問への即答率 | 100% |

---

## 9. このスクリプトの育て方

- 顧客の質問で **新しいパターン** が出たら、本スクリプトに追記
- 月1回のロールプレイで **言いにくい言葉・伝わらない言葉** を発見し、修正
- Phase 2 以降の市場反応で **二重シェル戦略の説明** を進化させる
- 季節限定の登場時に **限定対応スクリプト** を追加

---

## 10. CEO への引き継ぎ事項

- スタッフ採用面接時に **本スクリプトの暗記力** を確認
- スタッフが慣れる前は **CEO（店長）が立会いで補助**
- 苦情・トラブルは **必ず CEO まで報告**
- 月1回のロールプレイ会で本スクリプトの検証
