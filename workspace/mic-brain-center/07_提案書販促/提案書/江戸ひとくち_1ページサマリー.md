# 江戸ひとくち — 提案サマリー

> 売れるお菓子を、ゼロからつくる。
> 東京駅で長く愛される、和菓子の現代翻訳ブランドのご提案です。

---

## 🎯 提案の要点（一目で）

### コンセプト
> **「東京の挨拶を、ひとくちに。」**

和三盆を軸に、6種の江戸素材（焙じ茶・あんこ・きな粉・黒糖・抹茶・和三盆）を **500円玉サイズの個包装菓子** に集約した、東京駅の手土産ブランド。

### 独自性
- 表箱（外装）= 江戸の品格
- 個包装（中身）= 江戸を裏切る現代の蛍光色
- **開封体験そのものが拡散装置になる二重シェル構造**

### 何を狙うか
- 大丸東京店内で **2016〜2026年連続1位** の N.Y.C.SAND が示す「**長寿型ロングセラー**」を、和菓子の現代翻訳枠で取りに行く

## 🗓 24ヶ月段階展開

```
Phase 0（M0-2）：顧客テスト・商標調査
Phase 1（M3-12）：グランスタ東京 A単独で長寿基盤確立
Phase 2（M13-18）：大丸 + EC で B（蛍光個包装）試行
Phase 3（M19-24）：3分岐判断 → フル展開
```

### Phase 3 数値判断基準（市場反応で決定）

| 評価 | EC月商 | SNS言及 | 大丸内ランキング | 顧客評価 | 判断 |
|------|-------|--------|--------------|----------|------|
| 強 | 月300万円〜 | 月50件〜 | TOP10 | 4.0/5〜 | **全店二重シェル化** |
| 中 | 月100-300万円 | 月15-50件 | TOP30 | 3.5-4.0 | 大丸+ECのみ継続 |
| 弱 | 月100万円未満 | 月15件未満 | TOP30外 | 3.5未満 | **A単独路線で長寿型確立、B撤退** |

→ **撤退も合理的選択** として予め設計してある。

## ⚠️ 必ず確認いただきたい3点

### 1. 商標調査
ネーミング3案（江戸ひとくち / 江戸所作 / てみやげ江戸）は **すべて商標調査未済**。
**着手前に弁理士による正式調査が必要**です。

### 2. 売場確保
グランスタ東京は **JR東日本クロスステーション** の出店審査が必要。
3-5坪枠で申請を推奨（8坪は審査難度高）。

### 3. 顧客テスト
Phase 0 で **30名×2グループ（30-40代/50-60代）** に試食評価を実施。
「江戸の見立て」が顧客に5秒で伝わるかを定量検証。

## 🛡 リスクと対策のハイライト

| リスク | 対策 |
|-------|------|
| 表裏の対比が「ふざけている」と映る | **接客スクリプト**で5分以内に「江戸の見立て」を説明 |
| 二重シェル意匠の量産難度 | Phase 1 = A 単独、**Phase 2 から段階導入** |
| B反応が悪い | Phase 3 で **A単独路線（撤退）も選択肢** として残す |
| 食品衛生事故・SNS炎上・商標訴訟 | 各々の **72時間対応プロトコル** を整備済 |
