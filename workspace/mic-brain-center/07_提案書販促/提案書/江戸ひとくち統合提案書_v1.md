# 江戸ひとくち 統合提案書 v1

> **本提案書の核**：パッケージ意匠の対立2案（A：江戸品格 / B：江戸を裏切る）を「綺麗に折衷」せず、**「両方を抱える二重構造」** として提案する。
> これが画期的さの正体である。

---

## 0. エグゼクティブサマリー（3行）

1. 東京駅の土産菓子市場で、**和菓子の現代翻訳 × 長寿型** のポジションは N.Y.C.SAND（10年連続1位）の隙間として空いている。
2. 「江戸ひとくち」は、和三盆を軸に **6種の江戸素材を500円玉サイズの個包装菓子** に集約した。
3. 意匠は「江戸品格（表）」と「江戸を裏切る（裏）」の **二重構造**。表箱は伝統で安心、開けた瞬間に現代の蛍光が立ち上がる。**開封体験そのものが拡散装置** となる。

## 1. 目的の再定義

東京駅は、N.Y.C.SAND（10年連続1位・大丸東京店）が象徴する **「長寿ロングセラー型」** の最激戦区である。

しかし、和菓子の現代翻訳枠は **空白**。
- 京ばあむ → 京都
- 船橋屋こよみ → 老舗江戸（くず餅）
- N.Y.C.SAND → 都市記号（New York 文脈で和を排除）

「**東京 = 江戸の玄関口**」という記号一致を、**和菓子の現代翻訳で正面から取りに行く**。
これが本案件の存在理由である。

## 4. 表現方針（本提案書の核 ★画期的構造）

### 4-1. 対立2案を統合する考え方

パッケージ意匠で2案が出た。

| 案 | 軸 | 強み | 弱み |
|----|----|------|------|
| **A：江戸品格路線** | 江戸記号を正面活用（白×墨×朱、江戸小紋、明朝、江戸文字） | 王道。失敗確率が低い。男女年代を問わない | 画期的さは中位。SNS拡散力は中 |
| **B：江戸を裏切る路線** | 江戸記号を一切使わず、現代の粋を表現（蛍光色、英字、QR的幾何） | SNS拡散力◎、インバウンド受容◎、画期的 | 50代以上の伝統嗜好層に違和感 |

**通常の提案書ならば、A or B の二者択一で1案に収束させる。**
本提案書はそれをしない。

### 4-2. 採用する統合構造：**二重シェル戦略（Dual-Shell Strategy）**

> **表は A（江戸品格）、開けた瞬間に B（江戸を裏切る）が立ち上がる。**

- **表箱（外装）= A**：白マット紙 + 江戸小紋 + 明朝筆文字
- **個包装（内側）= B**：蛍光色6種 + 英字（"01 / WSB" 等のコード化）+ アルミ蒸着フィルム

### 4-3. なぜこの構造が画期的か（4つの理由）

#### 理由1：開封体験そのものが拡散装置になる

- 表箱を見た時：「老舗の和菓子か、ハズレない」（伝統的安心感）
- 開けた時：「え、これ和菓子なの？」（驚き）
- → **この体験差そのもの** が SNS 拡散・口コミの強烈な動機になる

#### 理由2：贈答リスクと拡散力の両立

- 渡す側：A の品格で **50代以上にも安心**
- 受け取った側：B の現代性で **30〜40代に強く刺さる**
- → 単一意匠では達成できない **「贈り手と受け手の年代差」を吸収する構造**

#### 理由3：江戸の精神に最も忠実

- 江戸の本質は「型を破る粋」
- 表面で「江戸らしさ」を演じ、内側で「江戸を裏切る」 = **江戸の見立ての精神そのもの**
- 浮世絵（藍摺りの新規性）/ 寄席（型の中の即興）/ 歌舞伎（古典の再解釈）はすべてこの構造

#### 理由4：京ばあむ・N.Y.C.SAND にはない構造

- 京ばあむ：単一意匠（京都記号で統一）
- N.Y.C.SAND：単一意匠（NY記号で統一）
- 江戸ひとくち：**二重意匠**（表=江戸 / 裏=現代）
- → カテゴリ内でも前例がほぼなく、**模倣されにくい構造的優位**

### 4-4. 想定顧客体験フロー

```
【1】売場で見る
  → 表箱が見える（白×墨×朱の江戸品格）
  → N.Y.C.SAND 隣で「和の上質手土産」と認識
  → 購入決定（試食 + サイズ選択）

【2】手土産として渡す
  → 渡す側：「江戸の手土産」として伝統的に渡せる
  → 受け取る側：「いい品をいただいた」と最初は思う

【3】開封する
  → 表箱を開けると、6種の蛍光色個包装が並んでいる
  → 「え、これ和菓子？」の認知反転

【4】SNS / 口コミで拡散
  → 「東京駅で買った和菓子、開けたら衝撃だった」
  → 写真撮影 → SNS投稿 → 拡散

【5】次の購買サイクル
  → 投稿を見た人が「東京駅で買ってみたい」
  → ブランド認知の指数関数的拡大
```

### 4-5. 売場（中立フレーム）

- グランスタ東京改札内・5-8坪・旗艦
- 大丸東京店・3-5坪・拡張時
- 売場什器は **A（黒木和紙）と B（白アクリル蛍光）の混在**
- 売場壁面：A の品格（外装陳列）/ ガラスケース内：B の試食ピース可視化
- → **売場でも対立構造が体験できる**

## 5. 提案理由（なぜこの方向か）

### 5-1. 市場文脈

- 訪日需要・観光消費は2026年も高水準（追い風）
- 土産菓子市場は3,963億円（高位安定）
- N.Y.C.SAND の10年連続1位は **「長寿型」が今後も主流** であることの証明

### 5-2. 競合差別化

- 「東京 = 江戸の玄関口」枠は構造的空白
- 二重シェル戦略は **既存の単一意匠ブランドが追随しにくい**
- 「画期的さ × 安全性」を同時に持つのは本構造のみ

### 5-3. ペルソナ整合

- 30〜60代男女ビジネス層を **両方とも取りに行ける**
- 表（A）で伝統層を確保 / 裏（B）で若年・インバウンド層を獲得

### 5-4. 過去の勝ち筋との整合

| 過去事例 | 学び | 本案での実装 |
|---------|------|------------|
| 京ばあむ | 商品コンセプトと意匠の同時実装 | 6種素材と6色蛍光色の同時実装 |
| N.Y.C.SAND | 単一カテゴリ記号で長寿 | 二重意匠で長寿 + 拡散の両立 |
| REICACAO | 物語性 × 意外性 | 表=伝統 / 裏=裏切り の意外性 |

## 9. なぜこの提案が画期的か（最後に）

通常の提案書は、対立する2案を **「A・Bを比較し、Aを選ぶ」** 形で書く。
本提案書は **「Aを選び、その内側にBを抱え込む」** 形で書いた。

これは折衷ではない。**構造的な選択**である。

- 折衷：両方の良いところを混ぜて中庸を作る → **平均化・凡庸化**
- 構造的選択：両方の対立を残したまま、層を分けて両方を抱える → **驚きと信頼の両立**

この選択ができるのは、**江戸文化の本質である「見立て」の精神** に立脚している場合のみ。
表と裏、伝統と現代、安心と驚きを **同時に成立させる構造** こそ、本案件の独自性である。
