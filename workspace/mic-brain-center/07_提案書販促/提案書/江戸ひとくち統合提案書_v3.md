## 1. 目的の再定義

東京駅は、**大丸東京店内ランキングで2016〜2026年連続1位の N.Y.C.SAND** が象徴する「長寿ロングセラー型」の激戦区である。
ただし、和菓子の現代翻訳枠は、現状観測できる範囲では空白。

「**東京 = 江戸の玄関口**」という記号一致を、**和菓子の現代翻訳で正面から取りに行く**。

**v3 の方針**：単発で全力突入せず、**段階展開でリスクを分散**しながら長寿基盤を確立する。

## 4. 表現方針（v3 で大改訂）

### 4-1. 二重シェル戦略の本質（思想は不変）

> 表は A（江戸品格）、開けた瞬間に B（江戸を裏切る）が立ち上がる。

- **表箱（外装）= A**：白マット紙 + 江戸小紋 + 明朝筆文字
- **個包装（内側）= B**：蛍光色6種 + サンセリフ英字 + アルミ蒸着フィルム
- **食品表示部分のみ通常配色**（黒文字 / 白背景）に切替（v2 から継承）
- **フォント**：オープンソース（Inter / Noto Sans JP / IBM Plex Sans）採用を主候補に（v2 から継承）

### 4-2. 段階展開の設計（v3 新規）

二重シェル戦略は、初日からフル実装しない。
**24ヶ月で段階的に立ち上げる**。

```
Phase 0（M0〜M2）：顧客テスト・準備
   ├ 3パターン（A単独 / B単独 / A+B）の試食評価
   ├ 30-40代と50-60代に分けて評価
   └ 結果でPhase 1の優先軸を決定

Phase 1（M3〜M12）：グランスタ A 単独で長寿基盤を固める
   ├ グランスタ東京 改札内 3-5坪
   ├ パッケージA（江戸品格）のみ
   ├ コア4種（和三盆・焙じ茶・あんこ・抹茶）から開始
   ├ M（12個入・2,484円）1SKU に集中
   └ 目標：単月1,000箱・東京駅手土産の認知獲得

Phase 2（M13〜M18）：大丸 + EC で B 試行
   ├ 大丸東京店 銘菓フロア 3坪 拡張
   ├ EC（自社サイト + Amazon 等）で B（蛍光個包装）を期間限定試行
   ├ コア6種に拡大
   ├ S（8個入）/ L（16個入）追加
   └ 目標：B市場反応の評価・SNS拡散の量と質を測定

Phase 3（M19〜M24）：二重シェル統合フル展開
   ├ Phase 2 の結果を踏まえ、二重シェル戦略を判断
   │   ├ 3-1：B反応 強い → グランスタも二重シェルで展開
   │   ├ 3-2：B反応 中位 → 大丸 + EC のみ二重シェル継続
   │   └ 3-3：B反応 弱い → A単独路線で長寿型を確立（B撤退）
   ├ 季節限定（年4回・各2種）の展開開始
   └ 目標：3年目以降の長寿ロングセラー基盤完成
```

> **重要**：Phase 3 で **3つの分岐**を予め設計してある。
> 「二重シェル戦略を必ずフル実装する」前提ではない。
> 市場反応で **A単独路線（撤退）も合理的選択** として残す。

### 4-3. なぜこの構造が合理的か（4つの理由）

#### 理由1：開封体験そのものが拡散装置になる（思想は v2 から継承）

#### 理由2：贈答リスクと拡散力の両立（思想は v2 から継承）

#### 理由3：江戸の精神に通じる構造（思想は v2 から継承）

#### 理由4：単一意匠ブランドにない構造（思想は v2 から継承）

#### v3 の補強：顧客理解の難所を「接客スクリプト」で支える

「江戸の見立て」を5秒で伝えるのは難しい。
これに対応するため、別ファイル `09_運営/SOP/2026-05-04_江戸ひとくち_接客スクリプト.md` で：

- **30秒接客**（試食誘導まで）
- **1分接客**（6種素材の説明）
- **3分接客**（二重シェル戦略の説明）
- **5分接客**（江戸の見立ての精神）
- **よくある質問への回答**

を整備した。**スタッフ全員が5分接客まで暗記** することが Phase 1 の運用前提。

### 4-4. 想定顧客体験フロー（v2 から継承・短縮）

売場で見る → 試食 → 購入 → 手土産として渡す → 開封 → SNS 拡散 → 次の購買サイクル

### 4-5. 売場戦略（v3 で大改訂）

#### 売場の二段階化

ファクトチェック逆チェック1で指摘された通り、**グランスタの売場確保には制約がある**：
- 8坪は審査難度が高い → **3-5坪スタートが現実的**
- 蛍光色什器は駅ナカ意匠調和に合わず **不採用リスク**

→ 売場を二段階化する：

| 売場 | フェーズ | 規模 | 採用意匠 | 役割 |
|------|--------|------|---------|------|
| **グランスタ東京** | Phase 1〜 | 3-5坪 | A 江戸品格のみ | 長寿基盤確立・出張ビジネス層 |
| **大丸東京店** | Phase 2〜 | 3-5坪 | A表 + B裏（二重シェル試行） | プレミアム贈答・百貨店ギフト |
| **EC（自社・Amazon）** | Phase 2〜 | — | B（蛍光フル意匠の限定版）| 試行・SNS拡散・インバウンド |
| **東京ギフトパレット** | Phase 3〜 | 検討 | A表 + B裏 | 観光客・希少性運用 |

#### 売場の役割分担

- **グランスタ = 安定の入口**（A単独・伝統層・出張ビジネス層）
- **大丸 = 二重シェルの本丸**（百貨店の品格 + 開封体験）
- **EC = 攻めの実験場**（B試行・SNS拡散・インバウンド向け）

## 5. 提案理由（v2 から継承）

### 5-1. 市場文脈

- 訪日需要・観光消費は2026年も高水準（追い風）
- 土産菓子市場は3,963億円（2025年見込み）
- 大丸東京店内で N.Y.C.SAND が10年連続1位（2016〜2026）= 「長寿型」が東京駅で機能することの一証拠

### 5-2. 競合差別化

- 「東京 = 江戸の玄関口」枠は、現状観測できる範囲では空白
- 二重シェル戦略は、単一意匠ブランドが追随しにくい構造

### 5-3. ペルソナ整合

- 30〜60代男女ビジネス層を、Phase 1 の A 単独で確実に取り込み
- 30〜40代・SNS層・インバウンドは Phase 2 の B 試行で取り込む

## 10. 本提案書の独自性（v2 から継承）

通常の提案書は、対立する2案を「A・Bを比較し、Aを選ぶ」形で書く。
本提案書は **「Aを選び、その内側にBを抱え込む」** 形で書いた。

これは折衷ではない。**構造的な選択** である。

### v3 の補強

v3 では、この構造的選択を **「24ヶ月で段階的に実装する」** 計画に翻訳した。
論理だけでなく、**現実の市場・製造・運用** が追従可能な形まで降ろした。

- 折衷：両方の良いところを混ぜて中庸を作る → 平均化
- 単発の構造的選択：両方の対立を残して一気に実装 → 現場が追従できないリスク
- **v3 の段階的構造的選択：対立を維持しながら、フェーズ別に検証して実装** → 現場で機能する独自性
