# SNS需要シグナル収集ツール（sns-signal-collector）

## 概要

X API v2 を使い、対象ブランドへの公開言及を収集 → 土産菓子特化の語彙辞書で文脈分類 → 週次レポート（需要シグナル推移・文脈構成比・地理分布・急増アラート）を生成するツール。
「SNS需要シグナル分析サービス」（東京玉子本舗様提案）の収集・分析エンジンの初版。

## 絶対ルール

1. **公開投稿のみを各プラットフォームの正規API経由で取得する。** スクレイピングによる収集機能は実装しない（提案書§7「正規の方法で取得」との整合のため）
2. **サンプルデータ（sample_data/）はダミー。** レポートに出力する際は必ず「ダミーデータ」の表記を維持する
3. 投稿者個人が特定される情報（ユーザー名等）を顧客向けレポートに転載しない。引用は要旨化する
4. 依存は Python 3.11 標準ライブラリのみ。外部パッケージを追加しない（threads-tool と同じ方針）
5. APIキーは `.env` のみに置く。コード・コミットに含めない

## 構成

```
sns-signal-collector/
├── collect.py        ← X API言及収集（--mock でAPIなし動作）
├── classify.py       ← 文脈分類エンジン（専用語彙辞書）
├── report.py         ← 週次レポート生成（Markdown + CSV）
├── brands.json       ← ブランド定義・表記ゆれ辞書・販売エリア
├── sample_data/      ← 動作確認用ダミー言及データ
├── data/             ← 収集データ（Git管理外）
└── output/           ← レポート出力（Git管理外）
```

## コマンド

- 収集（モック）: `python3 collect.py --mock`
- 収集（実API）: `python3 collect.py --brand nycsand --max-pages 2`
- レポート生成: `python3 report.py`
- 分類テスト: `python3 classify.py "テキスト"`
