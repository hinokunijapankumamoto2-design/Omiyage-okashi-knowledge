# 投稿モード一覧

スイーツ王子（@sweetsouji.0384）の投稿は、その日の目的に応じて「モード」を切り替えて生成する。
各モードは独立した分析プロンプト＋投稿フォーマットを持つ。

---

## 利用可能なモード

| mode_id | ファイル | 用途 | データ取得元 |
|---------|---------|------|-------------|
| `rakuten_daily` | `rakuten_daily.md` | 楽天デイリーランキングTOP5を本音採点 | 楽天API（自動取得） |
| `gift_advisor` | `gift_advisor.md` | 用途別（義実家・取引先・ご褒美等）の比較・選定提案 | 手動／Web調査 |
| `sns_research` | `sns_research.md` | SNS競合・空白ポジション戦略調査 | Web/手動調査 |

将来追加予定：
- `seasonal_event` … 季節イベント先回り（母の日・お中元・帰省など）

---

## 使い方

### CLI引数で指定
```bash
python auto_post.py --mode rakuten_daily
python auto_post.py --mode gift_advisor
python auto_post.py --mode sns_research
```

### 引数なし → 対話選択
```bash
python auto_post.py
# モード選択メニューが出る
```

### 固定運用（バッチ用）
```bash
echo rakuten_daily > current_mode.txt
python auto_post.py
```

## モードの選び方

| その日にやりたいこと | 推奨モード |
|---------------------|----------|
| 楽天TOP5を機械的に解読して投稿 | `rakuten_daily` |
| 「義実家向け5選」など用途で勝負 | `gift_advisor` |
| 戦略・ポジション・競合を考え直す | `sns_research` |

---

## 全モード共通の制約

すべてのモードは以下に従う：

1. **`../persona.md`** の人格定義（スイーツ王子）
2. **8指標ルーブリック**（味・価格妥当性・特別感・個包装・日持ち・常温可否・渡しやすさ・楽天で買う合理性）
3. **用途別の重みづけ**（義実家／取引先／職場ばらまき／自分ご褒美／友人宅）
4. **NG表現の排除**（神・優勝・バズる・絶対買って・沼る・やばい・秒で買うべき）
5. **必ず「向く人」と「向かない人」を分ける**
6. **個人実名・所属（秋坂洋三郎、お土産お菓子研究所など）は一切登場させない**
7. **PR・提供品は明示**
8. **実食していない商品を断定レビューしない**

## 新しいモードを追加したい時

1. `_template.md` をコピーして `<mode_id>.md` にリネーム
2. フロントマター（`---` 内）の `mode_id`, `name`, `data_source`, `post_count` を埋める
3. 「役割定義」「分析手順」「投稿フォーマット」「NGルール」「出力例」を書く
4. この `README.md` の表に1行追加
