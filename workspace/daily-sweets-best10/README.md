# Daily Sweets ベスト10 ── 朝7時定時実行 SNS投稿システム設計書

> お土産お菓子研究所-GINZA-（秋坂洋三郎）のX投稿を毎朝7時に自動でドラフト生成する仕組み。
> 実際の商品写真＋10秒動画つき投稿を前提に設計。**設計・文面・絵コンテ生成までは無料**、動画の実生成のみクレジット消費（承認制）。

## 全体フロー

```
毎朝 7:00 JST（定時実行 Routine / cron: 0 22 * * * UTC）
   ↓
① リサーチ：Web検索で本日のスイーツ・お土産菓子の話題を収集
   （楽天スイーツデイリーランキング / 新商品ニュース / 季節催事 / SNSトレンド）
   ↓
② ベスト10選定（下記の選定基準）
   ↓
③ X投稿文ドラフト生成（投稿テンプレート準拠）
   ↓
④ 10秒動画の絵コンテ＋生成用プロンプト作成（カウントダウン形式）
   ↓
⑤ 各商品の「実際の写真」入手先リスト作成（公式EC・プレスリリースのURL）
   ↓
⑥ 朝7時に通知 → ユーザーが内容確認
   ↓
⑦ ユーザーが「生成OK」と返信 → 10秒動画を生成（ここだけ有料）→ 投稿
```

## 設計の4軸（Claude Code入門ガイドの「タスク解体テンプレ」準拠）

| 軸 | 内容 |
|----|------|
| インプット | Web検索結果（当日のランキング・新商品情報）＋ 📚ナレッジ/コンテンツナレッジ の3ファイル |
| アウトプット | 投稿文ドラフト・ランキング表・10秒動画絵コンテ・写真入手先リスト → 毎朝の通知として届く |
| スコープ | ドラフト生成まで。**動画の実生成・実投稿はユーザー承認後のみ**。他者の写真の転載は提案しない |
| ゴール | 商品名・価格・販売状況に「要確認」フラグ付きで、朝7時にそのまま確認できる状態で届いたら完了 |

## ベスト10の選定基準

1. **実在確認が取れる商品のみ**（公式ECまたはメーカー公式ページのURLが見つかること）
2. 当日性：新商品・季節限定・催事出品・SNSで言及増のいずれかがあること
3. ジャンルバランス：和菓子／洋菓子／ご当地限定を混在させる（同一メーカー2品まで）
4. 順位根拠を1行で言えること（例：楽天デイリー◯位、◯月◯日発売、◯◯催事出品中）
5. 確認できない数値・価格は「要確認」と明記し、推測で埋めない

## X投稿テンプレート

Xアルゴリズム2026攻略ナレッジ準拠：**動画10秒（Quality Video Viewの境界値）／1日1本に集中（連投減衰対策）／保存・共有したくなる判断基準つきリスト（リンクコピー+20狙い）**

```
【本日のお土産お菓子ベスト10】◯月◯日版

10位→1位を10秒でどうぞ🎥

1位の「◯◯」は◯◯（順位根拠を1行）。

保存しておくと帰省・出張の手土産選びに迷いません。

詳細はリプ欄に👇
（動画添付）
```

リプ欄（セルフリプ1本のみ・連投しない）：
```
📋全ランキング
1位 商品名（メーカー／地域）─ 選定理由1行
2位 …
（10位まで）
※価格・販売状況は各公式ページでご確認ください
```

## 10秒動画設計（カウントダウン形式）

参照：おのだまーしー氏のX投稿動画（https://x.com/ma_shi_onoda/status/2087884294374994090 ※本環境からはx.comへのアクセスが制限されており直接確認不可。実物確認後に下記絵コンテを調整すること）

| 時間 | 内容 | テロップ |
|------|------|---------|
| 0.0–1.2秒 | タイトルカード（ロゴ＋日付） | 「今日のお土産お菓子ベスト10」 |
| 1.2–6.1秒 | 10位→4位（各0.7秒）：商品写真全面＋順位数字 | 「10位 商品名」…（大きく短く） |
| 6.1–7.9秒 | 3位・2位（各0.9秒）：写真ズームイン | 「3位 商品名」「2位 商品名」 |
| 7.9–10.0秒 | 1位発表（2.1秒）：ドラム→写真＋理由1行 | 「1位 商品名」「＋選定理由」 |

- 縦型 9:16 ／ テロップは上下セーフエリア内 ／ 音無しでも伝わる構成（サイレント視聴前提）
- 生成手段：**MiniMax H3**（Higgsfield `generate_video` model `minimax_h3`、9:16・10秒対応／代替: Comfy Cloud `partner_generate` model `minimax/hailuo-03-t2v`）。スタイル指定は `skills/mascot-explainer-video/SKILL.md` の生成プロンプト参照（**1本ごとにクレジット消費のため、生成前に必ずユーザー承認を取る**）
- 素材写真が揃わない日は、写真が確認できた商品だけで「ベスト5」に縮小して成立させる

## 実際の写真の運用ルール（権利面・重要）

- ✅ 使ってよい：自前で撮影した写真／メーカーが報道・二次利用向けに公開しているプレスリリース素材／自社に提供された素材
- ⚠️ 条件付き：公式ECの商品画像は各サイトの利用規約次第。ドラフトには「入手先URL」のみ記載し、利用可否はユーザーが判断
- ❌ 提案しない：他のSNSユーザーの投稿写真の転載・スクリーンショット流用
- 毎朝のドラフトには各商品の「写真入手先URL」を添え、実際に使う写真の確定はユーザーが行う

## コスト設計（「無料でつくる」の範囲）

| 工程 | コスト |
|------|--------|
| 定時実行・リサーチ・投稿文・絵コンテ・写真リスト | 無料（Claudeの利用枠内） |
| 10秒動画の実生成（kling/higgsfield） | クレジット消費 → **毎回ユーザー承認後のみ実行** |
| 投稿作業 | ユーザーが手動投稿（X APIの自動投稿は将来拡張） |

## 運用開始・停止

- 定時実行は Routine（cron `0 22 * * *` UTC ＝ 毎朝7:00 JST）として登録済み
- 停止・時刻変更はセッションで「Daily Sweetsの定時実行を止めて／◯時に変えて」と依頼すれば変更可能
