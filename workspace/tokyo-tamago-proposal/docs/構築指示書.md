## 0. ゴール

株式会社東京玉子本舗向けのB2B提案書を、1ページ縦スクロールのWebアプリとして実装する。用途は「商談時のデモ表示」と「送付後の補助資料」。最終的に `npm run build` が通り、`dist/` を静的ホスティングにそのまま置ける状態にすること。

## 1. 技術要件

- Vite + React + TypeScript + Tailwind CSS + recharts
- 静的SPA・1ページのみ。ルーティング、状態管理ライブラリ、バックエンド、DBは導入しない
- localStorage / sessionStorage は使わない（状態はReact stateのみ）
- スマホ（375px）〜デスクトップまでレスポンシブ対応
- セットアップから自分で実行すること（`npm create vite@latest` から）

## 2. デザイン指針

- 基調色: 焦がしキャラメル系ブラウン `#8A5A2B`、見出し濃茶 `#3D2B1F`、背景は白〜生成り `#FBF7F1`、表ヘッダ `#F3E7D8`
- 和菓子・洋菓子メーカー向けの落ち着いた品格。装飾アニメーションは禁止（フェードイン程度まで）
- フォント: `"Yu Gothic", "Hiragino Sans", "Noto Sans JP", sans-serif`
- 絵文字・派手なグラデーション・影の多用は禁止

## 3. 共通機能

### 3-1. 簡易閲覧制限
- URLクエリ `?key=tamago2026` が一致しない場合、本文を表示せず「閲覧用URLをお持ちの方のみご覧いただけます」とだけ表示する
- キーは定数 `ACCESS_KEY` として1箇所にまとめる（後で差し替えるため）

### 3-2. 追従CTAバー
- スクロール量が300pxを超えたら画面下部に固定バーを表示
- 内容: 「無償トライアル（毎月3社限定・6/30締切）」の文言＋「申し込む」ボタン（→ §11のmailto C と同じリンク）＋「サンプルを請求」ボタン（→ mailto A）

### 3-3. 印刷対応
- `@media print` でCTAバー・閲覧制限UIを非表示、各章の途中で改ページしないよう `break-inside: avoid`、背景色は印刷でも出るよう配慮（出ない場合は罫線で代替）

### 3-4. プレースホルダ管理
- 提案者の社名・担当者名・メールアドレス・電話番号は定数オブジェクト `SENDER` に集約し、未設定なら画面上に赤字で「【要記入】」と表示する
  ```ts
  const SENDER = { company: "", dept: "", name: "", email: "", tel: "" };
  ```

### §1 エグゼクティブサマリー
本提案は、貴社3ブランド（銀座たまや・N.Y.C.SAND・CARAMER）に関するSNS・ECレビュー上の公開投稿をAIで構造化し、「どこで買えるのか」「お取り寄せしたい」という需要シグナルを週次で定量化するレポートサービスのご提案です。

貴社のN.Y.キャラメルサンドは、限定販路と行列が生む希少性そのものがブランド価値となっている一方、その裏側では全国に「買いたくても買えないお客様」の声が日々SNSに蓄積されています。この声は、催事出店エリアの選定、オンラインショップの在庫計画、新販路の判断材料として最も確度の高い一次データですが、現状これを継続的・定量的に捕捉する仕組みは一般的なSNS分析ツールでは実現できません。

私たちは土産菓子・お取り寄せスイーツに特化した独自の文脈分類技術（贈答・入手難・お取り寄せ要望の判別）により、この声を毎週月曜の朝、A4数枚のレポートとしてお届けします。ダッシュボードの操作は一切不要です。

**ご判断いただきたいことは一つだけです。** 4週間・費用ゼロ・契約義務なしの無償トライアル（毎月3社限定）にお申込みいただくか否か。詳細は最終章「次のステップ」をご覧ください。

### §2 背景認識：土産菓子市場とSNSの現在地
観光市場はインバウンド・国内旅行ともに力強い回復を見せており、土産菓子は再び成長市場に位置しています。同時に、購買行動の起点は「売場での偶然の出会い」から「SNSで見た・もらって知った」へと比重を移しつつあります。

土産菓子には他の食品カテゴリにない特徴があります。それは「購入者と消費者が異なる」ことです。贈られた側が商品を知り、気に入り、次の購入者になる。この転換の瞬間、人は必ず「どこで買えるの？」と検索し、SNSに投稿します。この瞬間を捕捉できるかどうかが、土産菓子のEC・催事戦略の精度を左右します。

### §5 ご提案：需要シグナル週次レポートサービス
**5-1. サービス概要**
X（旧Twitter）・Instagram・主要ECモールのレビューから貴社商品への言及を収集し、土産菓子特化のAI分類エンジンで「商品 × 文脈 × 地域 × 感情」に構造化。アナリストが監修した週次レポートを毎週月曜朝にメールでお届けします。貴社側でのツール操作・学習コストはゼロです。

**5-2. レポートに含まれる内容**

| 項目 | 内容 | 活用される意思決定 |
|---|---|---|
| 需要シグナル推移 | 「買えない」「通販してほしい」言及の週次推移と急増アラート | EC在庫計画・増産判断 |
| 需要の地理分布 | 言及者の推定所在地マップ（販売エリアとの乖離を可視化） | 催事出店エリア・新販路選定 |
| 文脈別UGC分析 | もらった／手土産／自分用／実食感想の構成比と代表的な生の声 | 商品開発・パッケージ・販促 |
| シェアオブボイス | 競合ブランドとの言及シェア比較（CARAMER向け） | 認知施策の効果検証 |
| イベント相関 | 連休・物産展・メディア露出と言及量の相関 | 投稿・在庫タイミング最適化 |

**5-3. 当社の差別化：土産菓子特化の分類技術**
汎用のソーシャルリスニングツールは、言及の「量」と「ポジネガ」しか測れません。当社は土産菓子業界専用の語彙辞書（贈答語彙・入手難語彙・表記ゆれ・混同リスク）を構築し、最新の生成AIで投稿1件ごとに文脈を判定します。例えば「ニューヨーク」「キャラメル」「サンド」を含む無関係な投稿の除外や、「実家の母が送ってくれた」という受贈文脈の判別は、この特化設計でのみ実現できます。

### §6 費用対効果の考え方
本サービスの年額費用は、3ブランドパックで90万円（月額75,000円×12ヶ月）です。これは「年に一度、判断の精度が一段上がれば回収できる」水準に設定しています。
- **催事出店の精度**：百貨店催事・物産展は1出店あたりの売上・コストともに大きく、出店エリアの選定を需要の地理分布データで裏づけられれば、判断1回分の改善で年額費用を上回り得ます。
- **ECの機会損失防止**：「通販してほしい」言及の急増アラートにより、欠品・在庫過小による販売機会の取りこぼしを早期に検知できます。
- **施策効果の検証**：メディア露出やSNS施策の前後で言及量・文脈がどう動いたかを定点観測でき、次の投資判断の根拠になります。

なお、上記は試算の枠組みであり、貴社固有の数値は無償トライアルの実データでご確認いただく前提です。効果が見込めないと判断された場合、トライアル終了とともにご縁がなかったものとして構いません。

### §7 データの取扱いとセキュリティ方針
本サービスは、SNS・ECモール上で一般公開されている投稿のみを各プラットフォームの正規の方法で取得・分析します。貴社の顧客情報・販売データ・社内システムへの接続は一切不要であり、貴社からお預かりするのは分析対象の商品名リストのみです。レポートに掲載する投稿引用は要旨化し、投稿者個人が特定される情報は除去します。
