# CLAUDE.md

東京玉子本舗向け「SNS需要シグナル分析サービス」提案マイクロサイト。
B2B提案書を1ページ縦スクロールのWebアプリにしたもの。用途は商談デモと送付後の補助資料。
詳細仕様と提案書全文は `docs/構築指示書.md` を参照（本文の正本はそこ）。

## コマンド

- 開発: `npm run dev`
- ビルド検証: `npm run build`（変更後は必ず実行してから完了報告すること）
- 型チェック: `npx tsc --noEmit`

## 技術構成

- Vite + React + TypeScript + Tailwind CSS + recharts
- 静的SPA・1ページのみ。ルーター / 状態管理ライブラリ / バックエンド / DB は導入しない
- localStorage / sessionStorage 禁止。状態は React state のみ

## 重要な定数（src/config.ts に集約）

- `ACCESS_KEY`: 閲覧キー。URLクエリ `?key=` と一致しないと本文非表示
- `SENDER`: 提案者情報（社名・部署・氏名・メール・電話）。空欄の項目は画面に赤字「【要記入】」を表示する仕様。この挙動を消さないこと
- mailto の宛先・件名・本文プリセットは `SENDER.email` を参照

## 絶対ルール

1. **提案書本文（§1〜§11）の文言を改変・要約・追加しない。** 営業文書の正本であり、一字の違いが信頼に関わる。修正はユーザーの明示指示がある場合のみ
2. **デモチャートはダミーデータ。** 「※ダミーデータです」の注記を削除・縮小しない。実データ風に見せる変更は拒否して確認を取る
3. 顧客名（東京玉子本舗）入りの内容のため、外部トラッキング・解析タグ・第三者CDNへの依存追加は禁止
4. 価格・期限（6/30締切・毎月3社限定）・無償条件の数字を触る変更は、必ず変更前にユーザーへ確認

## デザイントークン

- 基調: `#8A5A2B`（焦がしキャラメル）/ 見出し: `#3D2B1F` / 背景: `#FBF7F1` / 表ヘッダ: `#F3E7D8`
- フォント: `"Yu Gothic", "Hiragino Sans", "Noto Sans JP", sans-serif`
- 落ち着いた品格を維持。装飾アニメーション・絵文字・派手なグラデーション禁止
- UIコピーに「〜と言えるでしょう」等のAI定型文を使わない

## 必須機能（壊さないこと）

- 閲覧キーゲート（key不一致時は案内文のみ表示）
- 追従CTAバー（スクロール300px超で表示、print時は非表示）
- `@media print` 対応（CTAバー非表示・`break-inside: avoid`・PDF出力で稟議資料になる品質）
- スマホ375px幅で表が崩れない（横スクロール許容）

## 変更時のチェックリスト

- [ ] `npm run build` が通る
- [ ] `?key=` なしで本文が見えない
- [ ] 印刷プレビューでレイアウトが破綻していない
- [ ] §1・§11 の本文が `docs/構築指示書.md` と一致している
