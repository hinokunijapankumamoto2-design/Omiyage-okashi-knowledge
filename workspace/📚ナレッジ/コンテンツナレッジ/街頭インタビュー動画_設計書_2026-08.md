## 1. SNS調査サマリー（2026年8月時点）

本動画の設問は、以下の一次リサーチから逆算して設計した。思いつきの街頭質問ではなく、**いま実際に起きている消費者行動のズレ**を拾いにいく設計である。

### 1-1. 「自分で食べるスイーツ」側で起きていること

| 論点 | 事実 | 出典系統 |
|---|---|---|
| 食感トレンド | 10代女子が好む食感は「もちもち」が **47.6%** で断トツ1位 | ぐるなび通信 2026スイーツ特集 |
| 情報接触経路 | 流行を知るきっかけの **85.1% がSNS経由** | 同上 |
| 具体トレンド | もちもち食感（わらび餅・生グミ・求肥）、フルーツそっくりスイーツ、韓国発「3Dアイス」、ドバイもちクッキー、バタートック | ぐるなび通信 / weblabo / TikTok |
| 拡散フォーマット | 「切る」「割る」瞬間の**断面 × ASMR動画**が拡散の主軸 | TikTok / Instagram リール |
| 定番化した例 | バスチー（バスクチーズケーキ）＝「映え」と「美味しさ」の両立でブーム後も棚に残った | マーケ畑 |

**要点**: 自分用スイーツの購買は、**新食感 × 短尺動画映え**でほぼ決まっている。

### 1-2. 「贈る土産菓子」側で起きていること

| 論点 | 事実 |
|---|---|
| 定番の強さ | クッキー・フィナンシェ・チョコレートが手土産の標準формат（＝安全牌）として維持 |
| 差別化軸 | パッケージデザインとトレンド性の比重が上昇。イベント限定の**缶（缶活）**が有力フック（例：銀座のパティスリー限定デザイン缶） |
| ご当地軸 | 土地限定・地元素材は「会話のネタになる」ことで選ばれる |
| SNS発の越境 | SNSでバズった菓子（例：カンロ ヒトツブカンロのグミッツェルBOX）がそのまま手土産候補に流入 |

**要点**: 贈答は依然として**定番・失敗しないこと**が優先。ただしSNS発の商品が越境してきている。

### 1-3. 導かれた仮説（＝本動画の設問）

> **同一人物の中で、「自分用」と「贈答用」の判断基準は分裂している。**
> 自分用は "新食感・映え" で買うのに、人に贈る瞬間だけ "定番・無難" に退避する。

この分裂こそが、地方老舗土産菓子メーカーにとっての**棚取りの空白**である。
街頭インタビューでこのズレを本人の口から言わせることが、本動画の唯一の目的。

## 3. 生成パイプライン

```
[ステップ1] キーフレーム画像生成 … Higgsfield Soul 2.0 (soul_2) / 9:16 / 2K
        ↓ job_id をそのまま参照渡し
[ステップ2] 動画化 … MiniMax H3 (minimax_h3) / image-to-video / 10秒 / 9:16 / 2K
```

### 実行記録（2026-08-08）

| 工程 | モデル | job_id | コスト |
|---|---|---|---|
| キーフレーム | `soul_2`（Higgsfield Soul 2.0） | `2e2d6a26-fac7-4c36-814a-e0125d50f73b` | — |
| 動画 | `minimax_h3`（MiniMax H3） | `572b8c67-2dde-447d-a04e-30fcd3765cda` | 40クレジット |

### 当初計画からの変更点

当初は **Comfy Cloud でキーフレーム → MiniMax で動画化** の構成を予定していたが、
Comfy Cloud 側が `Partner-node workflows require a paid subscription` を返し、
partner ノード（Seedream / Flux / Nano Banana 等）の実行が拒否された。
※ ジョブはキューに入っておらず（running 0 / pending 0）、**課金は発生していない**。

→ パイプラインの形（キーフレーム → MiniMax）は維持したまま、
キーフレーム生成のみ Higgsfield Soul 2.0 に差し替えて実行した。
Comfy Cloud の有料サブスクリプションを有効化すれば、当初構成に戻せる。

## 4. 既知の制約・次の検証項目

1. **音声**: `minimax_h3` は `generate_audio` パラメータを持たない。日本語セリフはプロンプト内で指定しているが、
   発話音声が乗るかは要検証。乗らない場合は以下のいずれかで対応する。
   - ElevenLabs 等で日本語VOを別生成し、後工程で合成
   - `generate_audio` を明示的に持つモデル（`flux_3_video` / `seedance_2_0` / `kling3_0`）へ切り替え
2. **カット数**: 本テストは1カット。本番は「導入1＋回答3〜5」の構成に拡張する。
   その際は各カットのキーフレームを同一人物指定で生成し、`start_image` 参照で人物ブレを抑える。
3. **テロップ**: 設問テロップ（例：「お土産のお菓子、何を基準に選ぶ？」）は生成に焼き込まず後工程で追加する。
   焼き込むと修正コストが跳ね上がるため。
4. **ネットワーク**: 本実行環境では生成物CDN（`d8j0ntlcm91z4.cloudfront.net`）が
   ネットワークポリシーで遮断されており、リポジトリへのバイナリ格納はできない。
   成果物はURLと job_id で管理する。
