## 6. 全バリエーション共通の必須要素

### 6-1. 必ず含めること（MUST）

- スイーツ王子の**顔・髪型は厳密に維持**（`character_reference/portrait_main.png` の人物）
- メインコピー（明朝体・大きく目立つ位置）
- サブコピー（メインコピーの下、補足的に）
- 各バリエーションのテーマカラーの統一
- 線画アイコン（手描き風・上品なライン）
- 余白の確保（ミニマリズム）

### 6-2. 絶対に避けること（NG）

- ❌ 王子の顔・髪型の変更
- ❌ 4バリエーション以外の独自アレンジ衣装（仕様外）
- ❌ ポップでカジュアルすぎる装飾
- ❌ 過剰な絵文字・記号の使用
- ❌ 安価に見える写真合成感
- ❌ 4バリエーション間での書体の統一性欠如
- ❌ メインコピーが小さすぎる／読めない
- ❌ アイコンが具象的すぎる（写実的なフォト調はNG）

## 15. 投稿用サムネ生成の必須4原則（第5版・大前提）

すべての Threads 投稿用画像生成において、以下4原則を**必ず守る**こと。

### 15-1. 投稿文にマッチした画像を生成する
- 投稿のテーマ・季節感・トーンに合致したカラー・装飾・キャッチコピーを選定
- 既製テンプレートの流用ではなく、投稿内容ごとに最適化

### 15-2. デザイン素材から自由な発想で画像設計する
- `character_reference/スイーツ王子コレクション/sheet1〜sheet3` の全素材を活用
- 素材の組み合わせ・配置は固定パターンに縛られず自由設計
- ゾーン分離・テキスト幅検証・フォトフレーム化のプロ設計原則は厳守

### 15-3. 必ずスイーツ王子を登場させる
- 顔・髪型は `character_reference/portrait_main.png` および `スイーツ王子投稿画像.png` の人物と100%同一に保つ
- 原本から抽出した王子写真をフォトフレームで使用（顔の再生成は禁止）
- 衣装はバリエーション可（`character_spec.md` のワードローブ参照）

### 15-4. 投稿文を分析して KEY POINTS 3つを記載

#### 必須ルール（強化版・2026-05-05）

##### A. 抽出原則：投稿文の具体事実から3つを取り出す
- **抽象的アドバイスではなく、投稿に書かれている具体名・日付・場所を優先**
- 「定番＋新作で空気が変わる」のような汎用論ではなく、**投稿に登場した個別商品・ブランド・店舗・期間・価格**を抽出
- 投稿テキストに無い情報は載せない（捏造禁止）

##### B. 抽出フロー（必ずこの順）
1. 投稿文から **固有名詞** を全列挙（商品名・ブランド名・店舗名）
2. 各固有名詞に紐づく **日付・場所・期間** を抽出
3. 商品が3つ以上ある場合 → 各商品をそのまま KEY POINTS に
4. 商品が2つの場合 → 商品2つ＋ポイントになる注意点1つ
5. 商品が1つの場合 → その商品の3要素（日付・場所・特徴）

##### C. 表記ルール
- 行頭に **お菓子アイコン**（マカロン／ケーキ／タルト／プディング／ティーカップ）
- 番号①②③は使わない
- セクション見出し：`KEY POINTS`（金色・小キャプション体）

##### D. 良い例（投稿事実ベース）

投稿に「トリプルデッカーロンドン 4/22 大丸東京1F」「SHIROÉ by Hugh Morgan 3/5 グランスタ東京」「バタークグロフ レモン 〜5/17 期間限定」とある場合：

```
🍪 トリプルデッカーロンドン｜4/22 大丸東京1F NEW
🍰 SHIROÉ by Hugh Morgan｜3/5 グランスタ東京 NEW
☕ バタークグロフ レモン｜〜5/17 期間限定
```

##### E. 悪い例（汎用論・抽象論で抽出失敗）

```
🍪 定番に「今年から」を1個添える          ← 抽象すぎ・固有名詞なし
🍰 新オープン2つ ＋ 期間限定1つ           ← 数だけで具体名なし
☕ 年齢・移動時間・温度帯で選ぶ            ← 投稿の補足軸であり主役ではない
```

→ **読者が画像だけで「何の話か」を即把握できないため不合格**

##### F. 自己問答（毎回・公開前必須）

## 16. URL検証プロトコル（第6版・絶対遵守）

### 背景

2. **記憶・推測のURLは禁止**
   - 「以前あったはず」「多分このパス」で書かない

   - `tokyoeki-1bangai.co.jp/tokyogiftpalette` のような曖昧パスは禁止

5. **投稿直前の最終チェック**
   ```bash
   python threads-tool/url_verify.py --from-text post.txt
   ```
   全URL 200 を確認した後でのみ `threads_api.py post` 実行
