# 元記事の分析サマリー

## 1. 記事の核心主張（3行）
1. Xのおすすめ欄は投稿の「品質点」を付けているのではなく、**「この人にこの投稿を見せたら次に何をするか」を行動別に予測し、重み付き合計**でランキングしている（おすすめ度 = Σ 行動確率 × 行動の重み）。
2. 軽い反応（いいね +0.5）より**人を動かす行動（リンクコピー +20、リプライ +5、フォロー +4）を強く評価**し、強い拒否反応（報告 −234、ミュート −58.8、ブロック −31.2）を極端に重く見る。
3. ランキング（加点減点）とは別に**可視性フィルター（候補から削除）**があり、点数がいくら高くても資格を失えばおすすめには出ない。

## 2. 事実検証（2026-08-15実施）

**公開自体は事実。** Xのアルゴリズムは2026年1月に [xai-org/x-algorithm](https://github.com/xai-org/x-algorithm) としてGitHubで公開され、2026年8月中旬のアップデートでランキングの具体的な重みが公開された。記事の「8月12日」は媒体により12〜14日と表記が揺れるが、重み公開のアップデートを指すと見て整合する。

**主要数値は複数の二次情報と一致：**
- リンクコピー +20.0 / リプライ +5.0 / フォロー +4.0 ✓
- 相互フォローの追加ブースト +15（+20から調整） ✓
- 報告 −234 / ミュート −58.8 ✓（「報告1件はいいね468回分」＝234÷0.5の換算も他媒体の表現と一致）
- Phoenix（Grok系Transformerベースのランキングモデル）の存在 ✓

**未検証（一次ソースのコード確認まではしていない）：** 連投減衰の具体係数（0.625/0.4375/下限0.25）、DPP 0.65、フォロー外0.75倍、48時間フィルター、Cold Start条件（フォロワー1,000以下・15〜16番目・上位85%）、動画10秒境界、dwell +0.004。記事の他の数値の正確性から信頼度は高いが、引用時は「公開コードのデフォルト値」と限定すること。

## 3. 記事の質の評価

### 評価できる点
- **期待値構造の誤読を先回りで潰している。** 「リンクコピー1回＝いいね40回」「報告1件＝468いいね分を消す」という典型的な誤解に対し、「重みに掛かるのは実際の行動数ではなく予測確率」と2度にわたり訂正している。この種の解説記事で最も多い誤りを避けている。
- **「ミュート > ブロック」の説明が妥当。** 重みは行動の強さだけでなく発生頻度（希少性）で調整されるという指摘は、推薦システムの実装慣行として合理的。
- **「減点」と「候補除外」を区別。**「フォロワーには見えるのにおすすめに出ない」状態を、点数の問題ではなく資格の問題として説明できている。これは伸び悩み診断の実務で最も重要な切り分け。
- **Cold Startを救済措置と誤解させない。** 「上位85%に入っている投稿だけがテスト枠に乗る」と限定し、「小さければ何でも押し上げられる」という楽観を排除している。

### 限界・注意点
- **数値はデフォルト値であり固定ではない。** 相互フォローブースト自体が+20→+15と短期間で調整された実例を記事自身が示している。数ヶ月後には別の値になりうる前提で使う。
- **公開コードと本番環境の乖離可能性。** 実験グループ条件（24時間以内など）が明記されている通り、全ユーザーに同一の挙動が適用される保証はない。
- **重みの絶対値比較はそれ自体がミスリードになりうる。** 行動確率のスケールが行動ごとに大きく異なるため（リンクコピーは稀、いいねは頻繁）、「+20だからリンクコピーを狙え」と単純化はできない。狙うべきは確率を上げられる設計。

# お土産お菓子業界への転用

## 発信設計への5つの含意

### 1. 「保存・共有される実用情報」がリンクコピー予測を上げる
+20のリンクコピーは「誰かに教えたくなる」行動。お土産ジャンルでは「新幹線改札内で買える手土産5選」「日持ち2週間以上の帰省土産」のような**判断基準つきリスト**が共有動機を作りやすい。感想投稿より判断基盤の提供。

### 2. リプ営業の構造的無効化 → オリジナル投稿一本足
フォロー外のリプライは候補除外されるため、大手グルメアカウントへのリプで新規露出を取る戦略は成立しない。フォロー外に届く唯一の経路は0.75倍を跳ね返せる強いオリジナル投稿。

### 3. 連投減衰 → 「1日1本の強い投稿」への集中
催事情報などを1日に何本も投稿しても、2本目以降は0.625倍から減衰する。新商品情報をまとめて1本の比較形式にする方が構造に合う。

### 4. 相互フォロー+15 → 業界内の相互関係が配信資産になる
メーカー・売場担当者・同業発信者との相互フォローは、営業上の関係構築と同時に配信ブーストとして機能する。ただし効くのはオリジナル投稿のみ。

### 5. Cold Start → 小規模期は「投稿直後の反応設計」が全て
フォロワー1,000以下のテスト露出枠で反応が出なければ止まる。投稿直後にリプが付きやすい問いかけ・引用したくなる論点をXポスト攻略ナレッジのフック技術と組み合わせて設計する。48時間フィルターと合わせ、投稿タイミングはターゲット（帰省客・出張客）がXを見る時間帯に厳密に合わせる。

## 避けるべきこと（ネガ予測の回避）
- 過剰な売り込み・恐怖訴求の連発は「ミュートしたくなる投稿」の予測確率を上げる（−58.8）。Xポスト攻略ナレッジの do_not_use_for と同方向。
- 同一テンプレの機械的量産は連投減衰＋DPP調整＋ミュート予測の三重で不利。

## Grok先回りリサーチナレッジとの接続
- 裏ワザ1（初速検出）の「初速が異常な投稿はまだおすすめ欄に乗り切っていない」という仮説は、本ファイルのCold Start・48時間・予測ベースの構造と整合する。特に「投稿直後の反応がその後のテスト露出通過を決める」という機構は、初速を追う合理性の裏付けになる。
- 一方で「本人比」分析（裏ワザ8・10）の重要性は本ファイルでさらに強まる。アルゴリズムはユーザー個人の反応履歴を入力にしており、伸びる型がアカウント固有になるのは構造的必然。
