# Knowledge Creator セットアップガイド

## はじめに

Knowledge Creator は、あなたの実績・文体・商品情報・コンテンツの成功法則をAIに深くインストールするためのスキルです。

このガイドでは、ダウンロードしたファイルをAIツールにセットアップする手順を説明します。

---

## 同梱ファイル一覧

```
Knowledge_Creator_配布用/
├── knowledge-creator.md              ← メインスキル（ナレッジ構築用）
├── knowledge.md                      ← 簡易追記コマンド（情報の追加・更新用）
├── セットアップガイド.md              ← このファイル
└── knowledge-creator/
    └── references/
        ├── personal-knowledge-guide.md   ← パーソナルナレッジ構築ガイド
        ├── product-knowledge-guide.md    ← プロダクトナレッジ構築ガイド
        ├── content-knowledge-guide.md    ← コンテンツナレッジ構築ガイド
        ├── quality-standards.md          ← 品質基準 参考例集
        ├── persona-template.md           ← ペルソナ分析テンプレート
        └── output-templates.md           ← ナレッジ出力テンプレート集
```

## セットアップ手順

### Claude Code（クロード・コード）の場合【推奨】

**Step 1: ファイルの場所を確認**

ダウンロードしたファイルは通常「ダウンロード」フォルダに入っています。
- Mac: `~/Downloads/`
- Windows: `C:\Users\あなたの名前\Downloads\`

**Step 2: 隠しフォルダを表示する**

`.claude` フォルダは隠しフォルダのため、通常は見えません。

- **Mac**: Finder を開いて `Command + Shift + .`（ピリオド）を押す
- **Windows**: エクスプローラーの「表示」タブ→「隠しファイル」にチェック

**Step 3: ファイルを配置する**

Claude Code の作業フォルダ（普段 Claude Code を使っているフォルダ）を開き、以下の場所にファイルを置きます:

```
あなたの作業フォルダ/
└── .claude/
    └── commands/              ← ここに入れる
        ├── knowledge-creator.md        ← ドラッグ&ドロップ
        ├── knowledge.md                ← ドラッグ&ドロップ
        └── knowledge-creator/          ← フォルダごとドラッグ&ドロップ
            └── references/
                ├── (6ファイル)
```

1. `knowledge-creator.md` を `.claude/commands/` にドラッグ&ドロップ
2. `knowledge.md` を `.claude/commands/` にドラッグ&ドロップ
3. `knowledge-creator/` フォルダを丸ごと `.claude/commands/` にドラッグ&ドロップ

> `.claude/commands/` フォルダがない場合は、自分で作成してください。

**Step 4: 動作確認**

Claude Code を起動し、以下のコマンドを入力:

```
/knowledge-creator
```

「どのナレッジを構築しますか？」と表示されれば成功です。

---

### Codex（OpenAI）の場合

1. `knowledge-creator.md` の内容をすべてコピー
2. Codex で「以下のスキル定義に従って動いてください」と入力し、コピーした内容を貼り付け
3. または `AGENTS.md` に配置して自動読み込み

---

### Cursor / Windsurf の場合

1. `knowledge-creator.md` を各ツールのルールファイルとして配置:
   - **Cursor**: `.cursor/rules/` フォルダに配置
   - **Windsurf**: `.windsurfrules` として配置
2. AIに「ナレッジ構築して」と入力すればスキルが起動

---

### その他のAIツールの場合

1. `knowledge-creator.md` の内容をすべてコピー
2. AIとの会話の最初に「以下のルールに従って動いてください」と入力し、コピーした内容を貼り付け
3. references フォルダ内のファイルも必要に応じて追加で読み込ませる

---

## 使い方

### ナレッジを構築する（初回）

```
/knowledge-creator
```

AIが対話形式でヒアリングを進めます。質問に答えていくだけでナレッジファイルが完成します。

### ナレッジを追記・更新する（日常）

```
/knowledge [追加したい情報]
```

または単に「Knowledge」と入力して情報を投げるだけでOK。AIが最適な場所に自動で格納します。

## よくある質問

**Q: .claude フォルダが見つかりません**
A: 隠しフォルダです。Mac は `Cmd+Shift+.`、Windows は「隠しファイルを表示」で見えるようになります。それでもない場合は、自分で `.claude/commands/` フォルダを作成してください。

**Q: /knowledge-creator と入力しても何も起きません**
A: ファイルの配置場所を確認してください。`knowledge-creator.md` が `.claude/commands/` の直下にあるか確認してください。

**Q: 実績がほとんどないのですが使えますか？**
A: はい。「経験の棚卸し」モードがあります。過去に人に教えたこと、得意なこと、学んできたことから強みを抽出します。競合の分析からポジショニングを言語化するサポートもあります。

**Q: 一度で全部入力しないとダメですか？**
A: いいえ。段階的に育てていけます。最初は最低限の情報でナレッジを作り、新しい実績や気づきが増えたら `/knowledge` で追記してください。

**Q: Claude Code 以外のツールでも使えますか？**
A: はい。Codex、Cursor、Windsurf、その他のAIツールでも使えます。上記の各ツール向けセットアップ手順を参照してください。
