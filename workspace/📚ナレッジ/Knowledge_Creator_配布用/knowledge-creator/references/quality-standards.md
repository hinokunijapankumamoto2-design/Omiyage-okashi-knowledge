# ナレッジ品質基準 Few-shot参考例集 v1.1

ユーザーの回答がこの参考例の「具体性」「情報密度」「熱量」に達していない場合、追加ヒアリングを行う。
**全3モード（パーソナル/プロダクト/コンテンツ）に対応。**

---

## Part 1: パーソナルナレッジ品質基準

### 1. 発信者と事業の実績

**品質基準ポイント:**
- Before/Afterが具体的な数字で示されている
- 個人実績と指導実績が明確に分離されている
- 事業規模を複数の指標で示している

**参考例:**
- 「英検3級、TOEIC250点から6ヶ月でTOEIC900点、2ヶ月で英検1級を達成」
- 「公式LINE登録者15万人以上、YouTube登録者25万人」
- 「累計5000名以上の指導実績、9割以上が何かしらの実績を達成」

**NG例:**
- 「英語が得意です」（数字がない）
- 「たくさんの人を教えてきました」（曖昧）

---

### 2. 受講生/クライアント事例

**品質基準ポイント:**
- 1人のクライアントにBefore/After/感情の3要素がある
- 具体的な数字（期間、スコア、売上）が含まれている
- 感情面のエピソードが生々しい
- 最低3名以上の事例がある

**参考例（N=1の書き方）:**
```
佐藤さん（IT関連会社経営）
- Before: 20年間のブランク。文法の基礎もほとんど覚えていない
- After: 1年以内で英検3級、準2級、2級を取得
- 感情: 「最後の頼み綱くらい」の気持ちで申し込んだ
```

**NG例:**
```
佐藤さん
- 成果が出ました
- 満足しています
```

---

### 3. 発信戦略

**品質基準ポイント:**
- テーマとターゲットが明確
- 独自の切り口が具体例付き
- ビジョンと想いが言語化されている

**参考例:**
- 切り口: 「〇〇はするな!」「【一撃で】〇〇する方法」「【知らないとヤバい】」
- コンセプト: 「本質に基づいた最短ルートでの習得支援」
- ビジョン: 「非効率的な学習法に対し、正しい方法を示すことで学習者を目覚めさせたい」

---

### 4. CTA・特典

**品質基準ポイント:**
- 特典の内容が具体的（スライド枚数、本数など）
- 緊急性の演出（期間限定、定員制）
- 制作コストの開示で価値を演出

**参考例:**
- 「無料豪華特典15個【1523枚】+ 電子書籍3冊【1565ページ】」
- 「1000万円以上の費用、2年以上の時間をかけて作成」
- 「4日間限定の募集、定員に達し次第終了」

---

### 5. SNS発信

**品質基準ポイント:**
- 各メディアの登録者数/規模が具体的
- メディア間の役割分担が明確
- コンテンツの構成テンプレートがある

---

### 6. 文体・キャラクター

**品質基準ポイント:**
- 文末表現の出現比率が数値化されている
- 口癖が10個以上リストアップされている
- 感情表現の4パターンが具体的
- 世界観・スタンスが5つの軸で定義されている

**参考例:**
```
文末パターン:
- 断定系（60%）: 「〜です」「〜と言い切れます」「〜一択です」
- 問いかけ系（15%）: 「〜ですよね？」「〜じゃないですか」
- 共感系（10%）: 「僕もそうでした」「わかります」
- 行動喚起系（15%）: 「今すぐ〜してください」「〜しましょう」

口癖:
1. 「はっきり言います」（重要な主張の前）
2. 「ぶっちゃけ」「正直に言うと」（本音を言う場面）
3. 「これマジで大事なんですけど」（強調）
4. 「〜なんですよ」（説明の締め）
5. 「〜わけです」（論理展開の結び）
```

## Part 2: プロダクトナレッジ品質基準

### 1. 商品概要・コンセプト

**品質基準ポイント:**
- 一言で何を提供するかが明確
- USPが「他でも言えること」ではなく独自性がある
- カリキュラムが具体的なステップで記載されている

**参考例:**
- 概要: 「AI×マーケティングで月収100万円を目指す6ヶ月のオンライン講座。週1のグループコンサル+チャットサポート+200本以上の動画教材」
- USP: 「1. 現役で月商3000万円を運用するマーケターが直接指導 2. AIツール20種以上を実際の業務で使える形で提供 3. 卒業後も永久アクセス可能なコミュニティ」
- コンセプト: 「AIを使いこなす"仕組み"を作れば、1人でも月商1000万円は可能」

**NG例:**
- 「すごい講座です」（何がすごいか不明）
- 「丁寧にサポートします」（具体性ゼロ）

---

### 2. ターゲット情報

**品質基準ポイント:**
- 表面的な悩みと本質的な悩みが分離されている
- 理想の未来が「感情レベル」まで記載されている
- 避けたい未来が具体的なシーンで描写されている

**参考例:**
```
表面的な悩み: SNSで毎日発信しているが、フォロワーが増えない
本質的な悩み: 「このまま一生、成果が出ないまま頑張り続けるのか」という焦燥感

理想の未来（短期）: 3ヶ月以内にAIで発信を仕組み化し、週2時間の作業で月収50万円
理想の未来（長期）: 場所と時間に縛られず、好きな仕事で年収2000万円

避けたい未来: 1年後も同じことをやっていて、周りだけがAIで成果を出している状態
```

---

### 3. オファー・ファネル

**品質基準ポイント:**
- ファネルの各ステージが媒体・状態・ゴール・KPIで記載されている
- 特典のコピーが実際に使っている文言そのまま
- 料金の見せ方（分割、比較、保証）が具体的

**参考例:**
```
ファネルマップ:
1. 認知 → YouTube（登録者2.5万人）/ X（フォロワー1.2万人）
   状態: 「AIで稼げるらしい」レベル
   ゴール: LINE登録
   KPI: 登録率 3-5%

2. 教育 → LINE配信（7日間ステップ配信）
   状態: 「この人の言うことは信頼できそう」
   ゴール: セミナー参加
   KPI: セミナー参加率 15-20%
```

## Part 3: コンテンツナレッジ品質基準

### 1. 構成テンプレート

**品質基準ポイント:**
- 全フェーズが「骨組み（意図・目的）」と「具体（実際の文章サンプル）」の二層で記載
- 各フェーズの心理効果が言語化されている
- 再現可能なレベルの具体性がある

**参考例:**
```
Phase 1: フック（最初の15秒）
【骨組み】
- 意図: 視聴者の「自分ごと化」を促す
- 手法: 衝撃の事実 or 共感できる悩み
- 心理効果: 「え、それ自分のことじゃん」→ 続きを見る動機

【具体】
> 「AIを使ってるのに成果が出ない人、ぶっちゃけ9割がこれやってないんですよ」
再現ポイント:
1. 「〜のに〜ない」の対比構造
2. 「9割」の具体的数字で説得力
3. 「ぶっちゃけ」のフランクさで距離感を縮める
```

**NG例:**
```
Phase 1: フック
- 最初に興味を引く（←具体性ゼロ。どう引くのかが書かれていない）
```

---

### 2. 文体分析

**品質基準ポイント:**
- 文末表現が出現比率%で数値化されている
- 口癖が10個以上、使用シーン付きでリストアップされている
- 感情表現が4パターン（熱量/共感/危機感/安心感）で具体例付き

**参考例:**
```
感情表現パターン:
1. 熱量UP: 「これマジですごいんですけど」「ここだけの話ですが」
2. 共感: 「わかります、僕も最初そうでした」「それ、めっちゃわかります」
3. 危機感: 「このまま放置すると…」「気づいた時にはもう手遅れです」
4. 安心感: 「大丈夫です、ちゃんとステップがあります」「僕が全部教えます」
```

---

### 3. Few-shot Examples

**品質基準ポイント:**
- 4パート（導入/教育/共感/クロージング）が全て揃っている
- 各パートにオリジナル抜粋 + 再現ポイント3つ以上がある
- 再現ポイントが「なぜそう書くのか」の理由付き

**NG例:**
- 「導入は興味を引く内容を書く」（参考にならない抽象論）
- オリジナル抜粋なしで再現ポイントだけ書く（具体が見えない）
