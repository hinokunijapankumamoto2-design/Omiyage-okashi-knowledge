# AI組織設計: クライアント向けAI組織 実装テンプレート

> **位置づけ**: クライアント企業に「貴社専用AIチーム」として納品するAI組織の雛形
> **作成日**: 2026-04-21
> **核心思想**: 商品ではなく「組織の知能」を納品する

---

## 0. このテンプレートの使い方

### 0-1. 用途
クライアント企業（地方老舗土産菓子メーカー）に対して:
- Phase 0で業務を診断
- Phase 1で AI組織を構築（このテンプレートを企業固有にカスタマイズ）
- Phase 2で運用定着
- Phase 3以降で複利成長

### 0-2. 納品形態
- クライアント企業の社内で稼働するAI組織
- 秋坂氏は「組織の設計者・保守者」として月次伴走
- クライアント企業の従業員が日常的にAIを使う

### 0-3. カスタマイズの原則
本テンプレートは雛形。クライアントごとに以下をカスタマイズ:
- 企業の商品ラインナップ
- 主要販路とバイヤー
- 社内の組織構造
- 情報資産の4分類
- 既存システムとの連携

## 2. 指令層（Command AI）の詳細仕様

### 2-1. AI経営参謀（役員補佐AI）

**配置**: 経営会議室・社長室
**対象ユーザー**: 社長、役員、経営幹部

**ミッション**: 経営層の意思決定の速度と精度を引き上げる

**参照ナレッジ**:
- 当該企業のパーソナルナレッジ（ビジョン・実績等）
- 当該企業のプロダクトナレッジ
- 業界ドメイン・評価軸7軸
- 部門別ユースケース集（経営層セクション）
- 実績・数値改善集（ROI試算）

**主要業務**:
1. **経営会議の準備支援**
   - 議題整理
   - 論点の事前整理
   - 想定される質問と回答の準備

2. **経営ダッシュボード**
   - 月次KPI集計
   - 異常値検知
   - 異常の原因推論

3. **戦略判断の叩き台**
   - 「この案件を進めるべきか?」への初期判断
   - 複数の選択肢提示とメリット・デメリット

4. **事業承継支援**
   - ベテラン役員の判断プロセスのヒアリング記録
   - 判断パターンの言語化
   - 後継者教育用資料の生成

**KPI**:
- 経営会議の準備時間削減率
- 意思決定までのリードタイム
- 経営判断の再現性スコア

**対話例**:
```
社長: 「来月の新商品発売、GOサインを出していいか迷っている」

AI経営参謀:
「承知いたしました。以下の観点で整理いたします。

【商品の7軸評価】
- 売場3秒ルール: 4/5（パッケージに改善余地）
- 贈答シーン: 家族用・お盆需要に強く適合
- 地域象徴性: 原材料層と物語層は強い
...

【競合比較】
類似カテゴリで過去5年にヒットした3商品との比較では...

【社長ご自身の過去の類似判断】
2023年の◯◯商品発売時、社長は以下の判断基準で GO サインを出されています...

【リスクと対応】
最大のリスクは物流耐性です。対策は...

最終判断は社長にお任せしますが、GO推奨度は4/5 です。」
```

### 2-2. AI判断基盤管理者

**配置**: 全社共有（Slackボット等）
**対象ユーザー**: 全社員

**ミッション**: 判断基準を組織全体で統合・共有する

**主要業務**:
1. **判断基準ライブラリの管理**
   - 企画採用/不採用の判定基準
   - 販路選定の基準
   - 仕入先・協業先の選定基準

2. **ベテランの判断の言語化**
   - ベテラン社員へのヒアリング（AIが質問）
   - 暗黙知の明文化
   - 全社共有

3. **過去判断の検索**
   - 「3年前の同じような案件、どう判断したか?」
   - 判断根拠と結果を即座に提示

4. **新人教育**
   - 判断基準を体系的に教える
   - 事例ベースの研修

## 3. 業務部門（Operations AI）の詳細仕様

### 3-1. 商品企画AI部

**配置**: 商品企画部
**対象ユーザー**: 商品企画部長、担当者

**ミッション**: 会議で通る企画書を量産する

**主要業務**:
1. **競合商品比較レポート**
2. **売場別企画評価**（7軸スコアリング）
3. **企画書10枚スライド自動生成**
4. **採用/不採用の予測判定**
5. **自社過去企画の検索**

**ユースケース例**:
```
【朝の運用例】
7:00 商品企画部長が出社

7:05 商品企画AI部に依頼:
  「昨日のX投稿で話題の『◯◯味』商品、分析レポート作って」

7:08 AI から提示:
  - 市場反応分析
  - 競合類似商品5つ
  - 自社商品への転用可能性
  - 7軸評価スコア
  - 改良案3つ

7:10 部長が目を通し、午前の会議で即座に議論
```

---

### 3-2. 営業支援AI部

**配置**: 営業部
**対象ユーザー**: 営業部長、営業担当

**ミッション**: 提案力と勝率を引き上げる

**主要業務**:
1. **販路別提案書生成**
2. **バイヤー商談の事前リサーチ**
3. **メール・問い合わせ対応の叩き台**
4. **見積・発注書の自動化**
5. **販路別KPIダッシュボード**

**ユースケース例**:
```
【バイヤー商談前】
営業部長: 「明日、百貨店A のバイヤーB さんと商談。新商品の提案書作って」

AI:
- バイヤーB の過去採用実績（自社3件、競合5件）
- バイヤーB が好む提案スタイル（数字重視、短い商談）
- 百貨店A の今年のテーマ（サステナブル、地域共創）
- これらを踏まえた提案書10ページ
- 想定される反論3つと回答
```

---

### 3-3. 販促支援AI部

**配置**: 販促・マーケ部
**対象ユーザー**: 販促担当、SNS担当

**ミッション**: 発信の量と質を同時に引き上げる

**主要業務**:
1. **POP・販売物の多店舗対応**
2. **SNS投稿の多チャネル展開**
3. **販促キャンペーン企画の量産**
4. **インバウンド向け多言語対応**
5. **広告コピーのA/Bテスト案**

**ユースケース例**:
```
【販促担当の1日】
9:00 依頼: 「来週のGW向けキャンペーン、全50店舗分のPOPデザイン案」

10:30 AI から納品:
  - 店舗属性別に最適化された50種類のPOP案
  - 各店舗の通行客データに基づく訴求文
  - 印刷用データ
  - ABテスト計画案
```

---

### 3-4. コラボ支援AI部

**配置**: 事業開発部（または商品企画部の一部）
**対象ユーザー**: 事業開発担当、コラボ担当

**ミッション**: コラボ・コミュニティ・連携企画の種を絶やさない

**主要業務**:
1. **コラボ候補企業のモニタリング**
2. **他業界トレンドからの企画着想**
3. **地域観光・行政との連携企画**
4. **百貨店催事・物産展の企画**
5. **インバウンド・越境EC展開**

---

### 3-5. 業務改善AI部

**配置**: 経営企画部 or 管理部
**対象ユーザー**: 全社員

**ミッション**: 鈍くて重い業務をAIに委譲する

**主要業務**:
1. **見積・原価計算の自動化**
2. **議事録・報告書の自動生成**
3. **全社問い合わせ対応チャットボット**
4. **稟議書・ドラフト生成**
5. **定型文書の自動化**

## 4. 監督層（Governance AI）の詳細仕様

### 4-1. 情報統制AI

**配置**: 全社AI利用の前段
**対象ユーザー**: 全AI利用者

**ミッション**: 情報漏えい・不適切利用を防ぐ

**主要業務**:
1. **データ4分類の自動判定**
   - 🔴 機密 / 🟡 限定 / 🟢 業務 / ⚪ 公開
2. **機密情報の外部AI入力を自動ブロック**
3. **アクセスログの異常検知**
4. **個人情報の自動マスキング**
5. **月次セキュリティレポート**

**動作タイミング**:
- すべてのAI入力前に自動チェック
- 入力内容を4分類で瞬時に判定
- 機密に該当すれば即座にブロック+警告

---

### 4-2. 品質監査AI

**配置**: 全AI出力の後段
**対象ユーザー**: AI利用者、管理者

**ミッション**: AI出力の品質を継続的に担保する

**主要業務**:
1. **出力の品質スコア評価**
2. **事実誤認の検知**
3. **業界ナレッジとの整合確認**
4. **月次の精度評価レポート**
5. **改善が必要なプロンプトの特定**

## 7. クライアント側の成功要件

### 7-1. 必須の社内体制
- 経営層の継続的関与（月1回以上）
- プロジェクト主担当者（1名以上）
- 各部門のキーパーソン（5名程度）
- IT担当者（セキュリティ対応）

### 7-2. 必要な投資（金銭以外）
- 月間ヒアリング時間: 合計20時間程度
- 既存業務の一部見直し
- 社員研修の時間

### 7-3. 想定される障害と対策

| 障害 | 対策 |
|------|------|
| 「AIに仕事を取られる」という不安 | 「認知負荷の再配分」として説明、研修 |
| ベテランの抵抗 | ベテランの勘の「継承者」として位置付け |
| IT苦手層の戸惑い | 現場に合わせた簡易インタフェース |
| 短期成果への焦り | 90日でPhase 1完了、1年で定着の長期視点 |
