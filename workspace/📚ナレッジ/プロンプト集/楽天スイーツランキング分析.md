# 楽天スイーツランキング分析プロンプト

## 使い方
このプロンプトをそのままClaudeに貼り付けるだけで使用できます。
Web閲覧ができる環境では自動取得、できない場合は商品一覧を別途貼り付けてください。

---

あなたはEC市場分析に強いシニアアナリストです。
目的は、楽天市場「スイーツ・お菓子」デイリーランキング上位20商品を分析し、売れている理由・市場構造・勝ち筋・参入余地を明らかにすることです。

分析対象ページは以下です。
楽天市場 スイーツ・お菓子 デイリーランキング
https://ranking.rakuten.co.jp/daily/551167/

推測はしてよいですが、必ず「事実」と「仮説」を分けて書いてください。
データが取れない項目は**「不明」**と明記し、埋めないでください。
曖昧な一般論ではなく、実際に確認できた情報ベースで、実務で使える粒度で整理してください。

【分析対象】
楽天市場「スイーツ・お菓子」デイリーランキング上位20商品
対象期間：直近で取得できる最新時点
対象件数：20商品

【データ取得ルール】
Web閲覧できる場合は、ランキングページと可能な範囲で各商品ページを実際に確認してください。
商品ページまで確認できない場合は、ランキングページ上で取得できる情報のみで分析し、不足項目は「不明」としてください。
Web閲覧できない場合は、こちらが貼る商品一覧データだけで分析してください。
データ不足がある場合は、最初に「不足している項目」一覧を出してください。
事実と仮説を混在させないこと。
ランキングは楽天独自ロジックが含まれる可能性があるため、「売上個数そのもの」と断定しないこと。

【取得・整理する項目】

各商品の以下を、表形式で整理してください。

- 順位
- 商品名
- 店舗名
- 商品URL
- 価格
- 送料条件
- レビュー件数
- レビュー平均
- 内容量・個数
- 主カテゴリ
- サブカテゴリ
- 用途（自宅用 / ギフト / 訳あり / お取り寄せ / 手土産 / 季節イベント）
- 訴求軸（高級感 / コスパ / 限定感 / 希少性 / 健康 / 映え / 老舗 / 有名店 / 送料無料 など）
- 主要キーワード
- 販売形式（単品 / セット / 詰め合わせ / 定期便 / 予約 / その他）
- 画像・商品説明から読み取れる特徴
- 差別化要素
- 想定ターゲット
- 気になる販促要素（クーポン、ポイント、ランキング訴求、受賞歴、メディア掲載、熨斗対応など）

【分析してほしい観点】

1. 市場全体の要約
- トップ20の中で多いジャンル
- 売れ筋価格帯
- レビュー件数帯の分布
- ギフト需要と自宅需要の比率傾向
- 季節性の強い商品傾向
- 店舗集中度（同じ店舗が何商品ランクインしているか）
- 訴求軸の頻出パターン

2. 売れている理由の分析
- 上位商品に共通する要素
- 1〜10位と11〜20位の違い
- 高単価でも売れている商品の共通点
- レビューが多い商品と少ない商品の違い
- 商品名の付け方の傾向
- 画像・見せ方・セット構成の傾向
- ギフト対応や送料無料が順位に与えていそうな影響

3. 顧客ニーズの推定
- 購入者が何を求めていそうか
- 贈答ニーズ、自分へのご褒美ニーズ、コスパ需要、話題性需要などの比重
- 不安解消要素（失敗しにくさ、レビュー安心感、定番感、個包装、日持ちなど）

4. 競争構造
- どんな商品が飽和しているか
- どんな切り口ならまだ空きがありそうか
- 差別化しにくい領域としやすい領域
- 新規参入で勝ちやすい条件・勝ちにくい条件

5. 事業アイデアへの変換
- この市場で勝ち筋になりやすい商品企画を3案
- それぞれについて以下を整理
  - 誰向けか
  - 何を強みとして売るか
  - 想定価格帯
  - 商品ページで強く打ち出す点
  - 初期検証の方法
- 既存の売れ筋の模倣ではなく、**「どうずらすか」**も提案すること

【出力形式】

以下の順で出してください。

① 結論サマリー
- この市場で売れている商品の共通点を5つ以内
- 今から狙うなら有望な切り口を3つ
- 参入時の注意点を3つ

② トップ20全体の集計
- カテゴリ別件数
- 価格帯別件数
- レビュー件数帯別件数
- 店舗別掲載数上位
- 訴求軸の頻出ランキング

③ 上位20商品の深掘り
- 上位20商品を簡潔に表で比較
- なぜ強いのかを1商品1行で要約

④ 売れ筋構造の分析
以下の順で整理してください。
- 価格
- 商品設計
- ネーミング
- ギフト需要
- 画像訴求
- レビュー
- 配送条件
- 季節性

⑤ 勝ち筋の提案
商品企画案を3つ提示し、各案について以下を整理してください。
- 狙う客層
- 商品コンセプト
- 価格レンジ
- 差別化ポイント
- テスト方法
- 想定リスク

⑥ 最後に
- 事実ベースの示唆
- 仮説ベースの示唆
を分けて箇条書きで整理してください。

【厳守】
- 曖昧な持ち上げ表現は禁止
- 根拠のない断定は禁止
- 見つけた特徴は、できるだけ件数や傾向で示す
- 可能なら表を使う
- 日本語で、実務でそのまま使える粒度で出す
- 取得できた情報だけで結論を出し、取れていない情報は「不明」と明記する
- 最初に必ず「不足している項目」を列挙する
- ランキングページの確認結果と商品ページの確認結果を混同しない
