```
../📚ナレッジ/パーソナルナレッジ/*.md   ← 発信者が想定する読者像
```

## 食品スイーツ業界 baseline ターゲット

### 一次ターゲット（コア読者）
- **性別比**：女性70% / 男性30%
- **年齢**：25〜55歳
- **職業**：会社員（OL・総合職）、自営業、子育て中の主婦・ワーママ、パート
- **居住地**：首都圏・関西圏・中京圏中心、地方都市も含む
- **可処分所得**：月のスイーツ予算 3,000〜15,000円

### 二次ターゲット（業界関係者）
- 菓子メーカー経営者・マーケ担当
- パティシエ・和菓子職人（独立志向）
- カフェ・スイーツ店オーナー
- お土産菓子のEC・D2C事業者
- 観光地の物販担当者

### 抱えている悩み・欲求（カテゴリ別）
| カテゴリ | 悩み・欲求 |
|---|---|
| 自分用 | ご褒美スイーツを探したい、自分時間の質を上げたい |
| ギフト | 手土産で気の利いたものを贈りたい、センスを示したい |
| お取り寄せ | 失敗したくない、口コミ・実食情報が欲しい |
| 健康志向 | ダイエット中でも罪悪感少なく食べたい、低糖質・グルテンフリー |
| 季節イベント | バレンタイン・母の日・お中元の定番から脱却したい |
| 観光 | 旅先で本当に美味しいものを買いたい |

### 行動パターン
- **平日昼休み（12:00-13:00）**：X閲覧・お取り寄せ検討
- **通勤時間（7:30-8:30 / 18:00-19:30）**：情報収集・検索
- **週末夜（20:00-23:00）**：購入決定・カート投入
- **季節イベント前 2〜3週間**：贈答品検索ピーク

### 刺さる言葉（積極的に使う）
- 食感系：「とろける」「とろっと」「ほろっと」「サクッと」「もちもち」「ふわっと」
- 価値系：「贅沢」「ご褒美」「素材本来の」「手間暇かけた」
- 希少性：「限定」「期間限定」「数量限定」「予約必須」「行列必至」
- 産地訴求：「[産地名]の[素材]を使った」
- シーン：「手土産」「お取り寄せ」「定番」「隠れた名店」「自分へのご褒美」

### 刺さらない・避ける言葉
- 「やばい」「えぐい」「マジで」（信頼性を損なう）
- 数字だけの煽り（「○○円稼いだ」系は食品文脈と相性悪い）
- 過度な誇大表現（薬機法・景表法リスク）
- 専門用語の羅列（製菓用語・業界用語は補足を入れる）

### ペルソナ例（baseline 3パターン）
1. **30代OLゆうこさん**：金曜夜の自分ご褒美探し。月1万円のスイーツ予算。Instagramも併用。
2. **40代ワーママまさみさん**：義実家への手土産選びに毎月悩む。失敗できない贈答品を求める。
3. **50代パティシエ山田さん（業界関係者）**：自店のSNS運用ヒントを求めて業界アカウントをフォロー。

→ 発信者の立場（パティシエ / 経営者 / レビュアー等）によって、上記3ペルソナのうちどこに重み付けするかが変わる。📚ナレッジ/パーソナルナレッジで明示すること。

## 出力時の使い方
- 投稿前に「これはターゲットに本当に刺さるか？」を自問
- 抽象論ではなく具体的なシーンで語る（「金曜夜にXを開いた30代OL」のような具体性）
- ペルソナのうち最も近い1人を想定して書く
- 発信者の立場に応じて、一次ターゲットと二次ターゲットの比重を調整

## 発信者個別の上書きルール

📚ナレッジ/パーソナルナレッジ または プロダクトナレッジに固有のターゲット情報がある場合：
- **業界baselineを否定せず、上書き or 補強する**
- 例：「BtoB特化のコンサル発信者」なら、二次ターゲット（業界関係者）に比重を寄せる
- 例：「お取り寄せレビュアー」なら、一次ターゲット（消費者）が中心
