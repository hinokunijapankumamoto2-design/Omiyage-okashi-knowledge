## 食品スイーツ業界 baseline（共通の作法）

### 食感ワード辞典（必ずどれか1つ以上を投稿に入れる）
| カテゴリ | ワード |
|---|---|
| とろける系 | とろける／とろっと／なめらか／クリーミー |
| ほろほろ系 | ほろっと／ほろほろ／さくほろ |
| サクサク系 | サクッと／サクサク／パリッと／カリッと |
| もちもち系 | もちもち／もっちり／ねっとり／むっちり |
| ふわふわ系 | ふわっと／ふわふわ／しゅわっと／とろふわ |
| 重厚系 | 濃厚／コク深い／芳醇／リッチ |
| 上品系 | 上品／繊細／優しい甘さ／角がない |
| 香り系 | 香ばしい／ほんのり／華やか／鼻に抜ける |

### 価値表現の語彙
- 「贅沢な」「ご褒美の」「素材本来の」「手間暇かけた」「贅を尽くした」
- 「老舗の」「歴史ある」「伝統の」「変わらない味」
- 「新感覚の」「次世代の」「進化系の」「再解釈の」

### 希少性・季節性表現
- 「限定」「期間限定」「数量限定」「予約必須」「行列必至」
- 「[月名]限定」「今だけ」「今週末まで」「入手困難」
- 「[産地]の」「[作り手]の」「[年間製造]個のみ」

### 食品スイーツ業界の禁止表現（絶対NG）
| カテゴリ | NG例 | 代替 |
|---|---|---|
| 効能訴求（薬機法） | 「健康になる」「美肌」「痩せる」「アンチエイジング」「腸活」 | 「ご褒美時間に」「特別な日に」 |
| 最上級（景表法） | 「日本一」「最高」「No.1」「最強」「絶対」 | 「[年]で評価された」「数量限定」 |
| 信頼性低下 | 「やばい」「えぐい」「マジで」「神」 | 食品の信頼性を保つ言葉に置換 |
| 産地誤認 | 曖昧な「国産」「天然」 | 具体的な原産地を明記 |
| 過度な煽り | 「絶対買うべき」「人生変わる」 | 体験ベースの具体表現 |

### 絵文字ルール（baseline）
- 1ポストに **2個まで**（食品の品の良さを保つ）
- 推奨絵文字：🌸🍰🍓🍡🍵🎁🌰🍂✨📦
- 避ける絵文字：🤣🥺🤤（軽すぎる、品が下がる）

### 改行・段落（baseline）
- 1行 25文字程度（スマホ表示で1〜2行に収まる）
- 3行で1ブロック
- 段落間は1行空ける
- 商品名・価格は太字 or 「」で強調

### AI出力臭を消すチェックリスト

| ✗ NGパターン | ✓ 修正方向 |
|---|---|
| 「いかがでしょうか」 | 言い切る or 削除 |
| 「ぜひ」「とても」「非常に」 | 具体表現に置換 |
| 「〜と言えます」「〜と言えるでしょう」 | 断定 or 具体 |
| 過剰な「、」 | 短文に分割 |
| 抽象表現（「素晴らしい」「すごい」） | 食感ワード・数値・固有名詞 |
| 文末の単調さ | 体言止め・倒置を混ぜる |
| 並列の三点（「AとBとC」） | 1つに絞り深掘り |

### スイーツ業界バズ投稿の構造（baseline）
```
[1行目] スクロールストッパー（食感ワード or 価格 or 限定性）
[2行目] 商品名・産地・素材の具体名
[3行目] 一言の感想（職人気質 or 消費者目線）
[改行]
[4-6行目] エピソード or 解説（30〜50文字）
[改行]
[末尾] ハッシュタグ（2〜4個）
```

## 発信者個別情報（📚ナレッジ/コンテンツナレッジから読み込み）

### 発信者の固有口癖・フレーズ
→ `../📚ナレッジ/コンテンツナレッジ/コンテンツ_文体パターン集.md` 等を参照
- 発信者ならではの口癖（毎ポストに1つ以上入れる）
- 1人称の選択（僕／私／俺等）

### 過去のバズポスト集
→ `../📚ナレッジ/コンテンツナレッジ/` の蓄積から型を取得
- 反応が良かった投稿パターンを再利用
- 発信者ごとに「効く型」が異なる

### 発信者固有のキャッチコピー
→ `../📚ナレッジ/コンテンツナレッジ/` の訴求ワード集
- 商品紹介時に使う固定フレーズ
- 自己紹介・プロフィール文の決まり文句

### 発信者の絵文字ルール
- 個別の好み・避けたい絵文字があれば優先

## 出力時の使い方

- **AIっぽい文体を排除**：上記チェックリスト参照
- **法令NGワードを必ずスキャン**：投稿前に最終確認

## 発信者個別の上書きルール

- **食感ワード辞典**は baseline を全員使用（業界共通の語彙資産）
- **絵文字ルール**は発信者個別が優先（baselineは目安）
- **改行・段落**は発信者個別が優先
- **NGワード**は baseline ＋ 発信者固有を統合（双方を遵守）
- **バズ型**は発信者の過去バズパターンを優先（コンテンツナレッジから）
