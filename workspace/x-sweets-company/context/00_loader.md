# Context Loader｜食品スイーツ業界版

## このファイルの役割
全社員が起動時に最初に実行する **ナレッジ読み込み手順書** 。
食品スイーツ業界の baseline 知識は context/ に内蔵されており、発信者個別の情報は `../📚ナレッジ/` から読み込む。

## 読み込み手順（必ずこの順序で実行）

### Step 1：context/ 配下の業界 baseline を読み込み
```
context/about-me.md             ← ブリッジ＋テンプレ
context/target.md               ← ブリッジ＋スイーツ消費者像
context/strategy.md             ← ブリッジ＋スイーツ季節カレンダー
context/industry-knowledge.md   ← ★スイーツ業界 baseline（必読）
context/writing-style.md        ← ブリッジ＋食感ワード等
```

### Step 2：📚ナレッジ全体の存在確認
```
Glob: ../📚ナレッジ/**/*.md
```
ヒット件数が0なら「baseline-onlyモード」（後述）。

### Step 3：パーソナルナレッジを読み込む（最重要）
```
Glob: ../📚ナレッジ/パーソナルナレッジ/*.md
→ 全ファイルをRead
```
発信者の名前・経歴・専門領域・トンマナを取得。
**food-sweets baselineの target.md / writing-style.md に対して、ここで取得した情報を上書き**する。

### Step 4：プロダクトナレッジを読み込む
```
Glob: ../📚ナレッジ/プロダクトナレッジ/*.md
→ 全ファイルをRead
```
販売中の商品・価格・ファネル・KPIを取得。
**baseline strategy.md の商品ラインナップを発信者の実商品で上書き**する。

### Step 5：ドメインナレッジで業界baselineを augment
```
Glob: ../📚ナレッジ/ドメインナレッジ/*.md
→ 全ファイルをRead
```
発信者独自の業界観・競合分析・サブニッチ知識を取得。
**baseline industry-knowledge.md に追加情報として統合**（baselineを否定しない）。

### Step 6：コンテンツナレッジを読み込む
```
Glob: ../📚ナレッジ/コンテンツナレッジ/*.md
→ 全ファイルをRead
```
発信者独自の文体・口癖・キャッチコピー集を取得。
**baseline writing-style.md の食感ワード等を発信者個別の表現で上書き**する。

### Step 7：その他のナレッジ（任意）
以下が存在すれば追加読み込み：
```
../📚ナレッジ/競合リサーチ/*.md
../📚ナレッジ/実績ナレッジ/*.md
../📚ナレッジ/正典思想/*.md
../📚ナレッジ/AI組織設計/*.md
../📚ナレッジ/ナレッジ索引.md
```

## bridge と baseline の優先順位

各 context/ ファイルは **「業界 baseline ＋ 発信者個別情報」** の二層構造で動く：

| ファイル | baseline | 発信者個別 | 優先度 |
|---|---|---|---|
| about-me.md | テンプレートのみ | 📚ナレッジ/パーソナル | **個別優先** |
| target.md | スイーツ消費者像 | 📚ナレッジ/パーソナル＋プロダクト | **個別が baselineを補強** |
| strategy.md | 季節カレンダー・投稿時間帯 | 📚ナレッジ/プロダクト | **商品は個別優先・季節はbaseline** |
| industry-knowledge.md | スイーツ業界 baseline 全般 | 📚ナレッジ/ドメイン | **baseline優先・個別は augment** |
| writing-style.md | 食感ワード・絵文字ルール等 | 📚ナレッジ/コンテンツ | **個別優先・baselineは補強** |

→ 発信者の独自性を最大化しつつ、業界の最低限ルール（法令・季節・KENGOOD7軸）は守らせる設計。

## baseline-onlyモード（📚ナレッジが空の場合）

ナレッジが1件もヒットしない場合：
1. context/ 配下の baseline のみで動作開始
2. ユーザーに以下を提案：
   ```
   ⚠ ../📚ナレッジ/ にファイルがありません。
   現在は食品スイーツ業界の baseline のみで動作しています。
   個性のある投稿を生成するには、最低限以下を格納してください：
   - ../📚ナレッジ/パーソナルナレッジ/ にあなたのプロフィール
   推奨：/knowledge スキルで投げ込んでください
   ```
3. 投稿は「業界一般の無個性な発信」になるため、長期運用は非推奨

---

## 更新タイミング

- **新セッション開始時**：必ず本ファイルの手順を最初に実行
- **ナレッジ更新後**：`/knowledge` でナレッジが追加されたら、再度Step 2から実行
- **長時間セッション**：4時間以上経過したら再読み込み推奨

---

## 重要な原則

- **baseline knowledge は触らない**：context/industry-knowledge.md の業界baselineは編集せず、`../📚ナレッジ/ドメインナレッジ/` で augment する
- **発信者個別情報のハードコード禁止**：context/about-me.md 等に直接プロフィールを書かず、`../📚ナレッジ/パーソナルナレッジ/` に格納する
- **法令・コンプライアンスは絶対**：薬機法・景表法・食品表示法のNG表現は baseline で固定。例外は認めない
- **不確実な情報は推測しない**：「要事実確認」と明記する
