# Bridge: 社長プロフィール｜About Me（食品スイーツ業界版）

> このファイルはブリッジ（ポインタ）です。発信者個別の情報は `../📚ナレッジ/パーソナルナレッジ/` から読み込みます。

## プライマリソース
```
../📚ナレッジ/パーソナルナレッジ/*.md
```
このフォルダ内のすべての `.md` ファイルを読み込み、発信者の人格コンテキストとして保持する。

## 抽出すべき情報
- **基本情報**：名前 / ペンネーム / 一人称 / 年齢 / 居住地
- **経歴・実績**：パティシエ歴 / 和菓子職人歴 / 経営歴 / 受賞歴 / メディア掲載
- **専門領域**：他の発信者には書けない強み（例：素材論 / 観光地物販 / お取り寄せレビュー）
- **発信の3軸**：3つ程度の柱
- **トンマナ**：文体・口癖・絵文字使用ルール
- **避ける表現**：信頼性を損なうワード・NGトピック

## 業界 baseline（発信者情報がない場合のみ参照）

食品スイーツ業界の発信者として最低限満たすべきトンマナ：

### 基本トンマナ（共通）
- 文体：丁寧かつ親しみやすい（食品の信頼性を損なわない）
- **避ける表現**：「やばい」「えぐい」「マジで」（食品の信頼性低下）
- 改行ルール：1ポストに絵文字は2個まで、3行で1ブロック程度

### 発信ジャンルの選択肢
食品スイーツ業界には複数の立場がある：
- 和菓子職人・パティシエ（作り手目線）
- 菓子メーカー経営者（ブランド戦略目線）
- カフェ・スイーツ店オーナー（店舗運営目線）
- お土産菓子事業者（流通・観光目線）
- お取り寄せレビュアー（消費者目線）
- 業界コンサルタント（マーケ目線）

→ どの立場かによって専門性の出し方が変わる。発信者は📚ナレッジ/パーソナルナレッジに自分の立場を明記すること。

## 出力時の使い方
- 投稿生成時：「自分の立場・専門性に基づくと…」という観点で書く
- 数値・実績は曖昧化しない（「○○年」「○○件」と具体的に）
- 経歴に矛盾する内容を書かない（実績のない領域での断定を避ける）
