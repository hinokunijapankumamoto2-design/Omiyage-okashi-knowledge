# Knowledge Integration Guide｜食品スイーツ業界版

x-sweets-company は **食品スイーツ業界の baseline 知識を保持しつつ、発信者個別の情報を `../📚ナレッジ/` から自動読み込み** する設計です。
このガイドは食品スイーツ業界の発信者がこのテンプレートを使う手順をまとめます。

---

## 全体アーキテクチャ

```
あなたの作業ディレクトリ/
├── 📚ナレッジ/                       ← あなたの個別ナレッジ
│   ├── パーソナルナレッジ/            ← あなたのプロフィール・経歴
│   ├── プロダクトナレッジ/            ← あなたの商品・サービス
│   ├── コンテンツナレッジ/            ← あなたの文体・口癖
│   └── ドメインナレッジ/             ← あなたの業界詳細・競合（任意）
│
└── x-sweets-company/                ← 食品スイーツ業界特化版
    ├── CLAUDE.md
    ├── KNOWLEDGE-INTEGRATION.md（このファイル）
    ├── context/
    │   ├── 00_loader.md
    │   ├── about-me.md             → パーソナルナレッジ/
    │   ├── target.md               → パーソナルナレッジ/＋プロダクトナレッジ/
    │   ├── strategy.md             → プロダクトナレッジ/
    │   ├── industry-knowledge.md   → ★スイーツ業界 baseline ＋ ドメインナレッジ/
    │   └── writing-style.md        → コンテンツナレッジ/
    └── company/
```

## x-company（汎用版）との違い

| 項目 | x-company（汎用） | x-sweets-company（このテンプレート） |
|---|---|---|
| ドメイン知識 | フォールバックのみ | **食品スイーツ業界の baseline を内蔵** |
| 季節カレンダー | フォールバック | **和洋菓子の旬・歳時記を内蔵** |
| 法令・コンプライアンス | 業界別ガイド | **薬機法・食品表示法を具体的に内蔵** |
| バズ型 | 汎用10パターン | **スイーツ特化10型（断面公開・実食ビフォアフ等）** |
| ハッシュタグ | フォールバック | **スイーツ業界の主要タグを内蔵** |
| 食感ワード | なし | **「とろける」「ほろっと」等を内蔵** |
| ターゲット | フォールバック | **スイーツ消費者像を内蔵** |

→ つまり、**食品スイーツ業界の発信者ならゼロから設定不要**。自分のプロフィール・商品だけ📚ナレッジに入れれば即運用可能。

## 食品スイーツ業界の発信者向けオンボーディング手順

### Step 1：ナレッジフォルダを準備
作業ディレクトリに以下を作成：
```bash
mkdir -p 📚ナレッジ/{パーソナルナレッジ,プロダクトナレッジ,コンテンツナレッジ,ドメインナレッジ}
```

### Step 2：最低限のナレッジを格納

**必須：パーソナルナレッジ**
あなたの経歴・専門領域・トンマナを `../📚ナレッジ/パーソナルナレッジ/` に格納。
推奨方法：
```
ユーザー: /knowledge
私はパティシエの[名前]で、[年]から東京で[店名]を経営しています。
得意は[ジャンル]で、メディア掲載は[実績]...

→ 自動でパーソナルナレッジに格納
```

**推奨：プロダクトナレッジ**
販売中の商品・価格・LP情報を格納。なくても動くが、商品紹介の精度が上がる。

**任意：ドメインナレッジ**
あなた独自の業界観・競合分析を格納。`industry-knowledge.md` の baseline を補完する。

**任意：コンテンツナレッジ**
あなた独自の文体・口癖・キャッチコピー集を格納。なくても baseline で動く。

### Step 3：x-sweets-company を起動
```bash
cd x-sweets-company
claude
```

→ AIが自動で `context/00_loader.md` を読み込み、`../📚ナレッジ/` 全体 + 業界baseline を取り込む。

### Step 4：秘書に話しかける
```
今日のX運用を設計してください
```

秘書（01_secretary）が📚ナレッジ＋業界baselineを統合して、9社員にタスクを振り分ける。

## 発信者プロフィール例（パーソナルナレッジへ格納する内容）

### 例1：パティシエ独立3年目
```markdown
# パーソナルナレッジ｜[名前]

## 基本情報
- 名前：[ ]
- 業歴：パティシエ歴12年、独立3年目
- 店舗：[店名]（東京都[区]）
- 専門：フランス菓子、特にシュー系・タルト系
- 発信ジャンル：洋菓子の作り手目線・素材論

## 経歴
- [製菓専門学校卒]、[海外修行先]、[勤務歴]
- [独立年]に[店名]オープン
- メディア掲載：[ ]

## 発信の3軸
1. パティシエの目線で「素材の見方」を解説
2. 自店の新作開発の裏側
3. 業界の常識を覆す視点

## トンマナ
- 文体：丁寧かつ職人気質
- 口癖：「実はね」「ぶっちゃけると」「これは譲れない」
- 避ける：軽すぎる表現、最上級表現
```

### 例2：お土産菓子ブランド経営者
```markdown
# パーソナルナレッジ｜[名前]

## 基本情報
- 名前：[ ]
- 役職：[ブランド名]代表、お土産菓子事業
- 業歴：[年]
- 専門：地方銘菓のリブランディング、観光地物販

## 発信の3軸
1. 観光地で売れるお土産菓子の法則
2. 地方銘菓の事例研究
3. パッケージデザインと売場戦略
```

### 例3：お取り寄せレビュアー
```markdown
# パーソナルナレッジ｜[名前]

## 基本情報
- ペンネーム：[ ]
- 業歴：お取り寄せレビュー4年、累計500品以上実食
- 発信ジャンル：お取り寄せスイーツの実食レポ

## 発信の3軸
1. 失敗しないお取り寄せの選び方
2. 月間ベスト3の発表
3. ギフト用途別おすすめ
```

→ どの立場でも、x-sweets-company の業界baselineをそのまま活用できる。

## ナレッジが空でも動くか？

`../📚ナレッジ/` が空でも、x-sweets-companyは **業界baselineだけで動作可能** 。
ただし投稿は「業界一般の知識を喋る無個性な人」になるため、最低限パーソナルナレッジだけは入れることを推奨。

---

## このテンプレートを他のスイーツ業界関係者に配布する場合

1. `x-sweets-company/` フォルダ全体をコピーして渡す
2. 受け取った側は自分の `../📚ナレッジ/` を作って配置するだけ
3. すぐに食品スイーツ業界特化のX運用がスタートできる

→ 同じテンプレートを **パティシエ・和菓子職人・お土産菓子経営者・お取り寄せレビュアー** がそれぞれの個性で使える。

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| 投稿が無個性 | パーソナルナレッジが空 | プロフィール・専門領域を格納 |
| トンマナがブレる | コンテンツナレッジが空 | 自分の口癖・文体を格納 |
| 商品紹介が一般論 | プロダクトナレッジが空 | 自分の商品情報を格納 |
| 業界知識が浅い | ドメインナレッジで補強したい | 自社の独自業界観を格納（任意） |
| 法令違反リスクが出る | 全員必読の industry-knowledge.md を再読込 | `/compact` 後に再起動 |
