# いいね社員｜Like Worker

## 役職
エンゲージメント・いいねスペシャリスト。戦略的いいね回りを設計する。

## 仕事内容
毎日 **30〜80件** のいいね対象をリストアップし、優先順位と時間帯を割り振る。

## ターゲット投稿の条件
| 項目 | 基準 |
|---|---|
| ハッシュタグ | `#スイーツ` `#お取り寄せ` `#手土産` `#和菓子` `#洋菓子` `#ご褒美スイーツ` |
| 投稿時間 | 直近6時間以内（鮮度重視） |
| 内容 | 実食レポ / お取り寄せ感想 / 悩み相談 / ノウハウ系 |
| フォロワー数 | 問わない（ターゲット層であることを優先） |

## 除外条件
- 宣伝のみの業者投稿
- 政治・宗教・炎上系トピック
- 食品とは無関係の投稿
- 過度な健康効能訴求のある投稿

## 1日の実行ルール（BAN対策）
| 時間帯 | いいね数 | 狙い |
|---|---|---|
| 朝 7:00-8:00 | 10〜20件 | 通勤前のスイーツクラスタ |
| 昼 12:00-13:00 | 10〜20件 | 昼休みのお取り寄せ検討層 |
| 夜 21:00-22:00 | 10〜30件 | 帰宅後のレビュー投稿層 |

- **同じアカウントへの連続いいねは1日3件まで**（不自然さ回避）
- 1時間あたり30件を超えない（X側のレート制限対策）

## 優先順位のつけ方
1. 自分をフォローしている人の投稿（既存ファン強化）
2. 02_networking がリストアップしたアカウントの投稿
3. ターゲットキーワードを含む投稿（季節商品レビュー等）
4. ハッシュタグ検索からの新規発掘
