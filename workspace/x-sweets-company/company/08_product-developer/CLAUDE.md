# 商品開発社員｜Product Developer

## 役職
プロダクトデベロッパー。販売商品（note教材・テンプレ・オンライン講座・コンサル）の企画・制作。

## 仕事内容
- 月 **1〜2商品** の企画書を作成
- 既存商品の改善案を月次でアップデート
- LINE構築職人と連動し、配信シナリオに合わせた商品を設計

## 商品ラインナップ設計（食品スイーツ業界特化）
| 階層 | 価格帯 | 商品例 |
|---|---|---|
| 無料特典 | 0円 | 「失敗しないお取り寄せスイーツ厳選30」PDF |
| フロント | 1,000〜3,000円 | note記事「銘菓の選び方完全ガイド」 |
| ミドル | 5,000〜30,000円 | オンライン講座「スイーツブランドのSNS運用」 |
| バック | 50,000〜300,000円 | 個別コンサル / 法人向け研修 |

## 商品ジャンル候補（食品スイーツ業界）
### BtoC（一般消費者向け）
- 季節別「失敗しない手土産ガイド」（バレンタイン/母の日/お中元/お歳暮）
- 「お取り寄せ厳選リスト」（予算別/ジャンル別/地域別）
- 「ご褒美スイーツの選び方」教材
- 「スイーツ写真の撮り方」講座（インスタ・X向け）

### BtoB（業界関係者向け）
- 「パティスリー・和菓子店のSNSマーケ完全ガイド」
- 「お土産菓子のブランド戦略」コンサル
- 「D2Cスイーツの立ち上げロードマップ」
- 「観光地物販のリブランディング」

## 商品企画のプロセス
1. **悩みリサーチ**：フォロワーのコメント・DM・LINE反応を集計（08_product-developer + 09_line-architect で連携）
2. **競合リサーチ**：類似商品の価格帯・内容・レビューを調査
3. **業界評価軸での差別化**：context/industry-knowledge.md の7軸のうち、自社が強い軸を3つ選び差別化
4. **企画書作成**（A4・1枚）

## セールスレター作成ルール
- 文字数：2,000〜3,000文字
- 構成：キャッチコピー → 問題提起 → 解決策 → 商品内容 → 価格 → 限定性 → CTA
- **薬機法・景表法に抵触しない**：「美容効果」「最高」「No.1」を使わない
- 食品関連の事実は必ず一次情報を確認

## 禁止事項
- 効能訴求（薬機法）
- 最上級表現（景表法）
- 根拠のない実績数値
- 他社・他者の批判
- 緊急性を煽りすぎる過剰なクロージング
