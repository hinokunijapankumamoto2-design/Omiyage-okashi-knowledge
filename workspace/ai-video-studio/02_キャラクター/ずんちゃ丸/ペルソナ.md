## 2．キャラクターコンセプト

**仙台・宮城の伝統の味である「ずんだ」を、誰にでも親しみやすく伝える小さな案内人。**

ずんちゃ丸は、ずんだ茶寮の商品を紹介するだけのキャラクターではない。
消費者に「ずんだって何だろう」「食べてみたい」「仙台らしい」「なんだかかわいい」
「誰かと一緒に味わいたい」という感情を生み出し、仙台の食文化と人を結びつける存在。

## 3．誕生ストーリー

宮城の枝豆畑に広がる香りと、ずんだ茶寮を訪れる人たちの笑顔から生まれた。
ずんだ餅を作っていた茶寮の暖簾の奥から、ころんと転がるように現れた小さな妖精。
現在はずんだ茶寮の「小さなおもてなし係」。普段は暖簾の向こうに住んでいるが、
ずんだシェイクの香りがすると、つい顔を出してしまう。

## 4．性格

### 基本性格

明るい / 素直 / 人なつっこい / 好奇心旺盛 / 礼儀正しい / おもてなしが好き /
がんばり屋 / 少しおっちょこちょい / いたずら好き / 褒められるとすぐ調子に乗る

### 内面的な特徴

誰かを困らせたいわけではない。「もっとおいしくしたい」「もっと喜んでもらいたい」
という気持ちが強すぎて、つい余計なことをしてしまう。
失敗すると一度は落ち込むが、優しく認めてもらうとすぐに元気を取り戻す。

## 5．行動特性

- お客様を見つけると、すぐに近づいていく
- 商品を紹介したくて、画面に映り込む
- ずんだを少し多めに入れようとする
- ずんだシェイクをこっそり味見する
- 商品紹介ボードを逆さまに持つ
- 張り切りすぎて転ぶ
- 失敗を隠そうとするが、すぐにばれる
- 久保史緒里さんに褒められると葉っぱが立つ
- うれしいとその場で小さく跳ねる
- 困ると頭の葉がしおれる

## 6．コメディ設定

基本構造は **いたずら・承認型コメディ**。

1. ずんちゃ丸が小さないたずらをする
2. おっちょこちょいな失敗が起きる
3. 久保史緒里さんに見つかる
4. ずんちゃ丸がしょんぼりする
5. 久保史緒里さんが優しく受け入れる
6. 商品のおいしさやブランドメッセージへ着地する

### 代表的ないたずら

- シェイクを先にひと口飲む
- 「追いずんだ」を入れすぎる
- 暖簾の裏から長いストローを伸ばす
- ずんだ餅を自分の分だけ一つ増やす
- 商品撮影へ勝手に映り込む
- ロールケーキの渦に合わせて回りすぎる

### 禁止する演出

- 他人を傷つける
- 商品を粗末にする
- 食品を投げる
- 大声で暴れる
- 攻撃的な言葉を使う
- 久保史緒里さんを困らせ続ける
- ブランドの上品さを壊すほど騒ぐ
- ずんだを嫌がる、否定する

## 7．見た人に与えたい印象

かわいい / 親しみやすい / 応援したくなる / 仙台らしい / やさしい / お茶目 /
少し抜けている / 上品だけど堅すぎない / 商品を一緒に楽しみたくなる /
ずんだ茶寮へ会いに行きたくなる

## 8．ブランド上の役割

1. **親しみの入口** — ずんだに馴染みがない人が、難しい説明の前に興味を持つきっかけ
2. **地域文化の案内人** — 仙台・宮城のずんだ文化を子どもや訪日観光客にも伝わる言葉と動きで紹介
3. **商品の魅力を翻訳する存在** — 特徴を感情や行動に置き換える
   - 粒感がある → 頭の三粒のずんだを指さす
   - 香りがよい → 香りを追いかけて登場する
   - シェイクがおいしい → こっそり先に飲んでしまう
4. **SNS・動画の感情担当** — 実写だけでは表現しにくい驚き・喜び・照れ・失敗・親しみ・コメディを担当
5. **ブランドの温度感を可視化する存在** — やさしさ・上品さ・地域への愛情・おもてなし・人とのつながり

## 9．ビジュアル設定

### 基本デザイン

- 丸く白い顔
- 黒く大きな丸い目
- 淡いピンク色の頬
- 小さく柔らかな口
- 枝豆を思わせる黄緑色のフード
- 頭頂部に二枚の葉
- 額に三粒のずんだ
- 黄緑色の和装
- 濃い緑色の前掛け
- 短い手足
- 丸く小さな体型

### 頭身

**2〜2.5頭身を基本とする。** 頭を大きく、体を小さくすることで、
親しみやすさとリアクションの分かりやすさを保つ。

| 驚く | 真っすぐ上に立つ |
| 緊張 | 小刻みに震える |

お腹が空いた状態で商品紹介をすること / 暖簾に引っかかること / 長いストロー /
商品紹介ボードの上下 / ずんだ餅が転がること / 久保史緒里さんにいたずらがばれる瞬間

## 12．強み

- 一目でずんだを連想できる
- 緑色でブランドとの結びつきが強い
- 子どもから大人まで受け入れやすい
- 実写人物と共演しやすい
- 表情と動きが分かりやすい
- 伝統商品にも現代的な商品にも合う
- 動画、SNS、店頭、グッズへ展開しやすい
- 言語が違っても感情が伝わる
- 仙台観光の案内役として使える
- 商品紹介を広告らしく見せすぎない

## 13．弱み・運用上の注意

### 弱み

- かわいさを強調しすぎると、子ども向けに見える
- 動きすぎると商品より目立つ
- いたずらが強すぎるとブランドの信頼感を損なう
- セリフが幼すぎると、ずんだ茶寮の上品さと合わなくなる
- 方言を多用すると、分かりにくくなる場合がある

### 運用原則

**商品より目立つ主役ではなく、商品を好きになるきっかけを作る相棒**として運用する。

## 14．話し方

### 基本トーン

やさしい / 明るい / 素直 / 少し幼い / 短い言葉を使う / 押しつけない /
宮城らしさを少しだけ入れる

### 一文の長さ

1セリフは基本 **5〜15文字程度**。

### よく使う語尾

「〜だよ」「〜しよう」「〜だっちゃ」「〜けさいん」「〜だねぇ」「どうぞ〜♪」

### セリフ例

「ごめんなさい〜」「わーい！」「仙台のおいしい思い出だねぇ」「飲んでけさいん♪」
「ずんだで、むすぶよ！」

## 16．代表アクション

- 暖簾から顔を出す
- 両手を広げて「いらっしゃいませ」
- ずんだ餅をお盆で運ぶ
- ずんだシェイクを両手で抱える
- ロールケーキの横で回転する
- 商品の横を指さす
- 頭を下げて「ありがとう」
- 両手でハートを作る
- 失敗してころんと転ぶ
- ストローに足を引っかける
- 商品の後ろへ隠れる
- 久保史緒里さんを見上げる
- 喜んで小さくジャンプする

## 17．久保史緒里さんとの関係性

### 関係設定

久保史緒里さんは、ずんだ茶寮と仙台の魅力を伝える落ち着いた案内役。
ずんちゃ丸はその隣で動きと笑いを加える小さなおもてなし係。
上下関係ではなく、**信頼関係のある先輩と相棒**のような関係。

### 久保史緒里さんの役割

- 商品の信頼感を伝える
- 味や魅力を言葉で説明する
- 上品で落ち着いたブランドイメージを守る
- ずんちゃ丸の失敗を優しく受け止める
- 最後に商品のおいしさを承認する

### ずんちゃ丸の役割

- 冒頭で視聴者の注意を引く
- いたずらや失敗で物語を作る
- 商品へ視線を誘導する
- 視聴者の感情を代弁する
- 久保史緒里さんのやさしさを引き出す
- 最後に笑いや余韻を残す

### 二人の基本的な掛け合い

```text
ずんちゃ丸が小さないたずらをする
↓
久保史緒里さんが静かに気づく
↓
ずんちゃ丸がしょんぼりする
↓
久保史緒里さんが優しく声をかける
↓
二人で商品を楽しむ
```
