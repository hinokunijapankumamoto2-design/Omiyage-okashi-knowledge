## 1. 外見の正準プロンプト（工程3: gpt-image-2 用）

すべての静止画生成で、この「外見ブロック」を imagePrompt の先頭に置く。
外見ブロックを崩すとショット間でキャラクターがブレる。

### 日本語版（そのまま貼って使う）

```
ずんだ茶寮の公式マスコット「ずんちゃ丸」。2〜2.5頭身の小さな妖精。
丸く白い顔、黒く大きな丸い目、淡いピンクの頬（#FFD9D9）、小さく柔らかな口。
枝豆を思わせる黄緑色のフード（#8BCB59）、頭頂部に二枚の葉、額に三粒のずんだ豆。
黄緑色の和装に濃い緑色（#6FB234〜#4EBC3A）の前掛け、前掛けに枝豆の紋。
短い手足、丸く小さな体型。やわらかい水彩調、白背景、上品でかわいい和の雰囲気。
```

### 英語版（モデルが日本語プロンプトで安定しない場合）

```
"Zuncha Maru", official mascot of a Japanese zunda sweets shop.
A tiny fairy, 2 to 2.5 heads tall. Round white face, big round black eyes,
soft pink cheeks (#FFD9D9), small gentle mouth. Edamame-green hood (#8BCB59)
```

### 表情の指定語彙（ペルソナ 15 の表情パターンに対応）

`通常の微笑み / 満面の笑顔 / 得意げ / いたずら顔 / 驚き / しょんぼり / 照れ /
真剣 / 渦巻き目 / 頬ふくらませ / 目をそらす / 自信満々`

表情を変えるときは、**頭の葉の状態を必ずセットで指定する**:

| 感情 | 葉の指定 |
|---|---|
| うれしい | 葉が上向きに大きく開く |
| 興奮 | 葉が左右に激しく揺れる |
| 困り | 葉が内側へ閉じる |
| 落ち込み | 葉が下向きに垂れる |
| 驚き | 葉が真っすぐ立つ |
| 緊張 | 葉が小刻みに震える |

## 2. モーションプロンプト（工程4: Kling image_to_video 用）

motionPrompt は「1ショット1アクション」。ペルソナ 16 の代表アクションから選ぶ。

| 用途 | motionPrompt の例 |
|---|---|
| 登場 | 暖簾の隙間からころんと転がるように顔を出し、うれしそうに葉が開く |
| 挨拶 | 両手を広げて小さくお辞儀し、頭の葉が上向きに揺れる |
| 商品紹介（餅） | ずんだ餅ののったお盆を両手で運び、商品の横を指さす |
| 商品紹介（シェイク） | ずんだシェイクを両手で抱え、こっそりひと口飲んで頬をふくらませる |
| 商品紹介（ロール） | ロールケーキの渦に合わせてくるくる回り、渦巻き目になる |
| いたずら失敗 | 張り切りすぎてころんと転び、葉がしおれてしょんぼりする |
| 喜び | その場で小さくジャンプし、葉が左右に揺れ、両手でハートを作る |
| 締め | 頭を下げて「ありがとう」、顔を上げて満面の笑顔 |

### Kling 向けの書き方

- カメラ指示は控えめに（固定〜ゆっくりズームまで。キャラの動きが主役）
- 「2頭身のマスコットが」など体型の再確認を1語入れると崩れにくい
- 尺は 3〜5 秒 = アクション1つ。詰め込まない

## 3. NG 制約（全工程共通・プロンプトの negative 相当）

ペルソナ 6 の禁止演出をそのまま生成制約にする:

- 他人を傷つける描写 / 食品を投げる・粗末にする描写
- 大声で暴れる・攻撃的な表現
- ずんだを嫌がる・否定する描写
- ブランドの上品さを壊す過度なドタバタ
- 頭身を 3 頭身以上にする（キャラ崩壊）
- パレット外の色をキャラ本体に使う

## 4. セリフ・字幕規則（工程2 台本 / 工程6 字幕用）

- 1セリフ **5〜15文字**。caption にもこの上限を適用する
- 一人称は「ぼく」
- 語尾: 「〜だよ」「〜しよう」「〜だっちゃ」「〜けさいん」「〜だねぇ」「どうぞ〜♪」
- 方言は1本の動画に1〜2回まで（ペルソナ 13 の注意）
- 決めぜりふ「ずんだで、むすぶよ！」は締めショット専用

## 5. 物語構造（工程1 企画 / 工程2 台本用）

基本フォーマットは **いたずら・承認型コメディ**（ペルソナ 6）:

```
①いたずら → ②失敗 → ③見つかる → ④しょんぼり → ⑤優しく受容 → ⑥商品・ブランドへ着地
```

15〜30 秒の縦動画なら、①②で注意を引き、⑤⑥で必ず商品に着地させる。
ずんちゃ丸は**主役ではなく相棒**（運用原則）。商品より目立たせない。

## 6. 実写共演の制作規則（工程5）

- 久保史緒里さんは**実写フッテージでのみ登場させる**。
  実在の人物なので、本人の容姿を AI 生成で作ることはしない
  （肖像の権利と本人の同意の問題。合成はずんちゃ丸側を実写に重ねる方向で行う）
- 掛け合いはペルソナ 17 の構造に従う（静かに気づく → 優しく受け止める）
- 合成時はずんちゃ丸を「ずんだ餅3個分」の身長感で配置する
