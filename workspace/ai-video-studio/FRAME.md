# FRAME.md — ずんだ茶寮 動画ブランドシステム

すべての動画制作でエージェントが従うブランドの見た目と動き方の定義。
スタジオ共通の正本。プロジェクト固有の上書きは各 `projects/<id>/FRAME.md` に置く。

推測で書いた項目はない。各項目の末尾に出典を記す。

---

## 1. ブランドの性格

やさしい・上品・地元愛・おもてなし・少しお茶目。
「商品より目立つ主役ではなく、商品を好きになるきっかけを作る相棒」の精神で、
動きも音も**商品と物語を邪魔しない控えめさ**を守る。
〔出典: ずんちゃ丸ペルソナ 7節・13節運用原則 / 久保さんプロフィール イメージキーワード〕

| ずんだグリーン（中） | #6FB234 | 前掛け・カップ・UI面 |

## 3. タイポグラフィ

- 和文: "Noto Sans JP", "Hiragino Sans", sans-serif。**太字(900)を基本**とし細字は補助のみ
- 字幕・セリフ: 白文字+輪郭グリーンの縁取り（-webkit-text-stroke + paint-order:stroke）
- ずんちゃ丸のセリフは白地・緑縁の丸吹き出し（border-radius 56px 以上）
- 1画面の文字は2階層まで（見出し+補助）。3階層以上並べない
〔出典: v1 制作実装（scenes/build.mjs）で検証済みのスタイル〕

## 4. 動きの言語（モーション）

### 登場
- キャラ・カード: 下から `back.out(1.2〜1.6)` で**ぽよんと1回だけ**弾んで定位置
- 吹き出し・擬音: `scale 0→1` を `back.out(2〜2.6)` で 0.3〜0.45s
- 文字: `opacity 0→1 + y 40→0` を `power3.out` で 0.5s。文字を回転させない

### 感情（ずんちゃ丸固有）
- 感情は必ず**頭の葉とセット**で動かす（うれしい=上向きに開く / 驚き=直立 / 落込み=垂れる）
- 震え・わくわくは 0.18〜0.2s の yoyo 小刻み回転

### 退場・転換
- 場面転換はカット基本。柔らげたい時のみ 0.3s 以下のクロスフェード
- 誇張退場（ころん・KO）は `bounce.out` で倒し、直後 0.5s 以上**静止の間**を置く

### テンポ
- 1ショット=1アクション。3秒に2つ以上の主アクションを入れない
- 「間」を恐れない: 発覚・受容の前に 0.5〜1 拍の静止を置く（承認型コメディの呼吸）

絶対に: 高速点滅・激しいシェイク・0.1s 未満のカット・無限ループ（repeat:-1）を使わない。
〔出典: v1/アニマティック実装のイージング実測値 / ペルソナ6節 禁止演出 / hyperframes-core 決定論規則〕

## 5. 音の言語

- BGM: C メジャーペンタトニックのマリンバ風・テンポ 110〜120・音量は SE の下
- SE は画面のビートに1対1で同期（ぽよん=登場 / ぽんっ=吹き出し / ちりん=ブランド要素）
- 事件・異常のパートは **BGM を消して環境音+SE のみ**（異常が際立つ）
- 全て自作合成（権利フリー）。外部音源を使う場合は権利確認を先に行う
〔出典: gen_audio.py 実装 / 12秒v1 の音響設計〕

## 6. レイアウト

- 縦 1080x1920 / 30fps 基本。字幕セーフエリア: 下 170px 基準
- ずんちゃ丸の定位置: 単独シーン=中央下 / 実写・商品と共演=右下 1/4（商品を隠さない）
- ロゴ・枝豆マークは小さく常時 or 締めのみ。**エンドカードでループを殺さない**
  （拡散用フォーマットでは締めをループ点にする）
- 余白を広く。1画面の要素は「背景+主役+文字1組」まで
〔出典: v1 実装 / バズ構造分析テンプレート〕

## 7. キャラクター運用

- ずんちゃ丸の正本は `02_キャラクター/ずんちゃ丸/ずんちゃ丸.svg`（柔らか立体シェーディング版）。
  composition には inline で埋め込み、表情は #expr-* グループの表示切替で行う
- 実在の人物（久保さん）は実写素材のみ。AI 生成・参照入力は禁止
〔出典: 02_キャラクター/ 各正本・制作規則〕

## 8. 物語の型

基本形は**いたずら・承認型**: いたずら→発覚→しょんぼり→優しい受容→商品着地。
久保さんは怒らない（気づく→静かに見る→一拍→小さく笑う→一緒に楽しむ）。
削るもの: 歴史説明・栄養説明・価格・長い味の説明・複数商品紹介・公式感の強いナレーション。
〔出典: ずんちゃ丸ペルソナ6節 / シナリオ正本「暖簾の向こうの犯人」〕
