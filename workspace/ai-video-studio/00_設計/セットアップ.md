## 1. 依存のインストール

```bash
cd workspace/ai-video-studio
npm install
```

### ffmpeg / ffprobe について

apt 権限が無い環境（このリポジトリの開発コンテナを含む）ではシステムに ffmpeg を入れられない。
そのため npm の静的バイナリを使う構成にしてある。**ffprobe は別パッケージ**で、
HyperFrames は両方を PATH 上に要求する。

`src/adapters/ffmpeg.ts` の `envWithFfmpeg()` が 2 つのディレクトリを `PATH` の先頭に足すので、
PATH 経由でバイナリを探す HyperFrames と video-use のヘルパーがそのまま動く。

システムに ffmpeg / ffprobe がある環境ではそちらが優先される。
明示指定したい場合は `FFMPEG_PATH` / `FFPROBE_PATH` を設定する。

### Chromium について

工程4（HyperFrames）と工程8（Remotion）はどちらもヘッドレス Chromium を使う。

Remotion は既定で `remotion.media` から専用ビルドを取得するが、送信先の allowlist に
無い環境では 403 になる。そこで `src/adapters/remotion.ts` の `resolveBrowserExecutable()` が
**HyperFrames が入れた chrome-headless-shell を再利用**する。
つまり `npx hyperframes browser ensure` を一度実行すれば両方の工程が動く。

明示指定したい場合は `REMOTION_BROWSER_EXECUTABLE` を設定する。

### ネットワーク制約と GSAP

送信プロキシが jsdelivr を遮断するため、HyperFrames の公式雛形にある
CDN 版 GSAP は読み込めない。読み込めなくても**レンダリングは警告だけ出して成功してしまい、
アニメーションが適用されない出力になる**。

そのため `scaffoldScene()` は `node_modules/gsap` の実体をシーンごとにコピーし、
`renderScene()` は `sub_timeline_script_failure` を検出したら明示的に失敗させる。
詳細は [HyperFrames実装ノート.md](HyperFrames実装ノート.md) を参照。

## 3. MCP / スキル

### Kling（工程3フォールバック・工程4）

**MCP コネクタは接続済み**（2026-07-26 確認、`mcp__kling__*` 系ツールが利用可能）。
モデル・ペイロードの詳細は [Kling実装ノート.md](Kling実装ノート.md) を参照。

接続経路は 2 つ。どちらか一方が生きていればよい。

1. **MCP コネクタ**（推奨・リモートセッション向け）
   claude.ai の 設定 → コネクタ → カスタムコネクタを追加 で `https://kling.ai/mcp` を登録し、
   ブラウザで OAuth 認可する。コネクタは claude.ai 側から接続されるため、
   実行環境の egress 制限の影響を受けない。接続後は `mcp__kling__*` 系ツールが使える。

2. **kling-cli スキル**（ローカルマシン向け）

   ```bash
   npx skills add klingai-tech/skills        # kling-cli スキルを登録
   npm i -g @klingai/cli-global              # 海外版 CLI（kling.ai アカウント用）
   kling login                                # ブラウザ OAuth（127.0.0.1 コールバック）
   ```

   `kling login` はブラウザを開いてローカルポートで認可を受けるため、
   **ヘッドレスなリモートコンテナでは完了できない**。さらに本リポジトリの
   リモート実行環境では egress プロキシが kling.ai への接続自体を 403 で遮断する。
   リモートセッションでは経路 1（MCP コネクタ）を使うこと。

呼び分けの定義は `src/adapters/mcp-bridge.ts` の `TOOL_IDS`、
CLI の使い方は `.agents/skills/kling-cli/SKILL.md` にある。

## 4. 動作確認

```bash
npm run studio -- new demo --title "デモ" --brief "商品紹介の縦動画" --duration 15
npm run studio -- run demo
```

工程1 は agent 層なので、ここで停止して Claude への作業依頼が表示される。
それが正しい挙動である（exit code 2）。

```bash
npm run studio -- status demo   # どこまで進んだか確認
```
