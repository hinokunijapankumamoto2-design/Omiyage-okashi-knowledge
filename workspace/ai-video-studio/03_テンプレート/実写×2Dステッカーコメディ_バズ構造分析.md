## 1. 構造分解

### 1-1. 時間構造（10秒4ショット）

| 時間 | ショット | 物語機能 | 感情の動き |
|---|---|---|---|
| 00:00–00:03 | ①塩の雪崩（いたずら） | セットアップ | 「あっ、やってる」共犯の笑い |
| 00:03–00:05 | ②ボトル没収＋ヘラでぽかっ（制裁） | ターン | カタルシス（お仕置きの快感） |
| 00:05–00:08 | ③噴水泣き＋口に詰める（餌付け） | エスカレーション | 「かわいそうかわいい」の情動反転 |
| 00:08–00:10 | ④塩辛KO・ころん（オチ） | ペイオフ＋フリーズ | 笑い→即ループ |

**配分則: 3-2-3-2。** セットアップとエスカレーションに3秒、ターンとオチに2秒。
オチをフリーズフレームで終えることで、ループ再生の継ぎ目が事実上消える
（インプレッションを稼ぐ核。10秒×高ループ率が再生数の実体）。

### 1-2. 物語構造

```
いたずら → 制裁 → 泣き＋ケア（餌付け） → KO（誇張された結末）
```

重要なのは③で、**制裁（お仕置き）とケア（食べさせる）が同じ手で連続する**こと。
罰する側が実は愛でている、という二重構造が「かわいそう×かわいい」の情動反転を作り、
リプレイ・共有の動機になる。純粋な制裁だけなら不快、純粋な可愛がりだけなら退屈。

### 1-3. コントラスト設計（この形式の発明の中核）

| 軸 | リアル側 | カートゥーン側 |
|---|---|---|
| 質感 | 8K実写キッチン・毛穴の見える手・油はね | 紙切り感のフラット2D・実照明の影響を受けない |
| 物理 | 塩が滝のように落ちる実物理 | たんこぶ「ドゥアン」・噴水涙・X目・魂の煙 |
| 音 | ジュージュー（ASMR的実音） | バネの「ボイン」・カートゥーンの泣き声 |
| カメラ | 手持ちの微揺れ（POV Vlogの文法） | キャラは常に正面向きのステッカー的静置 |

**「リアルを徹底するほどステッカーが際立ち、ステッカーを平面に保つほどリアルが際立つ」**
という相互強化。中途半端に馴染ませる（キャラに実照明を当てる等）と効果が死ぬ。

### 1-4. キャラクター記号の文法

- 感情はすべて**外部化された記号**で表現: 渦巻き目 / X目 / たんこぶ / 噴水涙 /
  めまい星 / 魂の煙 / 頭の葉の揺れ・しおれ
- セリフゼロ。言語非依存 = 国境を超えて伝わる（73万インプの到達範囲の説明変数）
- 頭部優位の誇張プロポーション（巨大頭・豆のような短足）= 小画面でも表情が読める

## 2. バズ要因の特定

| # | 要因 | 機構 |
|---|---|---|
| 1 | 0.5秒のパターン割り込み | 見慣れたPOV料理画面に「いるはずのないフラットな紙キャラ」→スクロール停止 |
| 2 | 既知ジャンルの転覆 | POV料理Vlogという確立文法を借りて文脈説明ゼロで開始できる |
| 3 | 10秒完結＋フリーズ終端 | 完走率とループ率を同時に最大化 |
| 4 | 音の二重設計 | 実音ASMR＋カートゥーンSFXの交互刺激。ミュート視聴でも記号で伝わる |
| 5 | 言語フリー | 字幕・言語理解が不要。国際リーチ |
| 6 | 情動反転（かわいそうかわいい） | 制裁→即ケアの連続が「守ってあげたい」共有動機を生む |
| 7 | ミーム母体 | X目・頬ぱんぱん等の静止フレームがそのままスタンプ・引用素材になる |
| 8 | 量産可能な構造 | キャラは実照明非依存＝合成コスト低。同構造で無限にエピソード化→フォロー動機 |

### 設計ルール（崩すと効果が落ちるもの）

1. 質感コントラストを絶対に混ぜない（キャラに実照明・実影を付けない）
2. ①のいたずらは「悪意ではなく過剰な善意」由来にする（共感の前提）
3. ③で制裁とケアを**同じ手**が連続して行う
4. ④は必ずフリーズで終える（ループ設計）
5. セリフを使わない。使うなら記号化された短い擬音のみ
6. 手の主は顔を映さない（視聴者の一人称を保つ）

## 4. ずんちゃ丸への適用（ブランド適合の変換）

カピバラルル版の構造はずんちゃ丸のペルソナと**ほぼ同型**（いたずら好き・おっちょこちょい・
記号化された葉の感情表現・餌付けされる側の可愛さ）。ただしブランド規約により2点を変換する。

| 原型 | ずんだ茶寮版への変換 | 理由 |
|---|---|---|
| ヘラで頭をぽかっ（物理制裁） | 手がそっと瓶を取り上げる／人差し指で「めっ」 | 禁止演出「他人を傷つける」「上品さを壊す」に抵触するため。発覚の驚き記号（！マーク・葉がピン）で同じビートは作れる |
| 塩＝失敗する調味料 | 追いずんだ＝入れすぎても美味しそうな増量 | 「商品を粗末にする」回避。いたずらの結果が商品の魅力増しに見える方向へ |
| 塩辛KO（苦痛の結末) | 食べすぎ幸せKO（満腹でころん・ほっぺ緑） | 苦痛ではなく多幸感で倒れる。ブランドの温度感を守りつつ④の誇張は維持 |

## 6. 15秒PR（zunda-shake-15s）との関係

- 15秒PR = 久保さん実写を軸にした**ブランド訴求**フォーマット（信頼・上品）
- 本テンプレ10秒 = キャラを軸にした**拡散**フォーマット（ループ・ミーム・言語フリー）
- 役割が異なるため置き換えではなく併走。同一素材（シェイク・暖簾・ずんちゃ丸）で
  2形式を量産するのが最も効率が良い
