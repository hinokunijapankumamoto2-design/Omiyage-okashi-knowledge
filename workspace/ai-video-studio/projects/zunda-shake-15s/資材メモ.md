# 資材メモ — ずんだシェイク 15秒PR

## 提供されたポスター（アートディレクション基準）

ユーザー提供のずんだ茶寮ポスター（横型）。この動画の画面設計はこれに合わせる。

### 構成要素

- **暖簾**: ずんだグリーンの暖簾が画面の主背景。「ZUNDA SARYO」の枝豆マーク＋「ずんだ茶寮」の白抜き文字
- **枝豆マーク**: 吹き出し「このマークが目印です！」で強調される、ブランドの目印
- **久保史緒里さん実写**: 白シャツ。ずんだシェイクを左手に持ち、右手の指差しで商品へ視線誘導。優しい微笑み
- **商品カット**: ずんだシェイク（通常／トッピング増し）が下段に2種
- **背景**: 店舗の陳列棚がぼけて映る（実店舗感）
- **ブランドロゴ**: 菓匠三全 / ずんだ茶寮（緑の大地から おいしさ＆ヘルシー）

### コピー（そのまま字幕・タイトルに使える）

- 「私はいつも、ずんだ茶寮のずんだシェイク！」（久保さんの一人称コピー）
- 「元祖の美味しさ、そのままに。」（ブランドタグライン）
- 「このマークが目印です！」

### 動画への転用方針

| ポスター要素 | 動画での使い方 |
|---|---|
| 暖簾＋枝豆マーク | s1 の背景（ずんちゃ丸の登場場所 = 暖簾はペルソナの住処設定と一致） |
| 久保さんの指差し・微笑み | s2 の実写カットの基準（表情01「優しい微笑み」） |
| シェイク商品カット | s3 のいたずら対象・s5 の締めカット |
| タグライン | s5 のタイトルカードに使用 |
| パレット | 全編ずんだグリーン基調（#8BCB59 系）＋白 |
