# 撮影キット「暖簾の向こうの犯人」— 久保さん実写パート

現場にこのファイルと `撮影ガイド/` の画像5枚を持っていけば撮影できる、完全指示書。
ずんちゃ丸・ストロー・字幕・記号は**すべて撮影後にこちらで合成する**ため、
現場で必要なのは「視線の演技」と「構図合わせ」だけ。

## 0. 事前チェック（プロデューサー確認欄）

- [ ] 久保さんご本人・所属からの出演許諾（本キットの用途・公開媒体を明記した書面）
- [ ] 撮影場所の使用許可（ずんだ茶寮店頭 or 暖簾を再現できる場所）
- [ ] 小道具: ずんだシェイク実物 ×2（通常サイズ＋ミニ）、緑のストロー

> 注: 「許可取得済み」との連絡を受けて本キットを発行していますが、
> 公開前に許諾書面の範囲（媒体・期間・編集可否）の最終確認を必ず行うこと。

## 1. 機材と共通設定

| 項目 | 指定 |
|---|---|
| カメラ | スマホで可。**縦向き固定**（三脚推奨） |
| 解像度 / fps | 1080×1920 以上 / **30fps** |
| 露出・WB | 固定（オートだとカット間で色が揺れる） |
| 照明 | 自然光 or 店内光。顔に影が落ちない正面寄り |
| 音声 | セリフは**同録不要**（後録り・字幕主体）。現場音は回しておくと編集で使える |

構図の基準: 各カットの `撮影ガイド/guide_bX.png` をスマホの隣に表示し、
**暖簾・人物・カップの位置をガイドのシルエットに合わせる**。
グレーの人型 = 久保さんの立ち位置。緑の要素 = 後合成されるずんちゃ丸・ストロー。

## 2. カット表（4カット・計約10秒の演技）

### CUT 1 — b1（使用尺 1.5秒 / 撮影 5秒）
ガイド: `guide_b1.png`
- シェイクを両手で持ち、ストローに口を近づける（飲む直前まで）
- 視線: カップ
- 構図: **画面左 1/3 を空ける**（暖簾とストローが合成で入る）
- NG: 実際に飲まない（b2 で中身の量が変わって見えるため）

### CUT 2 — b2（使用尺 2.5秒 / 撮影 8秒）
ガイド: `guide_b2.png`
- カップを不思議そうに見る（1秒）→ **ゆっくり**左の暖簾方向へ視線移動（1秒）→ 静かに疑う表情で止める
- 表情: シート05「考えている」→ 03「落ち着いた」。**驚かない・大げさにしない**
- セリフ「……ん？」は口を小さく動かすだけでよい（音は後付け）

### CUT 3 — b3 相当（音声のみ or 半身）
- 「ずんちゃ丸、飲んだでしょ？」の**セリフ音声を録る**（スマホのボイスメモで可・静かな場所で2〜3テイク）
- 画面はずんちゃ丸が主役のため、映る必要はなし。映る場合は画面右端に半身

### CUT 4 — b4（使用尺 2.5秒 / 撮影 8秒）
ガイド: `guide_b4.png`
- 画面下（転んだずんちゃ丸の位置）を見て、**責めずに微笑む**
- 表情: シート07「優しく見つめる」。一拍置いてから微笑むのが重要
- セリフ「全部つながってるよ」も口を動かす（音声は CUT 3 と同様に別録り）
- 構図: **画面下 1/3 を空ける**（ずんちゃ丸が転がる）

### CUT 5 — b5（使用尺 2.5秒 / 撮影 8秒）
ガイド: `guide_b5.png`
- ミニシェイクをテーブル（画面下 1/4）にそっと置き、小さく笑う
- セリフ「次は一緒に飲もうね」
- 構図: 置いたミニカップが**画面右下**に来る位置。左下はずんちゃ丸用に空ける

### 追加で録る音声（ボイスメモで可）
「……ん？」「ずんちゃ丸、飲んだでしょ？」「全部つながってるよ」「次は一緒に飲もうね」
各2〜3テイク。トーンは「静かに・優しく・上品に」（怒りゼロ）。

## 4. 受領後にこちらで行うこと（当日中）

1. video-use 系の前処理: 使用尺の切り出し・ずんだグリーン基調のカラーグレード
2. `v2/media/` のフォトベースを実写に差し替え（composition は src 差し替えのみ）
3. セリフ音声を SE/BGM とミックス（音量バランス調整）
4. check 5ゲート → レンダリング → **v3（実写版）納品**

フォト版 v2.1 がプレビズを兼ねているので、完成形のタイミング・構図は
現行動画の通りになる。現場で「これでいいのか」に迷ったら v2.1 を見ればよい。
