# 朝会メモ

> `/朝会` コマンドの実行結果（合意事項）が、ここに自動的に蓄積されます。

---

## このフォルダの役割

- `/朝会` コマンドが、CEO（あなた）と AI社員チームの**今日の進行を確定**したら、
  その合意事項を `YYYY-MM-DD.md` というファイル名で保存する場所
- 翌日の `/朝会` は、**前日のメモ** を参照して積み残しを拾う
- 1ヶ月分溜まれば、月次レビュー（`/週次報告`）と組み合わせて **会社の運用ログ** になる

---

## ファイル名規則

```
YYYY-MM-DD.md
```

例：
- `2026-05-04.md`
- `2026-05-05.md`

---

## 1ファイル分の標準構成

`/朝会` コマンドは、以下の形式で出力します。

```markdown
## 📅 YYYY-MM-DD 朝会

### 🎯 今日の重点
【1行で】

### 📋 本日のタスク（優先度順）
1. **[タスク名]** → @担当 / 目安XX分
   - 狙い:
2. ...

### 🔄 工程パイプライン（今日の流れ）
[例: @trend-researcher → @reel-scriptwriter → @reel-editor + @story-feed-runner]

### ⚠️ 気になる数字・動き（直近のインサイト）
- リーチ:
- 保存数:
- プロフィール遷移:
- 新規LINE登録:

### 💡 CEOへの確認事項
-

### 🌙 振り返り（任意・夕方追記）
- 完了したタスク:
- 残ったタスク:
- 翌日に持ち越す:
```

---

## 運用ルール

1. **朝会の合意事項のみ保存**（雑談ログは残さない）
2. **積み残しタスクは翌日の朝会で必ず拾う**
3. **1ヶ月以上前のファイル** は `99_アーカイブ/` に移動可
4. **数値（リーチ・保存・プロフィール遷移・LINE登録）** は取得日とともに記録
5. **CEO確認事項に未回答が残ったまま**翌日の朝会に進まない

## このフォルダが空のとき

`/朝会` を一度も実行していない状態です。
最初の朝会を実行するには、Claude Code 上で：

```
/朝会
```

と入力してください。
CEO（あなた）に対して、今日の重点・タスク・担当・確認事項を提示します。
合意できたら、自動でこのフォルダに `YYYY-MM-DD.md` が保存されます。
