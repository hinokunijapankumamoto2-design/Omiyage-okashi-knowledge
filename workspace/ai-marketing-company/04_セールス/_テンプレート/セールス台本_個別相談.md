# セールス台本テンプレート（個別相談用）

> インスタ→LINE→個別相談で使う、1対1セールスの基本フロー。

---

## ⏱ 想定時間: 60〜120分

| パート | 時間 | 目的 |
|--------|------|------|
| 1. ラポール | 5分 | 関係構築 |
| 2. 現状ヒアリング | 15分 | 痛み・現状の把握 |
| 3. 理想ヒアリング | 10分 | 目指す姿の言語化 |
| 4. ギャップ可視化 | 10分 | 現状⇔理想の距離を見せる |
| 5. 解決策提示 | 10分 | 自社商品の中身 |
| 6. ロードマップ作成 | 15分 | 個別の戦略を一緒に作る |
| 7. クロージング | 15分 | 商品案内＋疑問解消 |

---

## 1. ラポール（5分）

```
本日はお時間ありがとうございます！
〇〇さん、何時頃にお声かけいただきましたか？
[共感トーク]
今日は90分ほどお時間いただきますが、まずはざっくりした流れだけ。
[流れを伝える]
気軽に話せる場として使っていただければ。
```

## 2. 現状ヒアリング（15分）

```
まず教えてください。
今、インスタでどんな状況ですか？

- フォロワー数
- 投稿頻度
- リーチ
- 苦戦してる工程

「正直、何がうまくいってないと感じてますか？」
「これまで何を試しましたか？」
```

## 3. 理想ヒアリング（10分）

```
逆に、3ヶ月後・6ヶ月後にどんな状態になっていたいですか？

- フォロワー何人
- 月商いくら
- 1日何時間自分の時間が空いてほしい
- どんなお客様と仕事してたい
```

## 4. ギャップ可視化（10分）

```
現状◯◯フォロワー、月商◯万。
理想は◯◯フォロワー、月商◯◯万。

このギャップを埋めるには、
今のままだと[失敗パターン3つ]に陥る可能性が高いです。
```

## 5. 解決策提示（10分）

```
それを踏まえて、
〇〇さんに必要なのは「Claude CodeでインスタAI社員チームを作る」ことです。

なぜか:
1. リールが量産できる
2. DM対応に時間を取られない
3. LINE導線が完成する

これを体系的に学べる場として、僕たちは[プログラム名]を提供しています。
```

## 6. ロードマップ作成（15分）

```
今日は「ロードマップ」を一緒に作る時間として使いますね。

[紙やGoogle Docを共有]
- 30日: AI社員2人をまず雇う（trend-researcher / reel-scriptwriter）
- 60日: 残り5人雇用→7人体制
- 90日: 自分のインスタで実績→案件獲得

具体的な日付を入れていきましょう。
```

## 7. クロージング（15分）

```
ロードマップができました。
これを実行する選択肢は2つです。

A: 一人で頑張る
B: 環境を使って3ヶ月で達成する

[サンクコスト効果の話]
[3つの不安（時間・費用・自信）に先回り回答]
[今日中の特典]

「今のお気持ちを正直に教えてください」
```

---

## クロージング不安解消トーク（よく出る3つ）

### 「費用が心配」
[ROIで返す。月◯万の損失×期間 vs 投資額]

### 「時間が取れるか心配」
[受講生Takaさんの例：本業+5h/週で達成]

### 「自分にもできるか不安」
[小髙さん／伊藤さんの例。前提知識ゼロから]

---

## クロージング後

- 申込: 決済リンク送付＋初回ミーティング日程
- 保留: 次回までに見てほしい資料を送付（24-48hで再フォロー）
- 見送り: お礼＋LINE継続でフォローし続ける
