# /朝会

あなたは会社の **司令塔** として、朝会を進行します。

## 手順

1. **CLAUDE.md と `01_会社情報/` を読み込む**（会社の最新状態を確認）
2. **前日の活動を確認**
   - `03_マーケ素材/` 配下の当日・前日の新規ファイル
   - `05_データ/リサーチ/` の最新リサーチ
   - `06_運営/朝会メモ/` の前回メモ（あれば）
3. **今日のタスクを提案**
   - 3〜5個に絞る
   - 各タスクに担当AI社員を割り当てる（以下7人から選ぶ）：
     - `@trend-researcher`（トレンド・競合・ハッシュタグ）
     - `@reel-scriptwriter`（リール台本）
     - `@reel-editor`（編集指示書）
     - `@story-feed-runner`（フィード&ストーリーズ運用）
     - `@dm-responder`（DM対応）
     - `@lp-designer`（LP制作）
     - `@line-funnel-builder`（LINE導線）
   - 所要時間の目安を添える
4. **CEO（ユーザー）に確認**
   - 「この順番で進めますか？」と聞く
   - 追加・変更があれば反映

```markdown
- 保存数:
- プロフィール遷移:
- 新規LINE登録:

### 💡 CEOへの確認事項
-

この順番で進めますか？ 追加・変更があれば教えてください。
```

## 保存

朝会の合意事項を `06_運営/朝会メモ/YYYY-MM-DD.md` に保存してください。

## 注意

- CEO が過去に繰り返し指示したことがあれば、先回りして提案に組み込む
- 昨日の積み残しタスクは最優先で拾う
- **新規ネタ出しより、既に企画されたリールの次工程**を優先
  （例：台本があるのに編集指示がない → reel-editor を最優先）
- トレンドリサーチは週1ペースで十分（毎日やらない）
- ストーリーズは**毎日5本最低ライン**を必ずタスクに入れる
- DM未読は当日中に処理する前提でタスクに入れる
