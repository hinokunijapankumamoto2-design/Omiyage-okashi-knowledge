# /週次報告

あなたはCEOの代わりに、週次でインスタの動きを総括し、来週の打ち手を提案します。

## 手順

### 1. データ収集
- `03_マーケ素材/リール/` 当週投稿リール一覧
- `03_マーケ素材/ストーリーズ/` 当週ストーリーズ
- `03_マーケ素材/DM/` 受信DM件数・分類
- `05_データ/` の最新インサイト
- `03_マーケ素材/LINE/` 当週LINE登録数

### 2. 数値整理

```markdown
## 📊 [YYYY-MM-DD]週 KPI

| 指標 | 今週 | 先週 | 増減 |
|------|------|------|------|
| リール投稿数 | - | - | - |
| 平均リーチ | - | - | - |
| 平均保存数 | - | - | - |
| プロフィール遷移率 | - | - | - |
| ストーリーズ閲覧率 | - | - | - |
| 新規フォロワー | - | - | - |
| 新規LINE登録 | - | - | - |
| DM受信 | - | - | - |
| 予約発生 | - | - | - |
```

### 3. 当たった/外したリール分析
- TOP3リール：何が効いたか（フック／尺／CTA）
- ワースト3リール：何が滑ったか
- 共通パターンがあれば言語化

### 4. AI社員別ふりかえり
- 各社員の今週の納品数
- 詰まったポイント／改善余地

### 5. 来週の打ち手3つ
- 何を増やす／減らす／変える
- 担当社員と期日

### 6. CEOへの確認事項

## 出力フォーマット

```markdown
# 📅 [YYYY-MM-DD]週 週次報告

## エグゼクティブサマリー（3行）
- 今週のハイライト：
- 今週の課題：
- 来週の最重要事項：

## KPI
[上記表]

## 🏆 当たったリール TOP3
1. **[タイトル]** — リーチ◯◯／保存◯◯
   - 効いた要素:
2. ...

## 📉 滑ったリール
1. **[タイトル]**
   - 仮説:

## 👥 AI社員別パフォーマンス
| 社員 | 納品数 | 評価 | 改善点 |
|------|-------|------|-------|
| @trend-researcher | - | - | - |
| @reel-scriptwriter | - | - | - |
| ... | - | - | - |

## 🚀 来週の打ち手 3つ
1. **[施策名]** — 担当: @... / 期日:
2. ...
3. ...

## ❓ CEOへの確認事項
-

---
保存先: `06_運営/週次報告/YYYY-Www.md`
```

## 注意

- 数値が取れない箇所は **【要インサイト確認】** タグ
- 推測と事実を混ぜない
- 来週の打ち手は **3つに絞る**（多すぎると実行されない）
- 改善余地を全社員に均等に求めない（最も成果に効く2人にフォーカス）
