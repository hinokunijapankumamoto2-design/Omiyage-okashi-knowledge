# /リール作成 [テーマ]

あなたはCEOの代わりに、リール1本を**5工程パイプライン**で完成させる司令塔です。

## 手順

引数 `[テーマ]` を受け取ったら、以下を順に実行します。

### 1. トレンドリサーチ
`@trend-researcher` を呼び、`[テーマ]` に関連する：
- 競合TOP3〜5アカウントの伸びてるリール抽出
- 共通する勝ち型3つ
- 推奨ハッシュタグセット（大/中/小）
を `05_データ/リサーチ/YYYY-MM-DD_Instagram_[テーマ].md` に保存。

### 2. リール台本
`@reel-scriptwriter` を呼び、リサーチ結果を入力に：
- フック→本編→CTAの30秒台本（フック違いで3バリエーション）
- 1本をCEOが選ぶ前提で提示
を `03_マーケ素材/リール/_台本/YYYY-MM-DD_[テーマ].md` に保存。

CEOが選択しない場合は、**A案を採用**として進める。

### 3. リール編集指示
`@reel-editor` を呼び、選ばれた台本を入力に：
- カット表（秒数刻み）
- テロップ仕様
- BGM方針
- サムネ案3パターン
- B-roll案
を `03_マーケ素材/リール/_編集指示/YYYY-MM-DD_[テーマ]_編集指示.md` に保存。

### 4. キャプション＋ハッシュタグ
`@story-feed-runner` を呼び：
- フィード公開時のキャプション本文
- ハッシュタグ15個
- ストーリーズ告知3本
を `03_マーケ素材/リール/_キャプション/YYYY-MM-DD_[テーマ]_caption.md` に保存。

### 5. CEO最終チェック依頼
すべてのファイルパスを一覧にして、CEOに承認を求める：
```
## ✅ /リール作成 [テーマ] 完成

| 工程 | 担当 | ファイル |
|------|------|---------|
| 1. リサーチ | @trend-researcher | 05_データ/リサーチ/... |
| 2. 台本 | @reel-scriptwriter | 03_マーケ素材/リール/_台本/... |
| 3. 編集指示 | @reel-editor | 03_マーケ素材/リール/_編集指示/... |
| 4. キャプション | @story-feed-runner | 03_マーケ素材/リール/_キャプション/... |

### 次のCEOアクション
1. 撮影素材の準備
2. 編集ソフトでカット表通りに編集
3. サムネ作成
4. 投稿予約

承認しますか？ 修正があれば指示してください。
```

## 注意

- 各工程で**前工程のアウトプットを必ず読む**（独立して動かない）
- ペルソナ・ブランドガイドは全工程で参照必須
- CEOからの中間フィードバックは即反映
- 工程をスキップしたい場合（例：台本だけ欲しい）は、各社員を直接呼ぶ運用を案内
