## 🔄 カスタマージャーニー（インスタ起点）

```
発見（リール） → プロフィール訪問 → フォロー →
ストーリーズで日常見る → DMで質問 → LINE登録 →
LINE内で教育 → LP遷移 → 予約／購入
```

| 段階 | 進める要素 | 離脱要素 |
|------|----------|---------|
| 発見 | 「1人でSNS回すの限界」「Claude CodeでAI社員チーム」など、自分の悩みに直撃するフックがある | 抽象的なAI礼賛、何が得られるか分からない投稿 |
| プロフィール訪問 | 何を教えている人か一瞬で分かる。Claude Code、AIマーケ、SNS導線設計が明記されている | 肩書きが曖昧、実績風だが何を提供しているか分からない |
| フォロー | 投稿が体系的で、保存したくなる設計図・比較表・手順が多い | バズ狙いの単発投稿ばかりで、学習導線がない |
| DM | 「比較表」「設定テンプレ」「AI社員構成図」など、具体的な受け取り理由がある | いきなり売り込み、返信がテンプレ臭い、何をくれるか曖昧 |
| LINE登録 | 登録特典が明確。例：Claude Code AIマーケ会社テンプレート、MCP初期設定チェックリスト | 登録後に何が届くか不明、無料相談への誘導だけが強い |
| LP | 悩み、失敗例、解決手順、提供物、FAQ、導入後の未来が順番に整理されている | 価格だけ先に出る、成果を盛りすぎている、再現条件が不明 |
| 購入 | テンプレート・設計書・実装手順・伴走内容が具体的で、買った後の作業イメージが湧く | 「AIで簡単にできます」だけで、実装範囲・サポート範囲が曖昧 |

## 💬 DMでの対応方針

### DMで最初に言うこと
「コメントありがとうございます。まずは比較表をお送りしますね。」

### その後に聞くべきこと
「ちなみに今は、ChatGPTやClaudeをどのあたりまで使っていますか？」

### 質問の意図
いきなり売らない。
まず相手の現在地を把握する。

分類は以下。

1. ChatGPTだけ使っている
2. Claudeも使っている
3. Claude Codeに興味があるが未導入
4. Claude Codeを触ったが詰まった
5. すでに使っているが業務化できていない

### DMで避けること
- 初回から無料相談へ誘導
- 長文で売り込む
- 相手のレベルを確認せず技術用語を並べる
- 「簡単です」と言い切る
- 不安を煽りすぎる
