# ブランドガイド

> このガイドはトーン・ルック・NG表現を統一するための"会社の言語マニュアル"です。
> 対象ブランド：Claude Code / AIエージェント / AIマーケティング設計系の発信ブランド
> 世界観の核は、**「派手なAI礼賛ではなく、仕組みとして勝つ」**です。

---

## 🎨 ブランドトーン

### 一人称
- 私 / 僕 / 俺 / 弊社 / 私たち
- **採用**: 僕（個人発信） / 弊社（法人説明・実績説明時のみ）

### 語尾
- 〜です／ます調 / 〜だ／である調 / カジュアル混合
- **採用**: です／ます調ベース。要点・断定・フック部分のみ短く強い断定文を混ぜる

### 雰囲気
- 親しみやすさ 20%
- プロフェッショナル 45%
- 熱量 30%
- ユーモア 5%

### トーンの要約
- 基本は実務家の先輩
- ふわっと励ますのではなく、構造で説明する
- 知識自慢ではなく、「なぜ詰まるのか」「何が本質か」を言い切る
- ただし冷たくしすぎず、**「ここで詰まるのは普通」**という救済感は残す
- 煽る時も感情任せではなく、論点→比較→結論で刺す

### 絵文字方針
- リール内テロップ: 使わない
- フィードキャプション: 少なめ
- ストーリーズ: 自由
- DM: 1〜2個まで
- LINE: 原則使わない。使う場合も1個まで

## 🖌 リールのビジュアル方針

### フォント
- メインフォント: Noto Sans JP Bold
- アクセントフォント: Noto Sans JP Black
- 太さ: Bold〜Heavy

### カラー
- メインカラー: #1E88E5（知的・テック感・信頼）
- アクセントカラー: #E53935（警告・比較・断罪・注意喚起）
- サブカラー: #111827（本文・締め）
- 背景色: #FFFFFF または #F7FAFC

### 編集スタイル
- カット数: 多め（30秒で10〜15カット）
- テロップ密度: 高
- BGMジャンル: テック系 / ミニマル / 軽い緊張感のあるエレクトロ / シネマティック控えめ

### ビジュアルの基本思想
- 見た目は派手にしすぎない
- 白背景 + 青見出し + 赤強調 を基本にする
- デザインで勝つのではなく、論点の明快さで勝つ
- "AIっぽい近未来感"より、資料感・設計図感・業務感を優先する
- スライドっぽい見せ方でよい。むしろその方が信頼されやすい

### サムネイル方針
- 文字サイズ: 60pt以上
- 文字数: 10〜15文字
- 構図: 中央大見出し / 左右二分割 / 上1/3見出し
- 基本ルール:
  - 一番強い単語を赤で置く
  - 名詞より評価語を入れる
  - 例: 「中途半端」「設定地獄」「壊れる」「そのままだと詰む」
  - 見た瞬間に「自分向けだ」と分かることを優先する

## 🚫 NG表現リスト

### 絶対NG
- 誰でも簡単にできます
- 完全放置で回ります
- 知識ゼロでも100%再現できます
- これだけで売れます
- 設定すれば全部自動です
- 何も考えずに使えます
- 絶対に失敗しません
- 一瞬でプロになれます

### 文脈次第NG（要相談）
- 最強
- 神
- 革命
- 人生変わる
- ヤバい
- エグい
- 秒で
- 稼げる
- 自走する部下

使うなら、必ず補足を入れる
例: 「ただし、ルール・接続・保守が前提です」

### 法律的NG（薬機法・景表法・特商法）
- 「絶対に治る」「100%効果」「世界一」「日本一」「完全に」
- 「全員に効く」「副作用なし」（医療・健康系）
- 根拠のない数値（「3倍効果」「10万円稼げる」等）
- 出典不明の比較優位
- 根拠のない"業界初""唯一"表現

## 🎬 リール冒頭フック方針

### 推奨パターン
- 質問型: 「まだ1人でSNS回してませんか？」
- 衝撃型: 「実は、その使い方だと詰みます」
- 数字型: 「90%の人がここで止まります」
- 共感型: 「設定したのに翌日壊れる、ありますよね」
- 比較断罪型: 「○○単体、正直中途半端です」
- 構造暴露型: 「AIが動かない理由、ツールじゃありません」

### 自社で多用するフック
- まだ○○だけでやってる人へ
- 実は○○だけでは足りません
- 一番キツいのはここです
- そのやり方、最初だけです
- AIが強いんじゃなくて、構造が強いんです
- 設定できても、運用で壊れます
- 比較すると、違いはここです

### 自社で使わないフック
- 人生変わります
- これ見ないと損です
- 絶対保存
- 神ツール爆誕
- 誰でも簡単
- 今すぐ稼げる
- 秘密を暴露
- 無料だから受け取って

> 無料訴求は使ってもよいが、価値が先、無料は後にする

## 🧠 ブランドの言語ルール

### 基本構文

このブランドの文章は、できるだけ以下の順で書く。

1. 結論
2. なぜそう言えるか
3. 何がズレているか
4. どう直すか
5. 次の行動

### 1文の長さ
- 長すぎる1文は避ける
- 断定文は短く
- 補足は次文に分ける

### よく使う接続
- 結論から言うと
- つまり
- 逆に言うと
- 要するに
- ここが本質です
- ただし
- 一方で
- 本当に重要なのは

### よく使う比較構文
- AではなくB
- 表のメッセージはA、裏の実態はB
- ツールの問題ではなく、構造の問題
- 生成の問題ではなく、保守の問題
- 派手に見えるが、実態は地味

## 🪞ブランドの思想

### このブランドが繰り返し言うべきこと
- AIは魔法ではない
- 本質は設計である
- 上流設計が弱いと、下流は全部弱い
- 自動化の前に、ルールと構造が必要
- 壊れた時に直せない仕組みは、運用ではない
- AIを使うことより、AIが働ける会社構造を作ることが重要
- 勝っているのはツール名ではなく、会社側の整理力

### このブランドが敵にするもの
- ふわっとしたAI礼賛
- 「誰でも簡単」系の発信
- 設定できた瞬間だけで終わるノウハウ
- 過度な夢売り
- 構造を飛ばして成果だけ見せる見せ方
- 再現条件を伏せた実績トーク

## 📝 AI社員への一言メモ

【トーン統一で最も意識してほしいこと】

このブランドは、AIを持ち上げるブランドではありません。
AIを「会社の仕組み」に落とすブランドです。

だから、出力時は必ず以下を守ってください。

1. 結論を先に言う
2. 感情ではなく構造で説明する
3. 煽るなら、必ず理由を添える
4. ツール名ではなく設計思想を中心に置く
5. 派手さより再現性を優先する
6. "簡単"と言いすぎない
7. 最後は必ず、次の行動が分かる形で終える

### 補足：このブランドの一言定義

「AIで楽をする」ではなく、
「AIが働ける構造を作る」ことを教えるブランド。
