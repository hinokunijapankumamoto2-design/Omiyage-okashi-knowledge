# DM返信案：リール作り方の質問

## 受信DM要約
- 30代女性個人事業主
- 「リールがなかなか伸びなくて悩んでいます。何かコツありますか？」
- フォロー有り、過去保存3回

## 文脈推定
- 関係性: フォロワー（接触あり）
- 期待値: 具体的なTipsが欲しい／個別アドバイス
- リスク: なし

## 返信案（3パターン）

### A: 標準テンプレ
```
〇〇さん、メッセージありがとうございます！
リール伸ばすコツ、ざっくり3つあるんですが、
①フックが命（1秒で止める）
②CTAは1つに絞る
③尺は7s/15s/30s/60s/90sにきっちり
1個でも変えると景色変わりますよ。試してみてください！
```

### B: 個別カスタマイズ強め
```
〇〇さん、メッセージありがとうございます！
過去のリール何本か拝見しました。✨
良い点は[具体ポイント]、

[具体改善案]に変えてみてください。
3本作ったら結果教えてください！
```

### C: LINE誘導型

理由: 過去保存があるので関係性ができている。具体性で「この人は本気で見てくれる」と思わせる方が長期的に強い。
