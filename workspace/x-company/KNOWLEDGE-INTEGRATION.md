# Knowledge Integration Guide｜ナレッジ連携ガイド

x-company は **発信者のナレッジを `../📚ナレッジ/` から自動読み込み** する設計です。
このガイドはその仕組みと、新規ユーザーが自分のナレッジを格納する手順をまとめます。

---

## 全体アーキテクチャ

```
あなたの作業ディレクトリ/
├── 📚ナレッジ/                       ← 発信者の「真実の源」
│   ├── パーソナルナレッジ/            ← あなたのプロフィール・経歴・実績
│   │   └── パーソナル_[名前]_ナレッジ.md
│   ├── プロダクトナレッジ/            ← 商品・サービス・価格・LP
│   │   └── プロダクト_[商品名]_ナレッジ.md
│   ├── コンテンツナレッジ/            ← 文体・口癖・キャッチコピー
│   │   └── コンテンツ_文体パターン集.md
│   └── ドメインナレッジ/             ← 業界知識・市場・法令・評価軸
│       └── 業界_[業界名]_ナレッジ.md
│
└── x-company/                       ← X運用組織（業界非依存の汎用版）
    ├── CLAUDE.md
    ├── context/                     ← ブリッジ層（ポインタのみ）
    │   ├── 00_loader.md
    │   ├── about-me.md             → パーソナルナレッジ/
    │   ├── target.md               → パーソナルナレッジ/＋プロダクトナレッジ/
    │   ├── strategy.md             → プロダクトナレッジ/
    │   ├── domain-knowledge.md     → ドメインナレッジ/
    │   └── writing-style.md        → コンテンツナレッジ/
    └── company/                     ← 9社員
```

---

## 新規ユーザーのオンボーディング手順

### Step 1：ナレッジフォルダを準備
作業ディレクトリに以下を作成：
```bash
mkdir -p 📚ナレッジ/{パーソナルナレッジ,プロダクトナレッジ,コンテンツナレッジ,ドメインナレッジ}
```

### Step 2：ナレッジを格納（推奨：3つの方法）

**方法A：`/knowledge` スキルを使う（推奨）**
```
ユーザー: /knowledge
私のプロフィール：[名前][業界][実績]...

→ 自動で パーソナルナレッジ/ に格納される
```

**方法B：`/knowledge-creator` スキルで体系構築**
体系的にパーソナル・プロダクト・コンテンツの3軸で構築。

**方法C：手動でMarkdownを配置**
4つのフォルダにそれぞれ `.md` ファイルを置く。

### Step 3：x-company を起動
```bash
cd x-company
claude
```

→ AIが自動で `context/00_loader.md` を読み込み、`../📚ナレッジ/` 全体を取り込む。

### Step 4：秘書に話しかける
```
今日のX運用を設計してください
```

秘書（01_secretary）が📚ナレッジの内容を理解した上で、各社員にタスクを振り分ける。

## 各ナレッジに格納すべき内容

### パーソナルナレッジ
- 名前 / 一人称 / 年齢 / 居住地
- 経歴・職歴・実績・受賞歴
- 専門領域と発信の3軸
- ターゲット読者像（ペルソナ）

### プロダクトナレッジ
- 販売中の商品・価格・特典
- LP / セールスレターの構成
- マネタイズファネル
- 月次KPI・売上目標
- 採用判断基準・撤退条件

### コンテンツナレッジ
- 文体・トンマナ・口癖
- 過去のバズポスト集（型として再利用）
- キャッチコピー・訴求ワード集
- NGワード・禁止表現

### ドメインナレッジ
- 業界構造・市場規模
- 主要プレイヤー・競合分析
- 業界特有の評価軸
- 法令・コンプライアンス（薬機法/景表法/業界特化法令）
- 季節カレンダー・歳時記

---

## ナレッジ更新時の動作

`/knowledge` スキルでナレッジを更新すると、x-company は **次回起動時に自動で最新情報を反映** する。
ハードコードされた情報は context/ に存在しないため、更新漏れが発生しない。

---

## ナレッジが空の状態でも動かしたい場合

各 context/ ファイルには **フォールバック・テンプレート** が用意されている。
`../📚ナレッジ/` が存在しない or 空の場合は、テンプレートに従って情報を直接 context/ に記述してもよい（ただし長期運用では非推奨）。

---

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| AIが汎用的な投稿しかしない | 📚ナレッジが空 / 浅い | パーソナル・プロダクトを充実させる |
| トンマナが安定しない | コンテンツナレッジに文体定義なし | `コンテンツ_文体パターン集.md` を作成 |
| 法令リスクのある表現が出る | ドメインナレッジに法令未記載 | 業界の薬機法/景表法ルールを追記 |
| 商品案内が的外れ | プロダクトナレッジに最新情報なし | `/knowledge` で商品情報を更新 |

---

## このテンプレートを他者に配布する場合

x-company/ フォルダ全体をコピーして渡せば、業界に依存せず使える。
受け取った側は自分の `📚ナレッジ/` を作って配置するだけで動作する。
