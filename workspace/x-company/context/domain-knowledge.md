# Bridge: 業界・ドメイン知識｜Domain Knowledge

> このファイルはブリッジ（ポインタ）です。実体は `../📚ナレッジ/ドメインナレッジ/` ＋ `../📚ナレッジ/競合リサーチ/` にあります。

## プライマリソース
```
../📚ナレッジ/ドメインナレッジ/*.md
../📚ナレッジ/競合リサーチ/*.md      （存在すれば）
```

## 抽出すべき情報
- **業界構造**：市場規模・成長率・主要プレイヤー
- **業界特有の評価軸**：購買決定要因・差別化ポイント
- **季節カレンダー**：歳時記・需要のピーク・季節商品の発信タイミング
- **法令・コンプライアンス**：業界特化の法令（例）
  - 食品 → 薬機法・食品表示法・景表法
  - 金融 → 金融商品取引法・景表法
  - 医療 → 医療広告ガイドライン
  - 美容 → 薬機法・景表法
  - 教育 → 特商法
- **業界トレンド**：直近の動向・話題のキーワード
- **業界用語**：専門用語と一般人向けの言い換え
- **NGワード**：業界として避けるべき表現

## 出力時の使い方
- **業界用語は必ず補足を入れる**：専門用語は一般読者にもわかるよう括弧で言い換え
- **法令違反となる表現は絶対回避**：domain-knowledge から取得したNGワードリストを必ずチェック
- **季節商品は3週間前から仕込む**：歳時記カレンダーに基づき先回り発信

## 業界×法令の対応表（汎用ガイド）

| 業界 | 主な法令 | NG表現の例 |
|---|---|---|
| 食品・スイーツ | 薬機法・食品表示法 | 「健康になる」「美肌」「痩せる」 |
| 健康食品・サプリ | 薬機法 | 効能効果の暗示 |
| 美容・コスメ | 薬機法 | 「シミが消える」「アンチエイジング」 |
| 医療・クリニック | 医療広告ガイドライン | ビフォーアフター写真の単独掲載 |
| 金融・投資 | 金融商品取引法 | 「絶対儲かる」「元本保証」 |
| 教育・スクール | 特商法・景表法 | 「全員合格」「100%成功」 |
| 不動産 | 宅建業法 | 二重価格・おとり広告 |
| 全業界共通 | 景表法 | 「日本一」「最高」「No.1」（根拠なし） |

→ 詳細は必ず `../📚ナレッジ/ドメインナレッジ/` を参照
