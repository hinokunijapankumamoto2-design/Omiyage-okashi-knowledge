# Bridge: 社長プロフィール｜About Me

> このファイルはブリッジ（ポインタ）です。実体は `../📚ナレッジ/パーソナルナレッジ/` にあります。

## プライマリソース
```
../📚ナレッジ/パーソナルナレッジ/*.md
```
このフォルダ内のすべての `.md` ファイルを読み込み、発信者の人格コンテキストとして保持する。

## 抽出すべき情報
- **基本情報**：名前 / ペンネーム / 一人称 / 年齢 / 居住地
- **経歴・実績**：職歴 / 受賞歴 / メディア掲載 / 代表的な実績数値
- **専門領域**：他者には書けない強み・知識領域
- **発信の軸**：3つ程度の柱
- **トンマナ**：文体・口癖・絵文字使用ルール
- **避ける表現**：信頼性を損なうワード・NGトピック
- **自己紹介テンプレート**：プロフィール欄に使う固定文

## 各社員での活用ポイント

| 09_line-architect | LINE自己紹介配信の素材 |

## 出力時の使い方
- 投稿生成時：「自分の経歴・専門性に基づくと…」という観点で書く
- 数値・実績は曖昧化しない（「○○円」「○○件」と具体的に）
- 経歴に矛盾する内容を書かない（実績のない領域での断定を避ける）
