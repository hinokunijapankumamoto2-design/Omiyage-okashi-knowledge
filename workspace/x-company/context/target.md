# Bridge: ターゲット読者｜Target

> このファイルはブリッジ（ポインタ）です。実体は `../📚ナレッジ/パーソナルナレッジ/` ＋ `../📚ナレッジ/プロダクトナレッジ/` にあります。

## プライマリソース
```
../📚ナレッジ/パーソナルナレッジ/*.md   ← ペルソナ・読者像のセクション
../📚ナレッジ/プロダクトナレッジ/*.md    ← 顧客像・購入層
```

## 抽出すべき情報
- **一次ターゲット**：性別比 / 年齢 / 職業 / 居住地 / 可処分所得
- **二次ターゲット**：業界関係者・準顧客層
- **悩み・欲求**：解決したい課題・叶えたい未来
- **行動パターン**：閲覧時間帯・購入トリガー・季節性
- **刺さる言葉**：響く語彙・フレーズ
- **刺さらない言葉**：信頼を損なう表現
- **ペルソナ**：3名程度の具体例

## 各社員での活用ポイント
| 社員 | 何に使うか |
|---|---|
| 02_networking | 交流アカウント選定基準（ターゲット層に近いか） |
| 03_reply-worker | リプの内容を「ターゲットに刺さる文脈」に調整 |
| 04_like-worker | いいね対象選定（ターゲット層の投稿を優先） |
| 06_buzz-poster | バズポストの語彙・行動時間帯の最適化 |
| 07_content-poster | 記事のテーマ選定・問題提起の精度 |
| 08_product-developer | 商品設計の価格帯・形式の判断 |
| 09_line-architect | ステップ配信のトーン・テーマ選定 |

## 出力時の使い方
- 投稿前に「これはターゲットに本当に刺さるか？」を自問
- 抽象論ではなく具体的なシーンで語る（「[時間帯]に[行動]している人へ」）
- ペルソナのうち最も近い1人を想定して書く
