# Bridge: 文体・コンテンツ作法｜Writing Style

> このファイルはブリッジ（ポインタ）です。実体は `../📚ナレッジ/コンテンツナレッジ/` にあります。

## プライマリソース
```
../📚ナレッジ/コンテンツナレッジ/*.md
```

## 抽出すべき情報
- **文体パターン**：基本トーン・敬体/常体・改行ルール
- **口癖・固有フレーズ**：その人らしさを出すワード
- **過去のバズポスト集**：型として再利用可能なフォーマット
- **キャッチコピー・訴求ワード集**：商品・サービス紹介時の語彙
- **NGワード・禁止表現**：信頼性を損なうワード
- **絵文字ルール**：使用頻度・選択基準
- **句読点・改行ルール**：1行字数・段落の長さ

## 出力時の使い方
- **AIっぽい文体を避ける**：「いかがでしょうか」「皆さんもぜひ」「〜と言えるでしょう」を排除
- **発信者の口癖を必ず使う**：1ポストに最低1つは固有フレーズを入れる
- **過去のバズパターンを参考に**：似たテーマでバズった投稿の構造を再利用

## AI出力臭を消すチェックリスト

| ✗ 出やすいNGパターン | ✓ 修正方向 |
|---|---|
| 「いかがでしょうか」 | 言い切る or 削除 |
| 「ぜひ」「とても」「非常に」 | 具体表現に置換 |
| 「〜と言えます」「〜と言えるでしょう」 | 断定 or 具体 |
| 過剰な「、」 | 短文に分割 |
| 抽象表現（「素晴らしい」「すごい」） | 数値・固有名詞 |
| 文末の単調さ | 体言止め・倒置を混ぜる |
| 並列の三点（「AとBとC」） | 1つに絞り深掘り |

→ 詳細パターンは必ず `../📚ナレッジ/コンテンツナレッジ/` を参照
