# Context Loader｜ナレッジ読み込み手順書

## このファイルの役割
全社員が起動時に最初に実行する **ナレッジ読み込み手順書** 。
発信者の人格・商品・専門知識・文体は `../📚ナレッジ/` 配下に格納されている前提で、それらを取り込む手順を定義する。

## 読み込み手順（必ずこの順序で実行）

### Step 1：📚ナレッジ全体の存在確認
```
Glob: ../📚ナレッジ/**/*.md
```
ヒット件数が0なら「フォールバックモード」へ（後述）。

### Step 2：パーソナルナレッジを読み込む
```
Glob: ../📚ナレッジ/パーソナルナレッジ/*.md
→ 全ファイルをRead
```
抽出する情報：
- 発信者の名前 / 一人称 / 年齢 / 居住地 / 専門領域
- 経歴・実績・受賞歴・メディア掲載
- 発信の軸（3つ程度）
- トンマナ・口癖・避ける表現
- ターゲット読者像（ペルソナ）

### Step 3：プロダクトナレッジを読み込む
```
Glob: ../📚ナレッジ/プロダクトナレッジ/*.md
→ 全ファイルをRead
```
抽出する情報：
- 販売中の商品・価格帯
- LP / セールスコピー構成
- マネタイズファネル
- 月次KPI・目標
- 採用基準・撤退条件
- 訴求ワード集

### Step 4：ドメインナレッジを読み込む
```
Glob: ../📚ナレッジ/ドメインナレッジ/*.md
→ 全ファイルをRead
```
抽出する情報：
- 業界構造・市場規模
- 主要プレイヤー・競合
- 業界特有の評価軸
- 法令・コンプライアンス
- 季節カレンダー・歳時記

### Step 5：コンテンツナレッジを読み込む
```
Glob: ../📚ナレッジ/コンテンツナレッジ/*.md
→ 全ファイルをRead
```
抽出する情報：
- 文体パターン・トンマナ詳細
- 過去のバズポスト型
- キャッチコピー集
- NGワード・禁止表現

### Step 6：その他のナレッジ（任意）
以下が存在すれば追加で読み込む：
```
../📚ナレッジ/競合リサーチ/*.md
../📚ナレッジ/実績ナレッジ/*.md
../📚ナレッジ/正典思想/*.md
../📚ナレッジ/AI組織設計/*.md
../📚ナレッジ/ナレッジ索引.md
```

## bridgeファイルとの対応関係

| Bridge | 対応するナレッジフォルダ |
|---|---|
| context/about-me.md | パーソナルナレッジ/ |
| context/target.md | パーソナルナレッジ/（ペルソナ部分）＋ プロダクトナレッジ/（顧客像） |
| context/strategy.md | プロダクトナレッジ/ |
| context/domain-knowledge.md | ドメインナレッジ/ ＋ 競合リサーチ/ |
| context/writing-style.md | コンテンツナレッジ/ |

各bridgeファイルは「どこから何を抽出するか」「フォールバック・テンプレート」を記述している。

---

## フォールバックモード（📚ナレッジが空の場合）

ナレッジファイルが1件もヒットしない場合：
1. 各bridgeファイルの「フォールバック・テンプレート」セクションを参照
2. ユーザーに以下を提案：
   ```
   ⚠ ../📚ナレッジ/ にファイルがありません。
   以下のいずれかで初期化してください：
   - /knowledge スキルで雑多に投げる
   - /knowledge-creator スキルで体系構築
   - 各bridgeファイルのテンプレートを埋めて 📚ナレッジ/ に配置
   ```
3. ユーザーが了承すれば、最低限のテンプレートで動作開始

---

## 更新タイミング

- **新セッション開始時**：必ず本ファイルの手順を最初に実行
- **ナレッジ更新後**：`/knowledge` でナレッジが追加されたら、再度Step 1から実行
- **長時間セッション**：4時間以上経過したら再読み込み推奨（更新漏れ防止）

---

## 重要な原則

- **ハードコードしない**：context/ にも company/ にも、業界依存・個人依存の情報を直接書かない
- **単一の真実の源**：すべての発信者情報は `../📚ナレッジ/` が唯一の参照元
- **ナレッジに無い情報は推測しない**：不確実な場合は「要事実確認」と明記
- **更新は ナレッジ側で**：context/ や company/ を直接編集せず、`/knowledge` 経由でナレッジを更新する
