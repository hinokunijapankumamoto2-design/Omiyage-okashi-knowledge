## プライマリソース
```
../📚ナレッジ/プロダクトナレッジ/*.md
```
販売中の商品・価格・ファネル・KPI・採用基準等を全件読み込む。

## 抽出すべき情報
- **商品ラインナップ**：フロント / ミドル / バック商品の価格と内容
- **マネタイズファネル**：X → LP → LINE → 商品 のフロー
- **無料特典**：LINE登録時のプレゼント内容
- **月次KPI**：フォロワー目標 / LINE登録目標 / 月商目標
- **訴求ワード**：商品ごとのキャッチコピー・売り文句
- **採用判断基準・撤退条件**：商品の継続/終了の判断軸
- **LP / セールスレター構成**：既存の販売ページ構成

## 全社員共通の禁止事項（基本ルール）
- 効能訴求 / 最上級表現（「最高」「日本一」「絶対」）
- 他社・他者の批判・誹謗中傷
- 根拠のない実績・誇張
- 過度な煽り・期間限定の連発

→ 業界特有の法令（薬機法・景表法・金融商品取引法等）は `domain-knowledge.md` 経由で取得
